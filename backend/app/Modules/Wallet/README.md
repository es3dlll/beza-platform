# وحدة المحفظة الرقمية (Wallet Module)

## الهدف
إدارة المحافظ الرقمية بمستويات توثيق متدرجة (KYC Tiers)، حدود ديناميكية، وأرصدة متعددة العملات.

## الاعتمادات
- **Identity** — المستخدمون ومستويات KYC
- **FinancialCore** — عمليات الخصم والإيداع (عبر Event Bus)
- **EventBus** — أحداث تغيير الحدود والرصيد

## التدفقات الرئيسية
1. إنشاء محفظة عند اكتمال KYC (مستمع لحدث KYCLevelUpdated)
2. التحقق من الحدود قبل كل معاملة (DynamicLimitService)
3. تحديث الأرصدة بعد المعاملات (مستمع لحدث TransactionPosted)
4. طلب زيادة حد (سير عمل موافقة إدارية)

## واجهات API
- `GET /v1/wallet/limits` — الحدود الحالية والمتبقي
- `POST /v1/wallet/limits/request-increase` — طلب زيادة حد
