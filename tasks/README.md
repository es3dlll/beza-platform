# دليل المهام — Beza Platform

**هيكل المهام حسب الوحدة وأولوية التنفيذ.**

---

## مسار المستخدم الأساسي (MVP — 3 أسابيع)

```
Week 1: A1 → A2 → A3          (المصادقة)
Week 2: W1 → W2 → W3          (المحفظة)
Week 3: T1 → T2 → N1          (المعاملات)

ثم: I1 → I2 → نشر تجريبي
```
