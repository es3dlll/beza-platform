# Agent Network Market Analysis

## Competitive Landscape (Syria 2026)

### Direct Competitors
| Competitor | Type | Agent Count | Key Weakness |
|------------|------|-------------|--------------|
| Syriatel Cash Agents | Mobile Money Agents | ~4,000 | Telecom-locked (Syriatel SIM required), SYP-only, no float management tools |
| MTN MoMo Agents | Mobile Money Agents | ~3,500 | Same as Syriatel, limited agent support, outdated POS app |
| Informal Hawala Dealers | Remittance + Cash Agents | ~2,000 (licensed) | Unregulated, no digital integration, high fees (5-10%), slow settlement |
| Exchange Houses (Al-Maghrib, etc.) | FX + Remittance | ~500 branches | Limited hours, urban-only, no cash-in/out for digital wallets |
| Bank Correspondents (BBS, Bemo) | Banking Agents | ~200 | Bank-centric, complex onboarding, low commission rates |
| Cash (informal shopkeepers) | Unofficial | Unknown | No accountability, no record-keeping, trust-based only |

### Indirect Competitors
| Competitor | Type | Threat Level |
|------------|------|-------------|
| Mobile wallets (direct app funding via bank transfer) | Digital | Low — <30% have bank accounts |
| Cash-on-delivery services | Logistics | Medium — only for e-commerce |
| Prepaid card vending machines | ATM alternative | Low — no cash-in capability |

## Competitive Advantages
| Beza Advantage | Competitor Gap |
|---------------|---------------|
| Multi-function POS (cash-in, cash-out, bill pay, airtime, transfers) | Competitors are single-function (cash-in/out only) |
| Offline-first POS (transactions queue during internet outage) | Competitors require constant connectivity |
| Real-time float monitoring with low-balance alerts | Competitors have no float management tools |
| Tiered agent system (Bronze→Platinum with growing benefits) | Competitors have flat agent models |
| Transparent commission dashboard with daily accruals | Competitors settle monthly with no visibility |
| Biometric verification for high-value transactions | Competitors use basic PIN only |
| Bluetooth thermal receipt printing | Competitors offer no physical receipts |
| Agent performance analytics and ML-based float recommendations | Competitors have zero analytics |
| Multi-currency support (SYP + USD float) | Competitors are SYP-only |
| Integrated with full Beza ecosystem (wallet, bills, transfers) | Competitors are standalone agent networks |
