# Remittance User Personas

## Persona 1: Khalid — Diaspora Remitter (Germany)
```
Name: Khalid Al-Hassan
Age: 34
Occupation: Electrician in Berlin
Income: €2,800/month
Location: Berlin, Germany (originally from Damascus)
Tech literacy: Medium
Banked: Yes (N26, Sparkasse)
Family: Wife + 2 children in Syria

Remittance behavior:
  - Sends €300-500/month to family
  - Currently uses informal hawala (contact in Berlin)
  - Hawala fee: 7-10% + bad FX rate
  - Wants: lower fees, instant delivery, tracking

Pain points:
  - Hawala takes 2-3 days
  - No delivery confirmation (anxiety about money reaching family)
  - FX rate is hidden — doesn't know effective cost
  - Has to take time off work to visit hawala agent
  - Wants automated monthly transfer

Needs:
  - Sub-3% all-in cost
  - Instant delivery to family's Beza wallet
  - Recurring monthly transfer setup
  - Real-time delivery notification
  - Arabic-language app with German bank integration
  - EUR→SYP conversion at fair rate
```

## Persona 2: Fatima — Professional Remitter (Sweden)
```
Name: Fatima Al-Sayed
Age: 29
Occupation: Nurse in Stockholm
Income: SEK 32,000/month
Location: Stockholm, Sweden (originally from Aleppo)
Tech literacy: High
Banked: Yes (Swedbank)
Family: Parents + siblings in Aleppo

Remittance behavior:
  - Sends €200-400/month to family
  - Uses bank transfer + Western Union occasionally
  - Bank fee: €15-25 per transfer

Pain points:
  - Bank transfers expensive (€15-25 flat fee)

  - Bi-weekly recurring transfer
  - Multi-currency (SEK/EUR funding, USD/SYP delivery)
```

## Persona 3: Ahmad — Local P2P Sender
```
Name: Ahmad Khoury
Age: 26
Occupation: Software developer in Damascus
Income: 600,000 SYP/month
Tech literacy: High
Smartphone: Yes (iPhone 13)
Banked: Yes (BBS)

Remittance behavior:
  - Sends 50,000-100,000 SYP/month to family in Aleppo
```

## Persona 4: Umm Mohammed — Recipient (Rural Syria)
```
Name: Umm Mohammed
Age: 52
Occupation: Housewife in Idlib countryside
Income: Support from son in Turkey (200,000 SYP/month)
Tech literacy: None
Smartphone: No (Nokia feature phone)
Banked: No

Receiving behavior:
  - Son sends money from Turkey via hawala
  - Travels 45 min to nearest town for pickup

```
