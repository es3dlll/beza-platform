# Remittance UX/UI Specification

## Screen 1: Send Money (Diaspora Remittance View)

### Layout
```
┌────────────────────────────────┐
│ <  إرسال أموال                │ Header
├────────────────────────────────┤
│ تحويل إلى                     │
│ ┌──────────────────────────┐  │
│ │ أم محمد                  │  │ Beneficiary avatar + name
│ │ أمي - دمشق               │  │ Relationship + city
│ │ آخر تحويل: 5 يونيو 2026  │  │ Last sent date
│ └──────────────────────────┘  │
│ [تغيير المستفيد] [إضافة مستفيد]│ Actions
├────────────────────────────────┤
│ المبلغ                        │
│ ┌────────────────────────┐    │
│ │        300          يورو   │  │ Amount input (large, centered)
│ └────────────────────────┘    │
│ EUR │ USD │ SYP              │ Currency selector
├────────────────────────────────┤
│ سعر الصرف                     │
│ 1 EUR = 13,200 SYP          │ Live FX rate
│ السعر الرسمي: 13,420        │ Mid-market comparison
│ فارق: 1.8%                   │ Spread indicator
├────────────────────────────────┤
│ تفاصيل العملية                │
│ المبلغ المحول:    300.00 EUR │
│ الرسوم (1.5%):     4.50 EUR  │
│ الإجمالي:         304.50 EUR │
│ ─────────────────────────    │
│ المستلم:       3,960,000 ل.س │ Recipient gets (SYP)
│ سعر الصرف:  13,200 SYP/EUR  │
├────────────────────────────────┤
│ ملاحظة (اختياري)              │
│ ┌────────────────────────┐    │
│ │ مصاريف البيت - يونيو   │    │ Note input
│ └────────────────────────┘    │
├────────────────────────────────┤
│ [تثبيت السعر 60 ثانية]       │ Rate lock button
│ [تأكيد الإرسال]              │ Primary CTA
└────────────────────────────────┘
```

### States
| State | Behavior |
|-------|----------|
| Loading rates | Skeleton: FX rate shimmer, fee breakdown shimmer |
| Rate expiring | Banner: "ينتهي تثبيت السعر خلال 10 ثوانٍ" + countdown |
| Rate expired | "انتهى السعر، تم تحديث السعر" with new rate |
| Insufficient funds | CTA disabled + "الرصيد غير كافٍ في حساب N26" |
| Daily limit reached | "تم تجاوز الحد اليومي" + upgrade KYC link |
| Successful | Confetti + "تم الإرسال! 3,960,000 ل.س في الطريق" |
| Failed | "فشلت العملية" + reason + "إعادة المحاولة" button |

## Screen 2: Beneficiary Management

### Layout
```
┌────────────────────────────────┐
│ <  المستفيدون                 │ Header
├────────────────────────────────┤
│ [إضافة مستفيد]                 │ Primary action
├────────────────────────────────┤
│ 🔍 بحث عن مستفيد...           │ Search
├────────────────────────────────┤
│ المستفيدون المفضلون            │
│ ┌──────────────────────────┐   │
│ │ أم محمد                   │   │
│ │ أمي · دمشق · آخر: 5 يونيو │   │
│ │ [أرسل] [تعديل]           │   │
│ ├──────────────────────────┤   │
│ │ أحمد خالد                 │   │
│ │ أخي · حلب · آخر: 1 يونيو  │   │
│ │ [أرسل] [تعديل]           │   │
│ ├──────────────────────────┤   │
│ │ لينا                      │   │
│ │ أختي · اللاذقية · جديد    │   │
│ │ [أرسل] [تعديل]           │   │
│ └──────────────────────────┘   │
└────────────────────────────────┘
```

### Add Beneficiary Form
| Field | Type | Validation |
|-------|------|-----------|
| Full name | Text | Required, 2-100 chars, Arabic/English |
| Relationship | Dropdown | أمي، أبي، أخي، أختي، زوجتي، زوجي، ابن، ابنة، صديق، آخر |
| Phone number | Phone | Required, +963 format or diaspora country code |
| City (optional) | Text | Any |
| Currency preference | Toggle | SYP / USD (default: SYP) |
| Notes | Text | Optional, max 200 chars |
