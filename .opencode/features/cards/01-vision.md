# Cards Feature Vision

## Elevator Pitch
Beza Cards provides virtual and physical prepaid cards that replace cash for online and in-person purchases — enabling Syrians to shop on international e-commerce, add cards to Apple Pay/Google Pay, withdraw from ATMs, and control spending with real-time limits and notifications, all from a single app.

## Problem Statement
- No prepaid card culture in Syria — population relies entirely on cash
- International e-commerce blocked for most Syrians (no international cards, sanctions)
- No way to pay online with Apple Pay/Google Pay using Syrian-issued cards
- ATM withdrawals require bank accounts with minimum balances many can't maintain
- No spending controls — traditional debit/credit cards have no category limits or freeze ability
- Physical card theft means full account compromise (no ability to freeze)

## Target Users
- **Primary**: Urban Syrians age 18-45 with smartphones needing online payment capability (3M target)
- **Secondary**: Beza wallet users upgrading from cash-only to card-enabled (2M target)
- **Tertiary**: Diaspora Syrians sending cards to family in Syria for daily use (500K target)

## Core Capabilities
| Capability | Priority | Description |
|------------|----------|-------------|
| Virtual card instant issuance | P0 | Generate card number, CVV, expiry instantly in-app |
| Physical card (NFC) | P0 | Plastic card with chip + NFC for POS/ATM, delivered via agent |
| Apple Pay / Google Pay tokenization | P0 | Add virtual card to phone wallet for contactless payments |
| Card freeze/unfreeze | P0 | Instant card locking from app without support call |
| PIN management | P0 | Set/change PIN via app, verified by phone OTP |
| Spending limits per category | P0 | Per-card limits: online, POS, ATM, international, total daily |
| One-time use virtual card | P1 | Single-use card number (privacy.com model) for untrusted merchants |
| Card replacement | P1 | Replace lost/stolen/damaged card, preserve same BIN/last-four |
| Transaction notifications | P0 | Real-time push/SMS on every card transaction |
| Transaction history | P0 | Filterable, merchant-categorized, downloadable |
