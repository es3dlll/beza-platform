### States
| State | Behaviour |
|-------|----------|
| Loading | Skeleton grid (8 placeholder cards) + shimmer |
| Empty | Illustration + "لم تقم بأي دفع حكومي بعد" |
| Error | "تعذر تحميل الخدمات" + "إعادة المحاولة" |
| Offline | Cached services shown, banner "قد لا تكون الأسعار محدثة" |
