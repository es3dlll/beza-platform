### States
| State | Behavior |
|-------|----------|
| Loading | Skeleton cards (3x) with shimmer animation |
| Empty | Centered illustration + "ليس لديك أي هدف توفير بعد! ابدأ الآن" + CTA |
| Error | "حدث خطأ في تحميل أهداف التوفير" + "إعادة المحاولة" |
| Offline | Cached goals shown, banner "قد لا تكون البيانات حديثة" |
| Slow network | Skeleton + shimmer, pull-to-refresh enabled |

### States
| State | Behavior |
|-------|----------|
| Initial | Default icon pre-selected, suggested amount calculated |
| Validation error | Red borders + inline errors in Arabic |
| Creating | Loading spinner on CTA, disabled |
| Success | Navigate to goal detail with celebration |
| Error | Snackbar: "فشل إنشاء الهدف، حاول مرة أخرى" |
