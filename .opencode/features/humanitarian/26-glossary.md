# Glossary of Terms

| Term (English) | المصطلح (بالعربية) | Definition |
|----------------|---------------------|------------|
| **Agent** | وكيل | Field officer who verifies beneficiaries and assists with wallet setup |
| **Aid Program** | برنامج مساعدة | A defined humanitarian intervention (type, budget, beneficiary list, rules) |
| **Beneficiary** | مستفيد | Individual or household receiving humanitarian assistance |
| **Biometric Verification** | التحقق البيومتري | Identity verification using fingerprint + facial recognition |
| **Burn Rate** | معدل الصرف | Percentage of distributed cash that beneficiaries have spent within a period (7/14/30 days) |
| **Cash-Based Assistance (CBA)** | المساعدة النقدية | Aid delivered as cash or vouchers rather than in-kind goods |
| **Conditional Cash Transfer (CCT)** | تحويل نقدي مشروط | Cash provided conditional on specific behaviours (e.g., school attendance) |
| **CSV Upload** | رفع ملف CSV | Batch beneficiary enrolment via comma-separated value file |
| **Distribution** | توزيع | The act of disbursing cash or vouchers to beneficiaries |
| **Do-No-Harm** | عدم الإضرار | Principle that humanitarian aid must not expose beneficiaries to additional risk |
| **Donor** | مانح | Entity funding humanitarian programs (ECHO, USAID, DFID, etc.) |
| **E-Voucher** | قسيمة إلكترونية | Digital voucher redeemable for specified goods at partner merchants |
| **Field Agent** | وكيل ميداني | See "Agent" |
| **Governorate** | محافظة | Syria's top-level administrative division (14 governorates) |
| **IDP (Internally Displaced Person)** | نازح داخلياً | Person forced to flee home but remaining within Syria's borders |
| **Impartiality** | عدم التحيز | Humanitarian principle: aid based on need alone, no discrimination |
| **MCC Code** | رمز تصنيف التاجر | Merchant Category Code — standard code classifying type of business |
| **MPC (Multi-Purpose Cash)** | مساعدة نقدية متعددة الأغراض | Unconditional cash that beneficiaries can spend on their priority needs |
| **NGO** | منظمة غير حكومية | Non-Governmental Organisation delivering humanitarian assistance |
| **OFAC** | مكتب مراقبة الأصول الأجنبية | US Office of Foreign Assets Control — sanctions enforcement agency |
| **Partner Merchant** | تاجر شريك | Approved merchant who accepts e-vouchers and receives settlement |
| **Program Manager** | مدير برنامج | NGO staff member who creates and manages aid programs |
| **Sanctions Screening** | فحص العقوبات | Process of checking beneficiary names against UN/EU/OFAC sanctions lists |
| **Settlement** | تسوية | Payment to merchant for redeemed vouchers (typically T+2) |
| **UNHCR** | المفوضية السامية للأمم المتحدة لشؤون اللاجئين | UN Refugee Agency — registers and protects displaced persons |
| **UNHCR ID** | رقم المفوضية | Unique registration number assigned by UNHCR to refugees/IDPs |
| **USSD** | خدمة الوسائط غير المنظمة التكميلية | Unstructured Supplementary Service Data — text-based mobile interface for feature phones |
| **Verification** | تحقق | Process of confirming a beneficiary's identity before aid disbursement |
| **Voucher** | قسيمة | Electronic token redeemable for specified goods/services at partner merchants |
| **Wallet** | محفظة رقمية | Beza digital wallet used to hold and spend cash assistance |
| **Winterisation** | مساعدة شتوية | Humanitarian aid specific to winter needs (heating, blankets, warm clothing) |
