# Internationalization & Localization

## Arabic-First Design

| Aspect | Approach |
|--------|----------|
| Default locale | `ar` (Arabic) — all UI renders RTL by default |
| Secondary locale | `en` (English) — for donor/international staff |
| Locale detection | Browser `Accept-Language` → IP geo-hint → default Arabic |
| Script direction | Full RTL support across all components |

## Translation Coverage

| Domain | Strings | Priority |
|--------|---------|----------|
| NGO dashboard (programs, beneficiaries, distributions) | ~500 | P0 |
| Field agent app (verification flow) | ~150 | P0 |
| Merchant app (voucher redemption, settlements) | ~100 | P0 |
| SMS / USSD beneficiary notifications | ~30 | P0 |
| Donor portal (reports, analytics) | ~200 | P1 |
| Error messages and validation | ~120 | P0 |

## Translation Infrastructure
- **Library:** next-intl (ICU message format with pluralisation)
- **Storage:** JSON files per locale in `messages/{locale}/humanitarian.json`
- **Tooling:** In-crowd translation management (NGO Arabic linguists review)
- **Variables:** Arabic locale strings may reorder English-optimised variable templates

## Arabic-Specific Considerations

| Consideration | Implementation |
|----------------|----------------|
| Text direction | `dir="rtl"` on all Arabic pages; `text-start`/`text-end` instead of `text-left`/`text-right` |
| Numerals | Eastern Arabic numerals (٠١٢٣٤٥٦٧٨٩) for dates, amounts on beneficiary-facing screens |
| Font | Noto Naskh Arabic for body, Noto Kufi Arabic for headings |
| Date format | `dd/mm/yyyy` (Arabic); Hijri calendar optional toggle for religious context |
| Names | Honourifics preserved: `السيد`, `السيدة`, `الدكتور` |
| Voice guidance | TTS prompts in Syrian Arabic dialect for illiterate beneficiaries |
| Currency display | `٧٥٫٠٠ دولار أمريكي` (Arabic numeral + currency name) |

## SMS / USSD Localisation

| Scenario | Arabic SMS |
|----------|------------|
| Cash received | `تم إيداع ٧٥ دولار في محفظتك. شكراً للصليب الأحمر العربي السوري.` |
| Voucher issued | `تم إصدار قسيمة غذائية بقيمة ٤٥ دولار. رمز القسيمة: XXXX-XXXX-XXXX` |
| Spending alert | `تم استخدام ٣٠ دولار من محفظتك هذا الأسبوع.` |
| Beneficiary enrolled | `تم تسجيلك في برنامج المساعدة النقدية. يرجى زيارة أقرب وكيل للتحقق.` |

## RTL Component Testing
All components with RTL support must pass visual regression tests for both `dir="ltr"` and `dir="rtl"` orientations.
