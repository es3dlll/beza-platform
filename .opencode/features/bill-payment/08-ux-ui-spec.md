# Bill Payment UX/UI Specification

## Screen 1: Bill Category Grid

### Layout
```
┌────────────────────────────────┐
│ <  دفع الفواتير                │ Header
├────────────────────────────────┤
│ فئات الفواتير                  │
│ ┌──────┐ ┌──────┐ ┌──────┐   │
│ │ 🔌   │ │ 💧   │ │ 📞   │   │
│ │كهرباء│ │ مياه │ │اتصالات│  │
│ │3 فواتير │ │2 فاتورة│ │3 فواتير│ │
│ └──────┘ └──────┘ └──────┘   │
│ ┌──────┐ ┌──────┐ ┌──────┐   │
│ │ 🌐   │ │ 🏛   │ │ 🎓   │   │
│ │إنترنت│ │ حكومة│ │تعليم│   │
│ │2 فواتير │ │3 فواتير│ │2 فاتورتين│ │
│ └──────┘ └──────┘ └──────┘   │
├────────────────────────────────┤
│ فواتيري الأخيرة                │
│ [فاتورة كهرباء 44,625 ل.س]    │
│ [Syriatel 33,000 ل.س]        │
│ [دفع المزيد >]                │
└────────────────────────────────┘
```

### States
| State | Behavior |
|-------|----------|
| Loading | Skeleton grid with 6 placeholder cards |
| Categories loaded | Animated fade-in of category cards |
| Error | "فشل تحميل الفئات" + Retry button |
| Recent bills exist | Show last 3 paid bills with quick re-pay |

## Screen 2: Customer ID Entry (PEED Example)

### Layout
```
┌────────────────────────────────┐
│ <  كهرباء — PEED               │ Header with biller logo
├────────────────────────────────┤
│ 🔌 الشركة العامة للكهرباء      │
│ دفع فاتورة الكهرباء            │
├────────────────────────────────┤
│ رقم المشترك                    │
│ ┌────────────────────────┐    │
│ │ 1234-5678-9012-3456   │    │
│ └────────────────────────┘    │
│ مثال: 1234-5678-9012-3456-7890│ Helper text
│ (24 رقم — 4×6)               │
├────────────────────────────────┤
│ [📸 مسح العداد] (Phase 2)     │ OCR camera button
├────────────────────────────────┤
│ الفواتير السابقة لهذا الرقم    │
│ ┌──────────────────────────┐   │
│ │ 2026-05 — 38,200 ل.س    │   │
│ │ ✅ مدفوعة                │   │
│ ├──────────────────────────┤   │
│ │ 2026-04 — 35,500 ل.س    │   │
│ │ ✅ مدفوعة                │   │
│ └──────────────────────────┘   │
├────────────────────────────────┤
│ [استعلام عن الفاتورة]          │ Primary CTA
└────────────────────────────────┘
```

### States
| State | Behavior |
|-------|----------|
| Empty | Cursor blinking at start position |
| Typing | Auto-format: insert dash every 6 digits |
| Invalid format | Red border + "يجب أن يتكون الرقم من 24 رقماً" |
| Max length | Input stops at 24 digits + auto-dash |
| Existing bills | Show last 2 paid bills for this ID |
| API error on fetch | "تعذر الاستعلام — حاول مجدداً" + Retry |

## Screen 3: Bill Detail (Fetched)

### Layout
```
┌────────────────────────────────┐
│ <  تأكيد الفاتورة              │ Header
├────────────────────────────────┤
│ 🔌 كهرباء — PEED              │ Biller name
│ رقم المشترك: 1234-5678-9012-3456-7890
├────────────────────────────────┤
│            42,500 ل.س          │ Hero amount
│           إجمالي المستحق       │
├────────────────────────────────┤
│ تفاصيل الفاتورة                │
│ الاستهلاك: 850 كيلوواط/ساعة   │
│ التعرفة: منزلي +250 ك.و        │
│ قيمة الاستهلاك: 40,000 ل.س    │
│ ضريبة: 2,500 ل.س (5%)         │
│ الإجمالي: 42,500 ل.س          │
├────────────────────────────────┤
│ ⚠️ غرامة تأخير: 2,125 ل.س    │ Late fee (red/amber bg)
│ (5% — متأخرة 5 أيام)          │
├────────────────────────────────┤
│ الإجمالي الواجب: 44,625 ل.س   │ Total due (bold)
├────────────────────────────────┤
│ تاريخ الاستحقاق: 2026-06-15   │
│ رقم الفاتورة: PE-2026-789012  │
├────────────────────────────────┤
│ ☐ أتعهد بصحة المعلومات        │ Checkbox
│ [تأكيد الدفع]                  │ Primary CTA
└────────────────────────────────┘
```

### States
| State | Behavior |
|-------|----------|
| Fetching | Spinner overlay with "جارٍ الاستعلام..." |
| Fetched | Slide-up animation of bill details |
| Late fees | Red banner with warning icon (animate pulse) |
| Already paid | Grey overlay + "هذه الفاتورة مدفوعة" |
| Network error | Toast: "تعذر الاتصال بمقدم الخدمة" |
