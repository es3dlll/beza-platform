# Information Architecture

## Navigation Structure

```
Marketplace (Tab)
├── Home
│   ├── Category Grid (6 items)
│   ├── Special Offers carousel
│   ├── Bestsellers row
│   └── Recommended for you
├── Top-Up (Quick Action)
│   ├── Network Selector
│   ├── Phone Number Input
│   ├── Amount Picker (presets + custom)
│   ├── Favorites
│   ├── Auto Top-Up Settings
│   └── History
├── Gift Cards (Category)
│   ├── Merchant Grid
│   ├── Merchant Detail
│   │   ├── Denomination Selector
│   │   └── Quantity
│   ├── Recipient / Delivery Options
│   └── My Gift Cards
├── Digital Goods (Category)
│   ├── Subcategories
│   │   ├── Game Credits
│   │   ├── Streaming Subscriptions
│   │   ├── Software Licenses
│   │   └── E-books
│   ├── Search / Filter
│   └── Product Detail
├── Internet Packages (Category)
│   ├── ISP Selector
│   ├── Plan List
│   └── Plan Detail
├── Bill Payment (Category)
│   ├── Bill Type Selector
│   ├── Account/Reference Input
│   ├── Amount & Payment
│   └── Payment History
├── Cart
│   ├── Cart Items
│   ├── Promo Code
│   ├── Order Summary
│   └── Checkout
└── Orders
    ├── Active Orders
    ├── Order History
    └── Order Detail
```

## Search Taxonomy

```
Product Categories (Level 1)
├── Mobile Top-Up
├── Internet Packages
├── Gift Cards
├── Digital Goods
│   ├── Game Credits
│   ├── Streaming
│   ├── Software
│   └── E-books
├── Bill Payment
└── Services

Product Attributes
├── Category
├── Vendor
├── Price Range
├── Rating
├── Delivery Type (Instant / Scheduled / Physical)
├── Language (for digital goods)
├── Region
└── Stock Status
```
