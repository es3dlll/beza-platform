# Open Finance Market Analysis

## Competitive Landscape (Syria/MENA 2026)

| Competitor | Type | Market Share | Key Weakness |
|------------|------|-------------|--------------|
| Syriatel Cash API | Telecom API | 20% | Limited to carrier billing |
| MTN MoMo API | Mobile Money API | 15% | Only mobile money |
| Local bank APIs (BBS, Bemo) | Banking APIs | 10% | Legacy protocols, slow |
| No local open banking platform | — | 0% | Gap in the market |

## Competitive Advantages
| Beza Advantage | Competitor Gap |
|---------------|---------------|
| Syria's first open finance API | No local competitor |
| Full platform (payments, wallets, FX) | Competitors offer single service |
| Sandbox with realistic test data | Most lack realistic sandbox |
| Arabic-first documentation + English | Most are English-only |
| NGO disbursement specialization | Underserved segment |
| Direct CFE integration | Competitors rely on banks |
| Competitive pricing (% of txn) | Banks charge fixed fees |
