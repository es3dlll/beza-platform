# Open Finance Portal UX/UI Specification

## Screen 1: Developer Console Dashboard

### Layout
```
┌────────────────────────────────────────────────────┐
│ Beza Developers                         [رحّاب] ⚙️ │
├────────────────────────────────────────────────────┤
│ مرحباً بك في منصة Beza للمطورين!                    │
│                                                    │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌────────┐ │
│ │ 150,000  │ │   2.3%   │ │   98ms   │ │  3     │ │
│ │ طلب اليوم│ │أخطاء (24س)│ │P99 متوسط │ │تطبيقات │ │
│ └──────────┘ └──────────┘ └──────────┘ └────────┘ │
│                                                    │
│ ┌──────────────────────────────────────────────┐   │
│ │  طلبات API — آخر 24 ساعة                      │   │
│ │  [Line Chart: requests per minute]            │   │
│ └──────────────────────────────────────────────┘   │
│                                                    │
│ ┌──────────────┐  ┌───────────────────────────┐    │
│ │ آخر الطلبات   │  │ حالة الخدمات               │    │
│ │ • POST pay.. │  │ Payment API    🟢 45ms    │    │
│ │ • GET /ba..  │  │ Account Info   🟢 32ms    │    │
│ │ • POST /we.. │  │ Webhooks       🟢 12ms    │    │
│ └──────────────┘  └───────────────────────────┘    │
└────────────────────────────────────────────────────┘
```

### States
| State | Behavior |
|-------|----------|
| Loading | Skeleton: stat cards shimmer, chart placeholder |
| Empty (new dev) | "أهلاً بك! ابدأ بإرسال أول طلب API" + Quick start CTA |
| Error | "فشل تحميل لوحة البيانات" + "إعادة المحاولة" |
| High error rate | Warning banner: "ارتفاع نسبة الأخطاء — راجع السجلات" |

## Screen 2: API Key Management

### Layout
```
┌────────────────────────────────────────────────────┐
│ <  مفاتيح API                         + إنشاء مفتاح │
├────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────┐   │
│ │ 🔑 مفتاح الإنتاج                             │   │
│ │ beza_live_abc123...xyz                       │   │
│ │ التاريخ: 2026-06-01  الانتهاء: 2027-06-01    │   │
│ │ الصلاحيات: payments.write, accounts.read     │   │
│ │ 🟢 نشط                    [تدوير] [إلغاء]    │   │
│ ├──────────────────────────────────────────────┤   │
│ │ 🔑 مفتاح الاختبار                            │   │
│ │ beza_test_def456...uvw                       │   │
│ │ التاريخ: 2026-06-01  بدون انتهاء             │   │
│ │ الصلاحيات: جميع الصلاحيات                     │   │
│ │ 🟢 نشط                    [تدوير] [إلغاء]    │   │
│ └──────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────┘
```

### Create Key Modal
```
┌────────────────────────────────────┐
│ إنشاء مفتاح API جديد               │
│                                    │
│ الاسم: [  تطبيق المتجر الإلكتروني  ]│
│                                    │
│ البيئة: ○ اختبار  ● إنتاج         │
│                                    │
│ الصلاحيات:                         │
│ ☑ payments.write    — إنشاء مدفوعات│
│ ☑ accounts.read     — قراءة الحسابات│
│ ☐ wallets.write     — إدارة المحافظ│
│ ☑ webhooks.read     — قراءة الإشعارات│
│                                    │
│ [إلغاء]              [إنشاء المفتاح]│
└────────────────────────────────────┘
```

### States
| State | Behavior |
|-------|----------|
| No keys | "ليس لديك أي مفاتيح بعد — أنشئ أول مفتاح" |
| Key exposed | Warning: "تم كشف المفتاح — قم بتدويره فوراً" |
| Expired key | Red badge: "منتهي الصلاحية" + renew option |
