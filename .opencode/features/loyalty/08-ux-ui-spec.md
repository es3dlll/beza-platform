# Loyalty UX/UI Specification

## Screen 1: Loyalty Hub

### Layout
```
┌────────────────────────────────┐
│ <  برنامج المكافآت        🔔   │ Header
├────────────────────────────────┤
│ ┌──────────────────────────┐   │ Points Card
│ │ 🏆 رصيد النقاط           │   │
│ │   15,000                 │   │ Large number
│ │   بقيمة 15,000 ل.س       │   │ SYP equivalent
│ │   اليوم: +50 نقطة        │   │ Daily activity
│ │ [صرف النقاط]             │   │ Primary CTA
│ └──────────────────────────┘   │
│                                │
│ ┌──────────────────────────┐   │ Tier Card
│ │ 🥈 فضي                   │   │ Tier name + icon
│ │ ████████████░░░░░░ 60%   │   │ Progress bar
│ │ 30,000 / 50,000          │   │ Progress to Gold
│ │ [فوائد المستوى]           │   │ Benefits link
│ └──────────────────────────┘   │
│                                │
│ المكافآت المميزة              │ Section header
│ ┌──────────────────────────┐   │
│ │ خصم رسوم تحويل           │   │
│ │ 5,000 نقطة ← 5,000 ل.س  │   │
│ ├──────────────────────────┤   │
│ │ رصيد هاتف SYRIATEL       │   │
│ │ 2,500 نقطة ← 2,500 ل.س  │   │
│ ├──────────────────────────┤   │
│ │ بطاقة هدايا بيمو         │   │
│ │ 10,000 نقطة ← 10,000 ل.س│   │
│ └──────────────────────────┘   │
│                                │
│ آخر النشاط                     │ Section
│ +25 نقطة  تحويل إلى أحمد   منذ 5 د   │ Green
│ +50 نقطة  دفع فاتورة كهرباء  │ Green
│ -5,000 نقطة  خصم رسوم تحويل  │ Red
└────────────────────────────────┘
```

### States
| State | Behavior |
|-------|----------|
| Loading | Skeleton: points shimmer, tier card skeleton |
| New user (no points) | "مرحباً بك! ابدأ بكسب النقاط بإرسال أو استلام الأموال" |
| Error | "فشل تحميل بيانات المكافآت" + retry |
| First points earned | Animated celebration + "لقد ربحت أول نقاطك!" |
