# 03 — User Stories

> Stories are written in English with Arabic user-facing titles.

---

## Company HR Manager

| ID | العربية | Story |
|----|---------|-------|
| US-01 | تسجيل الشركة | As an HR manager, I want to register my company with Beza Payroll so I can start paying salaries digitally. |
| US-02 | رفع قائمة الرواتب | As an HR manager, I want to upload a CSV salary sheet so that all employees are paid in one operation. |
| US-03 | جدولة الدفعة | As an HR manager, I want to schedule a payroll batch for a future date so it executes automatically. |
| US-04 | عرض سجل الدفعات | As an HR manager, I want to view all past batches so I can track payroll history. |
| US-05 | عرض تفاصيل الدفعة | As an HR manager, I want to see per-employee status within a batch so I can identify failures. |
| US-06 | إعادة المحاولة | As an HR manager, I want to retry failed employee payments individually so I don't re-run the whole batch. |
| US-07 | تنزيل كشوف الرواتب | As an HR manager, I want to download all payslips for a batch as a ZIP file. |
| US-08 | إدارة الموظفين | As an HR manager, I want to add/remove employees from the payroll roster so only active staff are paid. |

## CFO / Finance Manager

| ID | العربية | Story |
|----|---------|-------|
| US-09 | مراقبة الرصيد | As a CFO, I want to view my company's Beza balance so I know if funds are sufficient. |
| US-10 | إيداع الرصيد | As a CFO, I want to deposit funds into my payroll account so payroll can run. |
| US-11 | تسوية الدفعات | As a CFO, I want to see settlement reports so I can reconcile payroll with my ledger. |
| US-12 | تقارير التكاليف | As a CFO, I want a monthly cost report (salaries + fees) for accounting. |

## Employee

| ID | العربية | Story |
|----|---------|-------|
| US-13 | استلام الراتب | As an employee, I want to receive my salary directly in my Beza wallet so I don't need cash. |
| US-14 | عرض كشف الراتب | As an employee, I want to view and download my payslip so I have a record. |
| US-15 | عرض سجل الرواتب | As an employee, I want to see my full salary payment history. |
| US-16 | إشعار بالراتب | As an employee, I want an instant notification when my salary is credited. |

## Beza Admin

| ID | العربية | Story |
|----|---------|-------|
| US-17 | مراقبة المنصة | As a Beza admin, I want to monitor all batches across companies so I can detect issues. |
| US-18 | التدخل اليدوي | As a Beza admin, I want to manually intervene on stuck transactions so they can be resolved. |
| US-19 | إدارة الشركات | As a Beza admin, I want to approve/ suspend companies for compliance. |
