# Wallet Feature Vision

## Elevator Pitch
Beza Wallet is a multi-currency, programmable digital wallet that replaces cash for the everyday Syrian — enabling send, receive, pay bills, buy airtime, save, and borrow from a single account accessible via mobile app, USSD (*123#), or through any Beza Agent's POS terminal.

## Problem Statement
- 85%+ of Syrian economy runs on cash — unsafe, untraceable, inefficient
- No single app handles all financial needs (multiple apps for transfers, bills, airtime)
- Unbanked population cannot access digital financial services
- Syrian diaspora relies on expensive, slow, unreliable hawala channels

## Target Users
- **Primary**: Urban Syrians age 18-45 with smartphones (5M target)
- **Secondary**: Diaspora Syrians sending remittances (1M target)
- **Tertiary**: Semi-urban/rural users accessing via agent network (2M target)

## Core Capabilities
| Capability | Priority | Description |
|------------|----------|-------------|
| Multi-currency wallet | P0 | SYP + USD wallets per user |
| P2P transfer | P0 | Send money to any Beza user (phone number) |
| Wallet-to-bank | P1 | Withdraw to local bank accounts |
| Wallet-to-agent | P0 | Cash-out at any Beza Agent |
| Agent-to-wallet | P0 | Cash-in at any Beza Agent |
| Bill payment | P0 | Pay utilities, telecom, government fees |
| Airtime top-up | P0 | Buy prepaid mobile credit |
| Transaction history | P0 | Filterable, searchable, downloadable |
| Balance check | P0 | Real-time via app/USSD/agent |
| QR payments | P1 | Pay merchants via QR scan |
| Savings goals | P1 | Goal-based savings sub-accounts |
| Round-up savings | P2 | Auto-save spare change |
| Recurring transfers | P2 | Standing orders |
| Request money | P1 | Send payment request to contacts |
| Split bill | P2 | Split amount among multiple contacts |
| Transaction notes | P1 | Attach notes to transfers |
| Receipts | P0 | Digital receipt for every transaction |
| Statements | P1 | Monthly PDF statement |
| Card management | P1 | Virtual/physical prepaid card |
| Spending insights | P2 | Category-based spending breakdown |
