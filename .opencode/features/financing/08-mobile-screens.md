## Micro-interactions
| Action | Feedback |
|--------|----------|
| Tap "Apply" | Card lifts, brief haptic, loading spinner |
| Slide amount slider | Real-time installment preview updates |
| Auto-decision (success) | Celebration animation + confetti |
| Auto-decision (reject) | Soft vibration, clear reason display |
| Payment success | Green checkmark + "تم السداد" toast |
| Payment failed | Red X + error reason + retry button |
| Offer accepted | Contract animation (pages flipping) |
