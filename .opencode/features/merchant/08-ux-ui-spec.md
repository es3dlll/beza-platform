# Merchant UX/UI Specification

## Screen 1: Merchant Home / Dashboard

### Layout
```
┌────────────────────────────────┐
│ 📍 متجر الشمّام          🔔 ⚙️│ Header
├────────────────────────────────┤
│ ┌──────────────────────────┐   │
│ │ إجمالي مبيعات اليوم      │   │ Label
│ │    850,000 ل.س          │   │ Today's sales (large, 48pt)
│ │ ▲ 12% عن أمس            │   │ Trend vs yesterday
│ │ 12 معاملة               │   │ Transaction count
│ └──────────────────────────┘   │
├────────────────────────────────┤
│ [👁 عرض QR]  [🔗 رابط دفع]     │ Quick actions
│ [📊 التقارير]  [📋 المعاملات]  │
├────────────────────────────────┤
│ آخر المعاملات                  │
│ ┌──────────────────────────┐   │
│ │ 🟢 45,000 ل.س           │   │
│ │ 0912345678 — 10:30 ص     │   │ Customer phone + time
│ ├──────────────────────────┤   │
│ │ 🟢 22,500 ل.س           │   │
│ │ 0987654321 — 10:15 ص     │   │
│ ├──────────────────────────┤   │
│ │ 🟢 12,000 ل.س           │   │
│ │ 0911122233 — 09:45 ص     │   │
│ └──────────────────────────┘   │
├────────────────────────────────┤
│ التسوية                        │
│ [████████████░░░░░] 80%        │
│ التسوية القادمة: 23:59         │
│ صافي المتوقع: 837,250 ل.س      │
│ (مخصوم 1.5% رسوم: 12,750)     │
└────────────────────────────────┘
```

### States
| State | Behavior |
|-------|----------|
| Loading | Skeleton: sales card shimmer, 3x transaction skeleton rows |
| Empty (no sales) | "لم تستلم أي مدفوعات بعد — اعرض QR code لزبونك" with large QR button |
| Error | "حدث خطأ في تحميل البيانات" + "إعادة المحاولة" button |
| Offline | Banner: "أنت غير متصل — البيانات قديمة" + cached sales |
| High sales day | Confetti animation when daily sales exceed previous record |

## Screen 2: QR Code Display

### Layout
```
┌────────────────────────────────┐
│ <  QR Code                    │ Header
├────────────────────────────────┤
│ ┌──────────────────────────┐   │
│ │                          │   │
│ │    [Large QR Code]       │   │ 400x400px minimum
│ │    ██████████████        │   │
│ │    ██  ████  ██        │   │
│ │    ██  ████  ██        │   │
│ │    ██████████████        │   │
│ │                          │   │
│ └──────────────────────────┘   │
│ متجر الشمّام                   │ Business name
│ [Logo]                         │ Optional logo
├────────────────────────────────┤
│ 🔆 زيادة السطوع               │ Brightness boost (max brightness for 60s)
│ 📥 تحميل QR                    │ Download PNG
│ 🖨 طباعة                       │ Print (if connected to printer)
├────────────────────────────────┤
│ مقدار الدفع                    │ Payment amount section
│ ○ يحدده الزبون                 │ Customer enters amount (static QR)
│ ● مبلغ ثابت: [45,000] ل.س     │ Fixed amount (dynamic QR)
├────────────────────────────────┤
│ [مشاركة QR]                    │ Share via WhatsApp/SMS
└────────────────────────────────┘
```

### States
| State | Behavior |
|-------|----------|
| Brightness boost | Screen brightness to 100% for 60 seconds, then fade back |
| Downloaded | Toast: "تم تحميل QR بنجاح" |
| Shared | Opens share sheet with QR image + business name |
