# BEZA V4 — Documentation Operating System

## Architecture
```
Level 1 → docs/                     Vision, Product, Market, Strategy
Level 2 → features/{feature}/      30-file Feature Bibles
Level 3 → implementation/{layer}/  Engineering Specs
Level 4 → tasks/{discipline}/      Executable Work Items
Level 5 → tasks/ai/                AI Coding Blueprints
Level 6 → (generated at build)     Expected Source Structure
```

## Documentation OS Principles
1. **Product-first**: Every decision traces to product value
2. **System-first**: No feature exists in isolation
3. **AI-executable**: Docs structured for AI agent consumption
4. **Implementation-grade**: Senior engineers can build directly
5. **Perspective-complete**: Business + Product + UX + Frontend + Flutter + Backend + Infra + Financial + Compliance + Security + Monitoring + Testing + AI + Operations
