# Wallet User Personas

## Persona 1: Ahmad — Urban Professional
```
Age: 28
Occupation: Software developer in Damascus
Income: 500,000 SYP/month
Tech literacy: High
Smartphone: Yes (iPhone 12)
Banked: Yes (BBS account)
Pain points:
  - Carries cash for daily expenses (unsafe)
  - Pays bills at service centers (long queues)
  - Sends money to family in Aleppo (expensive agent fees)
  - Wants to track spending automatically
Needs:
  - Instant P2P transfers
  - Bill payment from app
  - Spending categorization
  - Card for online/retail purchases
  - No-fee cash-out
```

## Persona 2: Fatima — Small Business Owner
```
Age: 42
Occupation: Grocery store owner in Homs
Income: 1,000,000 SYP/month (irregular)
Tech literacy: Low
Smartphone: Yes (budget Android)
Banked: No (cash-only)
Pain points:
  - Hides cash at home/under mattress
  - Cannot pay suppliers digitally
  - Loses track of daily sales
  - Sends supplier payments through bus drivers
  - Wants to pay wholesalers digitally
Needs:
  - Agent cash-in (deposit daily sales)
  - P2P transfers to suppliers
  - Simple interface with Arabic
  - USSD backup when internet down
  - Transaction history printed at agent
```

## Persona 3: Khalid — Diaspora Remitter
```
Age: 35
Occupation: Taxi driver in Berlin
Income: €2,500/month
Tech literacy: Medium
Smartphone: Yes (Samsung Galaxy)
Banked: Yes (N26)
Pain points:
  - Sends €200-500/month to family in Damascus
  - Hawala charges 5-10% + slow (2-3 days)
  - Bank transfers are expensive (€15-25 per transfer)
  - No visibility on delivery status
Needs:
  - Low-cost remittance (target < 3%)
  - Instant delivery to family's wallet
  - USD or SYP delivery option
  - Delivery confirmation
  - Recurring monthly transfer
```
