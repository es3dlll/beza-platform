# Loyalty Market Analysis

## Competitive Landscape (Syria 2026)

### Direct Competitors
| Competitor | Type | Key Weakness |
|------------|------|-------------|
| Syriatel "Points Plus" | Telecom loyalty | Limited to airtime, telecom-only usage |
| MTN MoMo Rewards | Mobile money loyalty | Points only on MoMo transactions |
| Damascus Bank Rewards | Banking rewards | High minimum spend, limited catalog |
| Cash (no loyalty) | — | No rewards, switching cost is zero |

### Regional Programs (Benchmark)
| Program | Region | Notable Features |
|---------|--------|-----------------|
| Careem Rewards | MENA | Tiered with transport + food benefits |
| STC Pay Rewards | KSA | Points on all transactions, merchant offers |
| Vodafone Cash Rewards | Egypt | Cashback-style, tiered benefits |
| Noon.com Loyalty | UAE | Subscription-based (Noon VIP) |

## Competitive Advantages
| Beza Advantage | Competitor Gap |
|---------------|---------------|
| Multi-transaction earning (send, receive, bills, agents, savings) | Competitors limited to single transaction type |
| Real points with real value (not pseudo-points) | Many programs have confusing point values |
| Merchant loyalty campaigns built-in | Competitors offer no merchant tools |
| Points redeemable for fee discounts (immediate value) | Competitors redeem for external rewards only |
| Arabic-first loyalty experience | Most programs are English-then-Arabic |
| Tier system with tangible fee benefits | Competitors offer status without financial benefits |
| 12-month rolling window (forgiving) | Some programs use quarterly or shorter windows |

## Cultural Considerations
- Syrian users value tangible rewards (airtime, fee discounts) over abstract points
- Tier status carries social prestige ("Platinum customer")
- Arabic naming (برونز، فضي، ذهبي، بلاتيني) resonates with local identity
- Points = SYP direct equivalence is critical for trust
- Referral rewards leverage strong family/community ties
