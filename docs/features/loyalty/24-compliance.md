# Loyalty Compliance

## Points Liability Reporting

### Financial Reporting
```
Points Liability Recognition:
  - Points are recognized as liability when earned
  - Liability released when points are redeemed or expired
  - Monthly accrual journal entry
  - Quarterly audit of points liability vs unredeemed balance

Regulatory Treatment:
  - Points value ≤ 1 year: Current Liability
  - Points value > 1 year: Long-term Liability
  - All points expire in 12 months → Current Liability only
```

## Loyalty Program Rules (Syria-Specific)
```
Central Bank Considerations:
  - Points are not "currency" — no monetary value exchange
  - Points have no cash-out option (cannot convert to cash)
  - Points are promotional rewards, not financial instruments
  - Tier benefits are fee discounts, not interest payments

Consumer Protection:
  - Points expiry must be clearly communicated
  - Users notified 30 days before points expiry
  - Tier downgrade notified 30 days in advance (grace period)
  - Redemption terms clear and transparent
```

## Anti-Money Laundering (AML) for Points
```
Rule LOY-AML-1: Points Structuring
  - Multiple small redemptions approaching reporting threshold
  - Action: Flag for review

Rule LOY-AML-2: Points Transfer Between Accounts
  - Points are non-transferable (earned by user only)
  - Attempted transfer = policy violation
  - Action: Flag both accounts

Rule LOY-AML-3: Synthetic Identity via Referrals
  - Multiple accounts with same device/IP claiming referral points
  - Action: Flag, deny bonus, investigate

Rule LOY-AML-4: Merchant Campaign Laundering
  - Merchant creates campaign → "sells" bonus points to users
  - Action: Flag as potential value transfer
```
