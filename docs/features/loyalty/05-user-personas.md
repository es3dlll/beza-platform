# Loyalty User Personas

## Persona 1: Ahmad — Heavy Transaction User
```
Age: 28
Occupation: Software developer in Damascus
Income: 500,000 SYP/month
Transactions/month: 30+ (send, bills, airtime, savings)
Current points: ~15,000 (Silver tier)
Pain points:
  - Pays 0.5% on every transfer (2,500 SYP/month in fees)
  - Wants to reduce fees through higher tier
  - Doesn't know about loyalty program benefits
Needs:
  - Clear visibility on points balance and tier progress
  - Understanding of tier upgrade path to Gold
  - Automatic fee discounts based on tier
  - Points redemption for airtime (buys 50K SYP/month)
  - Push notifications for tier milestones
```

## Persona 2: Fatima — Small Business Owner
```
Age: 42
Occupation: Grocery store owner in Homs
Transactions/month: 100+ (receives payments, cash-in, cash-out)
Current points: ~45,000 (near Gold!)
Pain points:
  - High cash-out fees (1.5% = 15,000 SYP/month)
  - Wants to become Gold tier for fee reduction
  - Doesn't understand how tier works
Needs:
  - Simple Arabic progress bar to Gold
  - Daily tips: "أنت على بعد 5,000 نقطة من الذهبي!"
  - Know fee savings at next tier: "ستوفر 5,000 ل.س شهرياً"
  - Merchant campaign tools for her own customers
  - SMS notifications (not app-only)
```

## Persona 3: Khalid — Diaspora Remitter
```
Age: 35
Occupation: Taxi driver in Berlin
Transactions/month: 2 remittances × €300 each
Current points: ~6,000 (Bronze, near Silver)
Pain points:
  - Sends money to family monthly but doesn't earn enough
  - Points too low for meaningful redemption
  - Wants referral bonus (sends to many diaspora friends)
Needs:
  - Refer a friend: 5,000 bonus points
  - Send larger amounts to earn more points
  - USD-denominated points (or clear SYP value)
  - Redeem points for fee discount on next remittance
  - Share tier status with recipient family
```

## Persona 4: Hassan — Merchant (Campaign Owner)
```
Age: 39
Occupation: Electronics shop owner in Aleppo
Target: Wants to reward loyal customers with points
Pain points:
  - No way to differentiate from competitors
  - Wants customers to choose his shop over others
  - Current loyalty: manual punch cards (easily lost)
  - Cannot afford traditional loyalty program
Needs:
  - Create campaign: "2x points on purchases over 50K SYP"
  - Fund reward pool (deposit points or SYP)
  - Track campaign performance (redemptions, uplift)
  - Customer segment targeting (repeat buyers)
  - Simple setup (5 min, no coding)
```
