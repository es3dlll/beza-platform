# Loyalty Feature Vision

## Elevator Pitch
Beza Loyalty Program rewards users for every transaction on the platform — sending, receiving, paying bills, using agents, and saving. Users earn points that unlock discounts, airtime, gift cards, and partner offers through a tiered system (Bronze → Silver → Gold → Platinum) with escalating benefits.

## Problem Statement
- Users have no incentive to consolidate financial activity on Beza
- Transaction fees create friction without perceived value
- No loyalty competition in Syrian digital financial services
- Merchants lack tools to run their own customer loyalty campaigns
- High churn risk without engagement and retention mechanisms

## Target Users
- **Primary**: All Beza wallet users earning points through transactions
- **Secondary**: Heavy transactors (merchants, frequent senders, bill payers)
- **Tertiary**: Merchants running their own loyalty campaigns
- **Quaternary**: Partner businesses offering rewards

## Core Capabilities
| Capability | Priority | Description |
|------------|----------|-------------|
| Points earning | P0 | Earn 1 point per 1,000 SYP transacted |
| Tier system | P0 | Bronze → Silver → Gold → Platinum |
| Reward catalog | P0 | Fee discounts, airtime, gift cards, partner offers |
| Points redemption | P0 | Redeem points for rewards in catalog |
| Points history | P0 | Full audit trail of earnings and redemptions |
| Tier benefits | P0 | Lower fees, higher limits, priority support per tier |
| Merchant campaigns | P1 | Merchants create custom loyalty campaigns |
| Points expiry | P1 | 12-month rolling expiry policy |
| Referral bonuses | P1 | Bonus points for referring new users |
| Anniversary rewards | P2 | Annual bonus based on tier |
| Tier downgrade warning | P1 | Notification before downgrade due to inactivity |
