# المسرد — Glossary

## Arabic Terms
| Term | Explanation |
|------|-------------|
| قرض حسن (Qard Hasan) | A benevolent, interest-free loan where only the principal is repaid |
| مرابحة (Murabaha) | Cost-plus financing: seller discloses cost and profit margin |
| ربا (Riba) | Interest/usury — strictly prohibited in Islamic finance |
| غرر (Gharar) | Excessive uncertainty or ambiguity in contracts |
| صدقة (Sadaqah) | Voluntary charity — destination for late fees |
| فتوى (Fatwa) | Islamic legal ruling issued by qualified scholars |
| عقد (Aqd) | Contract — the legal agreement between parties |
| تمويل (Tamweel) | Financing / funding |
| ضامن (Dhamin) | Guarantor — person who guarantees repayment |
| قسط (Qist) | Installment |
| رأس المال (Ra's al-Mal) | Principal / capital amount |
| ربح (Ribh) | Profit — the disclosed markup in Murabaha |
| إعادة جدولة (I'adat Jadwala) | Restructuring of payment schedule |
| متعثر (Muta'athir) | Defaulted / non-performing |
| موافقة (Muwafaqa) | Approval |
| مبلغ (Mablagh) | Amount |

## English Terms
| Term | Definition |
|------|------------|
| Alternative Credit Scoring | Credit assessment using non-traditional data (wallet history, transactions) |
| Cash Flow Analysis | Evaluation of business income and expenses for Micro-Enterprise financing |
| Collection Queue | Prioritized list of overdue accounts requiring collection action |
| Credit Score | Numerical rating (300-850) representing creditworthiness |
| Deferred Profit | Profit recognized over time as installments are paid |
| Disbursement | Transfer of funds to borrower or merchant |
| Down Payment | Initial payment made by borrower (Murabaha) |
| Installment | Scheduled periodic payment |
| Late Fee | Penalty for overdue payment (redirected to charity) |
| Non-Performing Loan (NPL) | Loan that is 90+ days overdue |
| Offer Acceptance | User's digital signature agreeing to financing terms |
| Portfolio at Risk (PAR) | Percentage of portfolio with overdue payments |
| Provisioning | Setting aside funds for expected loan losses |
| Restructuring | Modifying loan terms to avoid default |
| Underwriting | Risk assessment process for loan approval |

## Contract Number Format
```
BZ-{PRODUCT}-{YEAR}-{SEQUENTIAL_5DIGIT}
Example: BZ-QH-2026-00001
```

## Status Codes
| Status | Arabic | Meaning |
|--------|--------|---------|
| draft | مسودة | Application not yet submitted |
| submitted | قيد المراجعة | Application received, pending scoring |
| underwriting | تحت التقييم | Credit assessment in progress |
| approved | تمت الموافقة | Approved, waiting for user to accept offer |
| rejected | مرفوض | Application declined |
| offer_accepted | تم القبول | User accepted the offer, awaiting disbursement |
| disbursed | تم الصرف | Funds transferred |
| active | نشط | Contract active, payments in progress |
| completed | مكتمل | All payments made, contract fulfilled |
| defaulted | متعثر | 90+ days overdue, non-performing |
| restructured | معاد جدولته | Terms modified to avoid default |
