# Savings Feature Vision

## Elevator Pitch
Beza Savings empowers Syrians to achieve their financial goals — a new phone, a wedding, an education fund — through automated, goal-based savings with profit sharing. No interest, no riba. Save individually or as a team. Every spare pound counts.

## Problem Statement
- Most Syrians lack access to formal savings instruments — banks are distrusted or inaccessible
- Cash savings under the mattress earn nothing and are vulnerable to theft, loss, inflation
- No structured tools exist to help users save consistently toward specific goals
- Manual saving is hard: users forget, get tempted to spend, lose discipline
- Social/group saving (jameyaat) is informal, undocumented, and risky
- Savings held in bank accounts earn interest (riba) which is impermissible for observant Muslims

## Target Users
- **Primary**: Urban Syrians age 18–45 with Beza wallets who want to save for goals
- **Secondary**: Families saving collectively for household goals (school fees, home repairs)
- **Tertiary**: Informal jameyaat groups who want a digital, documented, Sharia-compliant alternative

## Core Capabilities
| Capability | Priority | Description |
|------------|----------|-------------|
| Goal creation | P0 | Create named savings goals with target amount and date |
| Goal-based sub-wallets | P0 | Each goal gets a dedicated CFE sub-account |
| Auto-save (daily/weekly) | P0 | Automate recurring deposits from main wallet |
| Round-up spare change | P1 | Round transaction amounts to nearest 1,000 SYP, save difference |
| Manual deposit | P0 | One-time deposits to any goal |
| Partial/full withdrawal | P0 | Withdraw savings (with potential early-withdrawal penalty) |
| Goal lock period | P1 | Lock savings until target date or amount |
| Profit sharing | P1 | Periodic profit distribution (Qard Hasan, no riba) |
| Progress tracking | P0 | Visual progress bars, projections, nudges |
| Team goals | P1 | Group savings with invite codes and contribution tracking |
| Milestone celebrations | P2 | Push notification and animation on goal milestones |
| Goal completion | P0 | Release savings when target reached and lock period ends |
