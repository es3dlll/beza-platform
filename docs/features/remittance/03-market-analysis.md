# Remittance Market Analysis

## Competitive Landscape (Syria Remittance 2026)

### Direct Competitors
| Competitor | Type | Market Share | Key Weakness |
|------------|------|-------------|--------------|
| Informal Hawala | P2P cash transfer | 65% of diaspora flows | 5-10% fee, 2-3 days, no tracking, unregulated |
| Western Union / MoneyGram | Formal remittance | 15% | 7-12% fee, slow, requires government ID, branch access |
| Banks (wire transfer) | Bank-to-bank | 10% | $15-25 flat fee, 3-5 days, both sides need bank account |
| Syriatel Cash / MTN MoMo | Mobile money | 5% | Telecom-locked, no diaspora onboarding, SYP only |
| Crypto (USDT P2P) | Crypto | 5% | Volatility risk, tech barrier, regulatory uncertainty |

### Indirect Competitors
| Competitor | Type | Threat Level |
|------------|------|-------------|
| Exchange houses (Al-Maghrib, Al-Haram) | FX + remittance | Medium — trusted diaspora brands |
| Gold purchases for family | Value transfer | Low — impractical, high spread |
| Travelers carrying cash | Physical courier | Medium — trust-based, risky |

## Competitive Advantages
| Beza Advantage | Competitor Gap |
|---------------|---------------|
| < 3% all-in fee (FX + fee) | Hawala 5-10%, Western Union 7-12% |
| Instant delivery to wallet | Hawala 2-3 days, banks 3-5 days |
| Multi-currency (SYP, USD, EUR) | All competitors single-currency SYP |
| Real-time tracking (push + app) | Hawala: zero visibility |
| Recurring transfers with FX lock | No competitor offers automated recurring |
| Recipient doesn't need bank or smartphone | Banks require bank account; WU requires ID |
| Arabic-first UX with diaspora language support | Competitors are English/European-first |
| AI-powered fraud + AML screening | Hawala: zero compliance; WU: basic |
| Beneficiary management (save recipients) | Manual each time with competitors |
| Same-currency USD→USD retention | WU/banks force conversion to SYP |
