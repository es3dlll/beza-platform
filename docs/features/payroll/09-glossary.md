# 09 — Glossary

| English Term | العربية | Definition |
|-------------|---------|------------|
| Batch | الدفعة | A single payroll run processing salaries for multiple employees |
| Batch hold | تجميد الدفعة | Temporary reservation of funds in company account during processing |
| Beza Wallet | محفظة بيزة | Employee's digital wallet where salary is credited |
| Company payroll account | حساب الرواتب | Virtual ledger account tracking company's payroll balance |
| CFE (Core Financial Engine) | المحرك المالي الأساسي | Beza's transaction processing engine handling holds, debits, credits |
| CSV template | قالب CSV | Standardized spreadsheet format for salary data upload |
| Disbursement | صرف | The act of distributing salary payments |
| Employee roster | قائمة الموظفين | Company's registered list of employees with salary details |
| Failed transaction | معاملة فاشلة | A single employee payment that could not be processed |
| Fee | رسوم | Service charge (e.g., 0.5 % of batch amount) |
| Hold | تجميد | Temporary earmarking of funds before final settlement |
| KYC | اعرف عميلك | Know Your Customer — identity verification process |
| Payroll account | حساب الرواتب | Company's dedicated balance for salary payments |
| Payslip | كشف الراتب | Itemized document showing salary breakdown |
| Reconciliation | التسوية | Process of matching payroll records with financial transactions |
| Retry | إعادة محاولة | Automatic or manual reattempt of a failed transaction |
| Settlement | التسوية النهائية | Final transfer of funds from company to Beza (T+0, T+1, etc.) |
| T+1 | T+1 | Settlement one business day after batch processing |
| Wallet activation | تفعيل المحفظة | Employee's first login to set up Beza account |
| Write-off | شطب | Permanently marking a failed transaction as irrecoverable |
