# Agent Network Business Case

## Revenue Model
| Revenue Stream | Calculation Model | Margin | Y3 Annual Revenue |
|---------------|-------------------|--------|-------------------|
| Agent Cash-in Commission | 0.5% of txn volume (paid by Beza to agent) | N/A (cost) | -$4M |
| Agent Cash-out Commission | 0.75% of txn volume (paid by Beza to agent) | N/A (cost) | -$6M |
| User Cash-in Fee | 0% (free to drive adoption) | N/A | $0 |
| User Cash-out Fee | 1.5% of amount (paid by user) | 60% | $6M |

| Agent Premium Tier Fee | 25,000 SYP/month (Gold+ tiers) | 90% | $1.2M |

| Agent Data/Analytics API | Usage-based pricing for partners | 90% | $300K |
