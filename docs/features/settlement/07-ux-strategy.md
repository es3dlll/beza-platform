# Settlement UX Strategy

## Design Principles
1. **Operations-first**: Settlement is a back-office tool — clarity over beauty
2. **Exception-dominant**: Surface what needs attention, hide what's normal
3. **Progressive disclosure**: Summary first, detail on demand
4. **Arabic RTL by default**: Full Arabic interface with English option

## Notification Strategy
| Event | Channel | Priority | Language |
|-------|---------|----------|----------|
| Batch created | Dashboard toast | Info | Arabic |
| Batch processing | Dashboard + email | Info | Arabic |
| Batch completed | Dashboard + email | Info | Arabic |
| Batch on hold | Dashboard + email + SMS | High | Arabic |
| Exception created | Dashboard | Medium | Arabic |
| Exception resolved | Dashboard | Low | Arabic |
| Reconciliation mismatch | Dashboard + email | High | Arabic |
| Bank confirmation timeout | Dashboard + email + SMS | Critical | Arabic |
