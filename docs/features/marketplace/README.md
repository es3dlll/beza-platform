# Marketplace Feature

> **⚠️ DEFERRED — V4+ (24+ Months from Launch)**
>
> See ADR-007 for full rationale. Marketplace requires network effects from V2/V3 merchant density and user base.
>
> **Conditions for Revisit:**
> 1. 100,000+ active wallets
> 2. 5,000+ active merchants
> 3. Daily transaction volume > 500M SYP
> 4. Dedicated marketplace team available
>
> **No pre-work or sprint integration in V1-V3.**
