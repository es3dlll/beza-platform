# User Stories

## Epic 1: Mobile Top-Up
- US1.1: As a user, I want to top up my own phone number so that I don't run out of credit
- US1.2: As a user, I want to top up a family member's phone so that they stay connected
- US1.3: As a user, I want to select from preset amounts so that I don't have to type a number
- US1.4: As a user, I want my top-up to be instant so that I can use it immediately
- US1.5: As a user, I want to see a confirmation when my top-up is successful
- US1.6: As a user, I want to set up auto top-up so I never run out of balance
- US1.7: As a user, I want to see my top-up history so I can track my spending
- US1.8: As a user, I want to save favorite numbers so I can top up quickly

## Epic 2: Digital Goods Purchase
- US2.1: As a user, I want to browse digital goods by category so I can find what I need
- US2.2: As a user, I want to compare prices from different vendors before buying
- US2.3: As a user, I want to see vendor ratings so I can trust the seller
- US2.4: As a user, I want instant delivery of game codes and subscription vouchers
- US2.5: As a user, I want to request a refund if a code doesn't work
- US2.6: As a user, I want to receive purchase receipts in my email

## Epic 3: Gift Cards
- US3.1: As a user, I want to buy gift cards for popular merchants so I can gift easily
- US3.2: As a user, I want to send gift cards via WhatsApp so the recipient gets it instantly
- US3.3: As a user, I want to personalize gift cards with a message
- US3.4: As a user, I want to check my gift card balance and expiry date
- US3.5: As a user, I want to redeem a gift card to my wallet or at the merchant

## Epic 4: Cart & Checkout
- US4.1: As a user, I want to add multiple items to a cart and checkout once
- US4.2: As a user, I want to apply a promo code for a discount
- US4.3: As a user, I want to see a clear order summary before paying
- US4.4: As a user, I want my wallet to be charged only after successful delivery

## Epic 5: Orders & History
- US5.1: As a user, I want to view all my past orders in one place
- US5.2: As a user, I want to check the status of a current order
- US5.3: As a user, I want to cancel an order before it's fulfilled
- US5.4: As a user, I want to re-order items I've bought before

## Epic 6: Vendor Management
- US6.1: As a vendor, I want to create product listings with images and descriptions
- US6.2: As a vendor, I want to manage inventory through bulk CSV upload
- US6.3: As a vendor, I want to receive real-time order notifications
- US6.4: As a vendor, I want to fulfill orders manually for non-integrated products
- US6.5: As a vendor, I want to see my commission earnings and payout schedule
- US6.6: As a vendor, I want to withdraw my earnings to my bank account or wallet

## Epic 7: Admin Operations
- US7.1: As an admin, I want to approve or reject vendor applications
- US7.2: As an admin, I want to moderate product listings before they go live
- US7.3: As an admin, I want to set and adjust commission rates per category
- US7.4: As an admin, I want to resolve disputes between buyers and vendors
- US7.5: As an admin, I want to view marketplace analytics and financial reports
