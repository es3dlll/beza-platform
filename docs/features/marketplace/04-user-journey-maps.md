# User Journey Maps

## Journey 1: Mobile Top-Up (Layla)

| Step | Action | Touchpoint | Emotion | System |
|---|---|---|---|---|
| 1 | Opens Beza app | Home screen | Neutral | App launch |
| 2 | Taps "Mobile Top-Up" | Marketplace tile | Intentful | Navigate to top-up |
| 3 | Selects network (Syriatel) | Network selector | Focused | Pre-selects from last used |
| 4 | Enters phone number (0933-xxx-xxx) | Number input | Routine | Validates number format |
| 5 | Selects amount (1,000 / 2,500 / 5,000 / 10,000 SYP) | Amount picker | Decisive | Fetches current commission |
| 6 | Confirms payment from Beza wallet | Confirmation screen | Slightly anxious | Checks wallet balance |
| 7 | Receives success notification | Push notification | Satisfied | API call to Syriatel |
| 8 | Sees updated balance on phone | SMS from Syriatel | Happy | Delivery confirmed |

**Friction Point**: Step 6 — if wallet balance is insufficient, user must top up wallet first.

## Journey 2: Digital Goods Purchase (Omar)

| Step | Action | Touchpoint | Emotion | System |
|---|---|---|---|---|
| 1 | Opens Marketplace tab | Bottom navigation | Curious | Loads categories |
| 2 | Searches "PUBG UC" | Search bar | Eager | Full-text product search |
| 3 | Browses vendor offers | Product listing | Comparing | Sorts by price/reliability |
| 4 | Selects "600 UC + 60 Bonus" at 28,000 SYP | Product detail | Confident | Shows vendor rating |
| 5 | Adds to cart | Cart button | Casual | Cart updated |
| 6 | Proceeds to checkout | Cart screen | Ready | Calculates total |
| 7 | Confirms payment | Payment screen | Trusting | Places hold on wallet |
| 8 | Receives activation code | In-app + SMS | Excited | Fulfillment delivers code |
| 9 | Redeems code in PUBG | External app | Joyful | Purchase completed |

**Friction Point**: Step 8 — if vendor is out of stock, fallback to refund.

## Journey 3: Gift Card Purchase & Send (Rania)

| Step | Action | Touchpoint | Emotion | System |
|---|---|---|---|---|
| 1 | Taps "Gift Cards" from marketplace | Category tile | Curious | Lists merchants |
| 2 | Selects a merchant | Merchant grid | Exploring | Shows denominations |
| 3 | Picks 25,000 SYP denomination | Amount selector | Decided | Shows preview |
| 4 | Chooses "Send via WhatsApp" | Delivery method | Thoughtful | Recipient input |
| 5 | Enters recipient's phone number | Recipient form | Warm | Validates number |
| 6 | Personalizes message (optional) | Message field | Caring | Stores message |
| 7 | Pays from wallet | Payment | Generous | Deducts wallet balance |
| 8 | Recipient receives gift card link | WhatsApp message | Happy (sender) | SMS + WhatsApp sent |
| 9 | Recipient opens link, saves card to wallet | Recipient app | Grateful | Card stored in profile |

**Friction Point**: Step 8 — if recipient does not have Beza, they are prompted to install.

## Journey 4: Vendor Onboarding (Khalid)

| Step | Action | Touchpoint | Emotion | System |
|---|---|---|---|---|
| 1 | Visits beza.sy/vendors | Website | Curious | Landing page |
| 2 | Clicks "Become a Vendor" | CTA button | Motivated | Application form |
| 3 | Fills business details | Form | Careful | Validates inputs |
| 4 | Uploads business license | File upload | Neutral | Scans for verification |
| 5 | Submits application | Submit button | Hopeful | Enters review queue |
| 6 | Receives approval (1–3 business days) | Email notification | Relieved | Admin approval |
| 7 | Logs into vendor dashboard | Vendor portal | Ready | Onboarding checklist |
| 8 | Creates first product listing | Product form | Focused | Enters moderation |
| 9 | First sale comes through | Notification | Thrilled | Commission logged |

**Friction Point**: Step 6 — approval SLA is critical; delays cause vendor drop-off.
