# 19 - حالات الحافة + سيناريوهات خطأ (Edge Cases)

## 1. تكرار حدث User::created

**المشكلة**: انطلاق الحدث أكثر من مرة لنفس المستخدم (خطأ في الكود أو DB callback).

**الحل**: التحقق من `$user->wallets()->exists()` قبل الإنشاء + UNIQUE(user_id, currency).

## 2. فشل إنشاء محفظة SYP مع نجاح USD

**المشكلة**: خطأ في قاعدة البيانات يمنع إنشاء إحدى المحافظ.

**الحل**: إذا فشل أحد الإنشاءين، يفشل الطلب بالكامل. المستخدم سيعيد المحاولة.

## 3. المستخدم غير نشط (status = pending/suspended)

**المشكلة**: إنشاء محفظة لمستخدم غير مفعل.

**الحل**: التحقق من `$user->status === 'active'` قبل الإنشاء.

## 4. duplicate wallet_number

**المشكلة**: احتمال تصادم أرقام المحافظ (نادر لكن وارد).

**الحل**: `generateWalletNumber()` يستخدم `while (Wallet::where(...)->exists())`.

## 5. المستخدم لديه محافظ مسبقاً (إعادة التسجيل)

**المشكلة**: مستخدم قديم لديه محافظ ويحاول التسجيل مرة أخرى.

**الحل**: التحقق المسبق + UNIQUE constraint يمنع إنشاء محفظتين بنفس العملة.

## 6. فشل إيداع الهدية (5$)

**المشكلة**: إنشاء المحفظة USD بنجاح لكن فشل إيداع الـ 5$.

**الحل**: DB::transaction يضمن Atomicity — إما الهدية كاملة أو ROLLBACK.

## 7. محاولة إنشاء محفظة يدوياً (API غير موجود)

**المشكلة**: محاولة استدعاء API غير موجود لإنشاء محفظة إضافية.

**الحل**: لا يوجد API — المحفظة تُنشأ تلقائياً فقط. يجب استخدام Seeder للإصلاح.

## 8. مبلغ هدية غير صحيح

**المشكلة**: تغيير قيمة الهدية يجب أن يكون عبر config.

```php
// config/beza.php
return [
    'signup_bonus' => env('SIGNUP_BONUS_AMOUNT', 5.00),
];
```

## 9. ربط المستخدم بمحفظة خاطئة

**المشكلة**: user_id خاطئ في المحفظة.

**الحل**: `Wallet::create(['user_id' => $user->id])` يأخذ user_id من $user مباشرة.

## 10. حذف المستخدم (Soft Delete)

**المشكلة**: حذف المستخدم يؤدي إلى حذف المحافظ.

**الحل**: `onDelete('cascade')` في الميغريشن يحذف المحافظ تلقائياً.

## 11. تعدد العملات مستقبلاً

**المشكلة**: إضافة عملة ثالثة (EUR).

**الحل**: إضافة العملة إلى `enum` وإنشاء محفظة إضافية في الـ Listener.

## 12. مستخدم مسجل لكن المحفظة لم تُنشأ

**المشكلة**: خطأ غير متوقع أوقف إنشاء المحفظة.

**الحل**: Job مخصص يعيد المحاولة:

```php
// php artisan make:job RetryWalletCreation
public function handle(): void
{
    User::whereDoesntHave('wallets')
        ->where('status', 'active')
        ->each(function (User $user) {
            app(CreateWalletService::class)->createWallets($user);
        });
}
```
