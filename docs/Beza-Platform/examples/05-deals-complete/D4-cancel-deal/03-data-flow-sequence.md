## جدول زمني لتنفيذ العملية

| الخطوة | الزمن المستغرق |
|--------|---------------|
| Network Request | ~30ms |
| Middleware | ~10ms |
| DB Transaction (100 مستثمر) | ~300ms |
| Response | ~10ms |
| **المجموع** | **~350ms** |
