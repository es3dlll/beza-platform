## جدول زمني لتنفيذ العملية

| الخطوة | الزمن المستغرق |
|--------|---------------|
| Network Request | ~30ms |
| Middleware | ~10ms |
| حساب الأرباح (100 مستثمر) | ~50ms |
| DB Transaction (100 عملية) | ~300ms |
| Response | ~10ms |
| **المجموع** | **~400ms** |
