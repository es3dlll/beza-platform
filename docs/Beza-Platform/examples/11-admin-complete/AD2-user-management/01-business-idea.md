# 01 - فكرة إدارة المستخدمين (Business Idea)

## الفكرة الأساسية

المشرف "خالد" يحتاج إلى إدارة جميع مستخدمي المنصة:
1. **عرض القائمة** — مع pagination وبحث وفلترة
2. **عرض التفاصيل** — معلومات المستخدم + محافظه + معاملاته
3. **التحكم بالحالة** — تعليق، تفعيل، حظر
4. **حذف** — حذف ناعم (soft delete) مع الاحتفاظ بالمعاملات
5. **عرض المعاملات** — سجل معاملات المستخدم

## سيناريو المستخدم (User Story)

```
بصفتي: مشرف منصة Beza
أريد: إدارة جميع المستخدمين وصلاحياتهم
لكي: أضمن أمان المنصة والتزام المستخدمين بالقوانين
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | عرض قائمة المستخدمين مع pagination | اختياري 10-50 لكل صفحة |
| 2 | بحث برقم الهاتف أو الاسم أو البريد | search parameter |
| 3 | فلترة حسب الحالة (active/suspended/blocked) | status filter |
| 4 | فلترة حسب KYC | kyc_status filter |
| 5 | عرض تفاصيل مستخدم | id endpoint |
| 6 | تعليق مستخدم → يمنع تسجيل الدخول | suspend |
| 7 | تفعيل مستخدم | activate |
| 8 | حظر مستخدم | block |
| 9 | لا يمكن حظر/حذف المشرفين | business rule |
| 10 | لا يمكن للمشرف حذف نفسه | self-delete protection |
