# 19 - حالات الحافة (Edge Cases)

## 1. مستخدم غير موجود (404)
**المشكلة**: محاولة عرض/تعديل مستخدم محذوف أو غير موجود.
**الحل**: `UserNotFoundException` ← 404.

## 2. محاولة تعليق مشرف
**المشكلة**: مشرف يحاول تعليق مشرف آخر.
**الحل**: التحقق من `is_admin` قبل التعليق.

## 3. محاولة حذف الذات
**المشكلة**: مشرف يحذف حسابه الخاص.
**الحل**: التحقق من `id !== adminId` قبل الحذف.

## 4. تعليق مستخدم معلق أصلاً
**المشكلة**: إرسال طلب تعليق لمستخدم معلق.
**الحل**: التحقق من الحالة الحالية ← تجاهل أو إرجاع خطأ.

## 5. بحث بدون نتائج
**المشكلة**: لا يوجد مستخدمون يطابقون البحث.
**الحل**: إرجاع مصفوفة [] فارغة مع meta = 0.

## 6. Soft Delete مع معاملات قديمة
**المشكلة**: المستخدم محذوف لكن معاملاته باقية مع `SET NULL`.
**الحل**: عرض "مستخدم محذوف" في معاملاته السابقة.

## 7. إبطال التوكنات بعد التعليق
**المشكلة**: المستخدم مسجل الدخول قبل التعليق.
**الحل**: `$user->tokens()->delete()` يمنع وصوله فوراً.

## 8. عدد كبير من المستخدمين
**المشكلة**: 100,000+ مستخدم — تحميل القائمة بطيء.
**الحل**: Pagination إجباري + Indexes على حقول الفلترة.

## جدول ملخص

| # | الحالة | النتيجة | الحل |
|---|--------|---------|------|
| 1 | مستخدم غير موجود | 404 | Exception |
| 2 | تعليق مشرف | 422 | is_admin check |
| 3 | حذف الذات | 422 | id !== adminId |
| 4 | تعليق معلق | 422/Skip | Status check |
| 5 | بحث فارغ | 200 [] | Empty array |
| 6 | مستخدم محذوف+معاملات | عرض "محذوف" | Soft delete |
