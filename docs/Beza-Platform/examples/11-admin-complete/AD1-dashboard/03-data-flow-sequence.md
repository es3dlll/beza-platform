## جدول زمني لتنفيذ العملية

| الخطوة | الزمن المستغرق | ملاحظة |
|--------|---------------|--------|
| Cache Check | ~5ms | Redis GET |
| DB Queries (بدون Cache) | ~200ms | 5-7 استعلامات |
| Response Serialization | ~20ms | JSON |
| **مع Cache** | **~25ms** | استجابة فورية |
| **بدون Cache** | **~220ms** | كل 5 دقائق |
