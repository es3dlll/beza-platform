# 14 - ACID للوحة التحكم

لوحة التحكم هي عملية **قراءة فقط** (Read-only). لا تحتاج إلى ACID transactions لأنها لا تكتب بيانات. لكن دقة البيانات مهمة.

## مشكلة الـ Dirty Read

إذا كانت لوحة التحكم تقرأ بينما معاملة مالية قيد التنفيذ:

```
Time |  معاملة مالية                      |  لوحة التحكم
-----|------------------------------------|-----------------------------
T1   |  BEGIN                             |
T2   |  خصم 100 من المحفظة A              |
T3   |                                     |  SELECT SUM(balance) ← 100 أقل!
T4   |  إضافة 100 للمحفظة B               |
T5   |  COMMIT                            |
```

**النتيجة**: لوحة التحكم ترى رصيداً ناقصاً 100 (المجموع الإجمالي غير متوازن).

**الحل**: قراءة البيانات بعد اكتمال المعاملات + استخدام Cache.

## ضمان الدقة

```php
// قراءة باستخدام READ COMMITTED (افتراضي InnoDB)
// يضمن أننا نقرأ فقط البيانات الملتزمة (committed)

DB::statement('SET SESSION TRANSACTION ISOLATION LEVEL READ COMMITTED');

$stats = $this->generateStats($period);
```

## استخدام Cache مع TTL مناسب

```
المعاملات الحية:  ───┐                      ┌───  تحديث Cache
                     ▼                      ▼
              ┌──────────────────────────────────────┐
              │          Cache (5 دقائق)              │
              │  البيانات شبه الحية (قراءة فقط)       │
              └──────────────────────────────────────┘
```

## استراتيجية العزل

| المستوى | الاستخدام | التأثير |
|---------|-----------|---------|
| READ COMMITTED | لوحة التحكم | يمنع Dirty Read |
| REPEATABLE READ | الافتراضي | يضمن تناسق القراءة |
| SERIALIZABLE | غير مستخدم | أداء منخفض جداً |

## تحديد Cache Stale

```php
// إظهار وقت آخر تحديث للمشرف
'cached_at' => $cachedAt->diffForHumans(), // "منذ 3 دقائق"

// إذا كان الوقت منتهياً — تحديث تلقائي
if ($cachedAt->diffInSeconds(now()) > self::CACHE_TTL) {
    $this->clearCache();
    return $this->generateStats($period);
}
```
