# 14 - منع الهجمات وهندسة المعدل (Rate Limiting & Brute Force)

## لا يحتاج Rate Limiting خاص

تسجيل الخروج عملية بسيطة وآمنة — لا تحتاج حماية إضافية.

## حماية عامة

```php
<?php
// في Route

Route::post('/auth/logout', [AuthController::class, 'logout'])
    ->middleware('auth:api')
    ->middleware('throttle:30,1');
    // 30 طلب كحد أقصى في الدقيقة
```

## منع إبطال توكنات الآخرين

```php
// auth:api middleware يضمن أن المستخدم
// لا يمكنه حذف إلا توكنه الخاص به
// JWT يتأكد من أن التوكن ينتمي للمستخدم المصادق

JWTAuth::invalidate(true);
// فقط التوكن الحالي — لا يمكن حذف توكنات مستخدمين آخرين
```

## ملخص الحماية

| الهجوم | الحماية |
|--------|---------|
| حذف توكنات الغير | JWT مدمج — التوكن مرتبط بالمستخدم |
| إغراق الطلبات | throttle:30,1 |
| استمرار التوكن المحذوف | JWT blacklist — غير قابل لإعادة الاستخدام |
