# 01 - فكرة العمل وسيناريو المستخدم (Business Idea) — تسجيل الخروج (Logout)

## الفكرة الأساسية

المستخدم "علي" يريد إنهاء الجلسة الحالية في Beza. العملية بسيطة:
1. **إبطال التوكن** — حذف التوكن الحالي من DB
2. **إنهاء الجلسة** — المستخدم يحتاج لتسجيل الدخول مجدداً

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم في Beza
أريد: تسجيل الخروج من التطبيق
لكي: أحمي حسابي عند استخدام جهاز مشترك
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | إرسال طلب مع Bearer token | إجباري |
| 2 | حذف التوكن الحالي فقط | OK |
| 3 | إبقاء التوكنات الأخرى نشطة (أجهزة أخرى) | OK |
| 4 | استجابة نجاح 200 | OK |
| 5 | التوكن المحذوف لا يعمل بعدها | OK |

## خيار Logout من كل الأجهزة

```
POST /api/v1/auth/logout-all — يحذف كل توكنات المستخدم
يستخدم في حال فقدان الجهاز أو الاشتباه باختراق
```

## تدفق الشاشات (User Flow)

```
[الإعدادات] → [تسجيل خروج] → [تأكيد] → [شاشة الدخول]
```
