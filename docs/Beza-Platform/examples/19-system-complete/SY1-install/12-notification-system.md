# 12 - نظام الإشعارات (Notification System)

## لا توجد إشعارات أثناء التنصيب

عملية التنصيب **لا تستخدم نظام الإشعارات** (FCM, SMS, Email) وذلك للأسباب التالية:

| السبب | التوضيح |
|-------|---------|
| **لا يوجد مستخدمون بعد** | التنصيب يتم قبل إنشاء أي مستخدم |
| **SMTP غير مضبوط بعد** | إعدادات البريد تتم أثناء التنصيب (الخطوة 3) |
| **FCM يتطلب مشروع Firebase** | إعدادات Firebase قد لا تكون جاهزة |
| **SMS يتطلب Gateway** | خدمة SMS تحتاج إعدادات مسبقة |
| **Queue قد لا يعمل** | الـ Queue يتم ضبطه أثناء التنصيب |

## البديل: رسائل الحالة المباشرة (Inline Status Messages)

بدلاً من الإشعارات، يعرض المثبت رسائل حالة فورية بجانب كل خطوة:

```javascript
// في React — رسائل الحالة المباشرة
const statusMessages = {
  checking: 'جاري الفحص...',
  pass: '✓ نجاح',
  fail: '✗ فشل',
  warning: '⚠ تحذير',
};

// كل استجابة من API تحتوي على رسالة توضيحية
// مثال لاستجابة /install/requirements
{
  "success": true,
  "data": {
    "all_pass": false,
    "items": {
      "ext_bcmath": {
        "pass": true,
        "message": "الإضافة BCMath — مثبتة"
      },
      "ext_redis": {
        "pass": false,
        "message": "الإضافة Redis — غير مثبتة (مطلوب للتخزين المؤقت)"
      }
    }
  }
}
```

## تسجيل السجل (Logging) بدلاً من الإشعارات

كل خطوة تسجل نتيجتها في سجل Laravel:

```php
// تسجيل نجاح خطوة
Log::info('تم الاتصال بقاعدة البيانات بنجاح أثناء التنصيب', [
    'host'    => $host,
    'db_name' => $database,
]);

// تسجيل فشل خطوة
Log::error('فشل الاتصال بقاعدة البيانات أثناء التنصيب', [
    'host'  => $host,
    'error' => $e->getMessage(),
]);

// تسجيل إكمال التنصيب
Log::info('تم إكمال تنصيب Beza بنجاح', [
    'admin_email' => $adminEmail,
    'app_url'     => env('APP_URL'),
]);
```

## الإشعار الوحيد: الإيميل بعد الإكمال

بعد إكمال التنصيب، قد يتم إرسال إيميل للمشرف لكن هذا **اختياري** ويعتمد على:

1. توفر SMTP (قد لا يكون مضبوطاً بعد)
2. إعدادات البريد المدخلة في الخطوة 3
3. نجاح الاتصال بخادم SMTP

```php
// محاولة إرسال إيميل — مع تجاهل الفشل
if (!empty(env('MAIL_HOST'))) {
    try {
        Mail::to($adminEmail)->send(new InstallationCompleteMail($adminData));
    } catch (\Throwable $e) {
        Log::warning('فشل إرسال الإيميل — تم تجاهل الخطأ');
    }
}
```

## مقارنة: الإشعارات في A1-register vs SY1-install

| الخاصية | A1-register | SY1-install |
|---------|-------------|-------------|
| FCM | ✅ إشعار ترحيبي | ❌ لا يوجد |
| SMS | ✅ رسالة ترحيب | ❌ لا يوجد |
| Email | ❌ (اختياري) | ⚠️ بعد الإكمال فقط (إن توفر SMTP) |
| In-app | ✅ إشعار داخل التطبيق | ❌ لا يوجد |
| رسائل حالة | ❌ | ✅ رسائل مباشرة في الواجهة |
| تسجيل سجل | ✅ | ✅ تسجيل مفصل لكل خطوة |
