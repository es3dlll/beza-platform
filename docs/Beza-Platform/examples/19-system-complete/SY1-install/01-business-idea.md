# 01 - فكرة العمل وسيناريو المستخدم (Business Idea) — تنصيب النظام (First-Run Installer)

## الفكرة الأساسية

المطور "خالد" يريد نشر منصة Beza على خادم جديد. يحتاج إلى:
1. **فحص البيئة** — التأكد من أن الخادم يلبي متطلبات PHP و الإضافات
2. **إعداد قاعدة البيانات** — إنشاء قاعدة MySQL واختبار الاتصال
3. **تهيئة Redis** — التأكد من أن التخزين المؤقت يعمل
4. **ضبط الإعدادات** — تكوين `.env` بقيم صحيحة (DB, Redis, Mail)
5. **تشغيل الترحيلات** — إنشاء جميع جداول التطبيق
6. **إنشاء المشرف** — حساب المسؤول الأول للمنصة

## سيناريو المستخدم (User Story)

```
بصفتي: مطور يقوم بنشر Beza على خادم جديد
أريد: إكمال عملية التنصيب عبر واجهة ويب خطوة بخطوة
لكي: تصبح المنصة جاهزة للاستخدام دون الحاجة للتعامل مع CLI
```

## تدفق الشاشات (User Flow)

```
[ترحيب] → [فحص المتطلبات] → [إعداد قاعدة البيانات] → [تهيئة البيئة]
→ [ترحيل البيانات] → [إنشاء المشرف] → [ملخص الإكمال]
```

## لماذا مثبت ويب وليس CLI؟

1. **سهولة الاستخدام** — ليس كل المطورين يعرفون Laravel CLI
2. **توجيه مرئي** — إظهار الأخطاء والتحذيرات بشكل واضح
3. **فحص تفاعلي** — تصحيح الإعدادات مباشرة من الواجهة
4. **توثيق خطوة بخطوة** — كل خطوة تظهر نتيجتها فوراً
5. **الإنتاج** — يمكن لمسؤولي النظام غير التقنيين نشر المنصة
