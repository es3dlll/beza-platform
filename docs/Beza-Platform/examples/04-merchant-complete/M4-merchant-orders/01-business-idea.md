# 01 - فكرة العمل (Business Idea)

## الفكرة الأساسية
نظام متكامل لإدارة طلبات التجار: يستلم التاجر الطلبات من العملاء عبر الموقع، يؤكدها، يشحنها، ويتابع التوصيل حتى التسليم. يربط العميل بالتاجر عبر واجهة موحدة مع إشعارات فورية وتتبع دقيق للحالة.

## سيناريو المستخدم الكامل

```
بصفتي: تاجر
أريد: إدارة دورة حياة الطلب بالكامل
لكي: أتمكن من معالجة الطلبات وتوصيلها للعملاء بكفاءة
```

```
بصفتي: عميل
أريد: تتبع حالة طلبي واستلام إشعارات
لكي: أعرف أين وصل طلبي ومتى سيصلني
```

## دورة حياة الطلب (Order Lifecycle Flow)

```
[browses] → [places order] → [pending] → [merchant confirms] → [processing]
    → [shipped] → [delivered] → [completed] → [customer reviews]
                                ↘ [return requested] → [refunded]
```

## جدول حالات الطلب (Order Statuses)

| الحالة | المعنى | الإجراء | الجهة المنفذة |
|--------|--------|---------|---------------|
| pending | الطلب معلق ينتظر تأكيد التاجر | عرض الطلب للتاجر | النظام |
| confirmed | أكده التاجر وجاهز للتجهيز | خصم المخزون | التاجر |
| processing | جاري تجهيز الطلب | تجهيز المنتجات | التاجر |
| shipped | تم الشحن وإرساله | إدخال رقم التتبع | التاجر |
| delivered | تم التوصيل للعميل | إشعار العميل | السائق/النظام |
| completed | أكمل العميل الاستلام | تحويل المبلغ للتاجر | النظام |
| cancelled | ألغي الطلب | إعادة المخزون | التاجر/العميل |
| returned | أعيد الطلب | استرجاع المبلغ | النظام |
| refunded | تم استرداد المبلغ | إغلاق الطلب | النظام |

## شروط القبول التفصيلية (Acceptance Criteria)

| # | الشرط | الأولوية |
|---|-------|----------|
| 1 | عرض الطلبات حسب الحالة (pending/confirmed/processing/shipped/delivered/cancelled) | عالية |
| 2 | تغيير حالة الطلب مع التحقق من الانتقال الصحيح | عالية |
| 3 | إشعار العميل عند كل تغيير حالة (إيميل + SMS + إشعار تطبيق) | عالية |
| 4 | البحث والتصفية حسب التاريخ، الحالة، رقم الطلب، العميل | متوسطة |
| 5 | طباعة فاتورة الطلب | متوسطة |
| 6 | إلغاء الطلب مع إعادة المخزون | عالية |
| 7 | طلب إرجاع من العميل ومعالجته من التاجر | متوسطة |
| 8 | لوحة إحصائيات (عدد الطلبات، الإيرادات، المنتجات الأكثر مبيعاً) | منخفضة |

## كود دورة حياة الطلب الأساسي
```php
class OrderLifecycle
{
    public const array TRANSITIONS = [
        'pending'    => ['confirmed', 'cancelled'],
        'confirmed'  => ['processing', 'cancelled'],
        'processing' => ['shipped'],
        'shipped'    => ['delivered'],
        'delivered'  => ['completed', 'returned'],
        'completed'  => [],
        'cancelled'  => [],
        'returned'   => ['refunded'],
        'refunded'   => [],
    ];
}
```

## تكامل مع الأنظمة الأخرى
- **المخزون**: خصم تلقائي عند تأكيد الطلب، إعادة عند الإلغاء
- **الدفع**: تعليق المبلغ لحين التسليم، تحويل التاجر عند completion
- **الشحن**: إنشاء شحنة تلقائي عند الحالة shipped
- **الإشعارات**: FCM + SMS + Email عند كل انتقال حالة

## خلاصة
هذا الموديول هو قلب المنصة. يدير التجار من خلاله كل العمليات اليومية من استلام الطلب إلى توصيله، مع تكامل كامل مع المخزون والدفع والشحن والإشعارات.
