# 20 - قائمة التحقق الأمني للتطوير المحلي (Security Checklist)

## 1. ملف .env
- [ ] APP_DEBUG=false في الإنتاج
- [ ] لا تشارك .env في git
- [ ] مفاتيح API حساسة محمية

## 2. قاعدة البيانات
- [ ] كلمة مرور MySQL قوية
- [ ] منفذ 3306 غير مكشوف للعام
- [ ] مستخدم منفصل لكل بيئة

## 3. Redis
- [ ] Redis محمي بكلمة مرور
- [ ] منفذ 6379 غير مكشوف

## 4. Laravel
- [ ] DEBUG=true فقط للتطوير المحلي
- [ ] APP_KEY أنشئ (php artisan key:generate)
- [ ] CORS origins محددة

## 5. الواجهات
- [ ] لا توجد مفاتيح API في الكود
- [ ] HTTPS للتطوير (اختياري)

## 6. Git
- [ ] لا توجد كلمات مرور في commit
- [ ] .gitignore يغطي الملفات الحساسة

## 7. التحقق النهائي
- [ ] API لا يعرض معلومات حساسة
- [ ] صفحات الأخطاء لا تظهر stack trace
- [ ] Rate limiting مفعل
