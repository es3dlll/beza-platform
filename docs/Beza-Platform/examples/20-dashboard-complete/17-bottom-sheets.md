# 17 - اللوحات السفلية (Send/Receive Bottom Sheets)

## لوحة الإرسال (Send Bottom Sheet)

### الهيكل

```
┌─────────────────────────────────┐
│       تحويل الأموال        [X] │  ← Header
├─────────────────────────────────┤
│  ┌─────────────────────────┐    │
│  │ رقم المستلم         ←  │    │  ← to_phone (tel)
│  └─────────────────────────┘    │
│  ┌──────────────┬──────────┐    │
│  │ المبلغ       │ SYP ▼   │    │  ← amount + currency
│  └──────────────┴──────────┘    │
│  ┌─────────────────────────┐    │
│  │ PIN (4 أرقام)        ←  │    │  ← password
│  └─────────────────────────┘    │
│  ┌─────────────────────────┐    │
│  │ ملاحظة (اختياري)        │    │  ← textarea
│  └─────────────────────────┘    │
│                                 │
│  [✔ تم التحويل بنجاح]          │  ← رسالة (اختياري)
│                                 │
│  ┌─────────────────────────┐    │
│  │     تأكيد التحويل       │    │  ← Gold Button
│  └─────────────────────────┘    │
└─────────────────────────────────┘
```

### CSS

```css
position: fixed;
bottom: 0;
inset-x: 0;
z-index: 50;
background: rgba(10,14,34,0.98);
backdrop-filter: blur(24px);
border-radius: 24px 24px 0 0;
max-height: 85vh;
overflow-y: auto;
```

### تدفق الإرسال

```
1. showSend = true → Bottom Sheet يظهر من الأسفل
2. المستخدم يملأ الحقول
3. نقر "تأكيد التحويل"
   → sendLoading = true
   → POST /transfer
   → نجاح: رسالة خضراء + إغلاق بعد 1.5 ثانية
   → فشل: رسالة حمراء
4. نقر خارج المحتوى أو [X] → showSend = false
```

## أزرار الإجراءات (Action Grid)

```
┌──────────────┬──────────────┐
│              │              │
│    ▲ إرسال   │    💳 بطاقات │
│              │              │
├──────────────┼──────────────┤
│              │              │
│  ▼ استقبال   │  ✦ ذهب وفضة │
│              │              │
└──────────────┴──────────────┘
```

| الزر | الإجراء | اللون |
|------|---------|-------|
| إرسال | `showSend = true` | ذهبي متدرج |
| بطاقات | `navigate('/cards')` | أرجواني |
| استقبال | `showReceive = true` | شفاف مع حدود |
| ذهب وفضة | `navigate('/gold-silver')` | ذهبي متدرج |
