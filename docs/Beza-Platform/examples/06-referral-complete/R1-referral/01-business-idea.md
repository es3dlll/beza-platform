# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية

المستخدم "أحمد" يستخدم Beza ويريد دعوة صديقه "محمد". يشارك رابط الإحالة الخاص به. محمد يسجل عبر الرابط، يقوم بأول تحويل بقيمة 50 USD، فيحصل كلاهما على 2 USD مكافأة.

1. **نمو عضوي** — كل مستخدم يصبح سفيراً للمنصة
2. **مكافآت متبادلة** — الداعي والمدعو يستفيدان
3. **شرط التحفيز** — المكافأة بعد أول معاملة فعلية
4. **شفافية** — تتبع الإحالات والمكافآت

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم في Beza
أريد: دعوة أصدقائي للانضمام إلى المنصة
لكي: أحصل أنا وصديقي على مكافأة 2 USD لكل منا
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | المستخدم لديه حساب نشط | إجباري |
| 2 | المستخدم يولد كود إحالة | إنشاء code |
| 3 | المستخدم يشارك الرابط مع صديقه | share |
| 4 | الصديق يسجل عبر الرابط | registration |
| 5 | الصديق يقوم بأول تحويل ≥ 10 USD | trigger |
| 6 | إضافة 2 USD لمحفظة الداعي | reward |
| 7 | إضافة 2 USD لمحفظة الصديق | reward |
| 8 | تسجيل معاملة من نوع referral_bonus | audit |

## لماذا برنامج الولاء؟

1. **تسويق بتكلفة منخفضة**: 4 USD لكل مستخدم جديد
2. **ثقة أعلى**: دعوة من صديق أكثر فعالية من الإعلانات
3. **تأثير الشبكة**: كل مستخدم جديد يجلب المزيد

## تدفق الشاشات (User Flow)

```
[الملف الشخصي] → [دعوة صديق] → [مشاركة الرابط] → [انتظار تسجيل الصديق] → [مكافأة]
```
