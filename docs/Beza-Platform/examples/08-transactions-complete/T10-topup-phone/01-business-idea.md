# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية

شحن رصيد هاتف في منصة Beza. 1. اختيار المشغل → 2. إدخال الرقم → 3. اختيار المبلغ → 4. خصم من المحفظة → 5. شحن عبر API المشغل

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم في Beza
أريد: شحن رصيد هاتفي المحمول
لكي: أعبّي رصيدي بدون الحاجة لبطاقات تعبئة
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | شحن رصيد هاتف | الحالة |
|---|-------|--------|--------|
| 1 | اختيار المشغل | operator (MTN/Syriatel) | إجباري |
| 2 | إدخال رقم الهاتف | phone_number | إجباري |
| 3 | اختيار المبلغ | amount | إجباري |
| 4 | خصم من المحفظة | deduct | atomic |
| 5 | شحن عبر API المشغل | operator_api | إجباري |

## القواعد الأساسية

- المشغلين المدعومين: MTN, Syriatel
- الحد الأقصى للشحن اليومي 50 USD
- الرقم يجب أن يكون صحيحاً ومنطقته مع المشغل
- يتم الشحن فوراً عبر API المشغل
- يتم الخصم من المحفظة قبل الشحن
