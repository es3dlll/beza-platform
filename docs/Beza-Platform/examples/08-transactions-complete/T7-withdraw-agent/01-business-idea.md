# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية

سحب وكيل في منصة Beza. 1. المستخدم يدخل رقم الوكيل → 2. التحقق من أن الوكيل لديه رصيد كافٍ → 3. خصم من المستخدم → 4. إضافة للوكيل → 5. الوكيل يعطي نقداً

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم في Beza
أريد: سحب نقدي من وكيل معتمد
لكي: أحصل على أموالي نقداً بدون بطاقة بنكية
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | سحب وكيل | الحالة |
|---|-------|--------|--------|
| 1 | إدخال رقم الوكيل | agent_phone | إجباري |
| 2 | تحديد المبلغ | amount | إجباري |
| 3 | إدخال PIN | pin | إجباري |
| 4 | التحقق من رصيد الوكيل | agent_balance | business rule |
| 5 | خصم من المستخدم + إضافة للوكيل | atomic | atomic |

## تدفق الشاشات (User Flow)

```
1. المستخدم يدخل رقم الوكيل →
│
 2. التحقق من أن الوكيل لديه رصيد كافٍ →
│
 3. خصم من المستخدم →
│
 4. إضافة للوكيل →
│
 5. الوكيل يعطي نقداً
```

## القواعد الأساسية

- الحد الأقصى للسحب النقدي 500 USD/day
- رسوم السحب النقدي 0% (مجاني)
- يجب أن يكون الوكيل نشطاً
- يجب أن يكون لدى الوكيل رصيد كافٍ
- الوكيل يعطي نقداً خارج المنصة
