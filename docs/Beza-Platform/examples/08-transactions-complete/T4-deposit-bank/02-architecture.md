# 02 - مكان العملية في الأرشيتيكشر (Architecture Position)

## موقع العملية ضمن طبقات النظام

```
┌──────────────────────────────────────────────────────────────────┐
│                    Flutter App / React SPA                        │
│  [BankDepositScreen] → [HTTP Request]                   │
└────────────────────────────────┬─────────────────────────────────┘
                                  │ POST /api/v1/deposit/bank
                                  ▼
┌──────────────────────────────────────────────────────────────────┐
│                   Laravel Router (api.php)                       │
│  Route::post('/deposit/bank', ...)
│  Route::get('/deposit/bank/status', ...)
└────────────────────────────────┬─────────────────────────────────┘
                                  ▼
┌──────────────────────────────────────────────────────────────────┐
│                    Middleware Stack                               │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────────────┐ │
│  │ auth:api │  │ throttle │  │ verified │  │ Optional: 2FA   │ │
│  └──────────┘  └──────────┘  └──────────┘  └──────────────────┘ │
└────────────────────────────────┬─────────────────────────────────┘
                                  ▼
┌──────────────────────────────────────────────────────────────────┐
│                    Controller                                     │
│  1. Validate input                                               │
│  2. Call Service Layer                                            │
│  3. Return response                                              │
└────────────────────────────────┬─────────────────────────────────┘
                                  ▼
┌──────────────────────────────────────────────────────────────────┐
│                    Service Layer                                  │
│  1. Business logic                                                │
│  2. DB::transaction {                                             │
│       WalletService::decrement()                                  │
│       WalletService::increment()                                  │
│       Transaction::create()                                       │
│  }                                                                │
│  3. event(new Event)                                              │
└────────────────────────────────┬─────────────────────────────────┘
                                  │
                     ┌────────────┼────────────┐
                     ▼            ▼            ▼
           ┌────────────┐ ┌────────────┐ ┌────────────┐
           │ MySQL       │ │ Redis      │ │ Queue      │
           │ tables      │ │ Cache      │ │ (Events)   │
           └────────────┘ └────────────┘ └──────┬─────┘
                                                │
                                       ┌────────┴────────┐
                                       ▼                 ▼
                                ┌────────────┐   ┌────────────┐
                                │ Listener    │   │ Webhook    │
                                │ SendNotif.  │   │ (optional) │
                                └────────────┘   └────────────┘
```
