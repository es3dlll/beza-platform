## معايير القبول (Thresholds)

| المقياس | الحد | التصرف |
|---------|------|--------|
| http_req_duration (p95) | < 200ms | فشل إذا تجاوز |
| http_req_failed | < 1% | فشل إذا تجاوز |
| iterations | > 1000/duration | إنذار إذا قل |
