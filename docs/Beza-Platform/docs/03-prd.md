### 3.2.5 الصفقات الاستثمارية (Deal-Based Investment)

يستثمر المستخدم في **صفقات تمويل تجاري محددة** — كل صفقة هي شحنة أو عملية تجارية حقيقية. الأرباح تُوزع بعد إتمام الصفقة.

| الميزة | الوصف |
|--------|-------|
| آلية العمل | تُعرض صفقات تمويل شحنات تجارية (إلكترونيات، مواد أولية، إلخ). يختار المستخدم الصفقة ويساهم بمبلغ |
| مصدر الربح | الفرق بين سعر الشراء والبيع بعد بيع الشحنة |
| مدة الصفقة | محددة مسبقاً (مثلاً 30-90 يوماً) حسب وصول الشحنة |
| توزيع الأرباح | عند إتمام الصفقة — يُقفل الاستثمار ويُضاف رأس المال + الربح إلى المحفظة |
| المخاطرة | نسبة الربح محددة مسبقاً، لكن قد تتأثر بتأخر الشحنة أو ظروف السوق |
| الحد الأدنى للمشاركة | يختلف حسب الصفقة (عادة 50-500 USD) |
| السحب المبكر | غير متاح — الاستثمار مقفل حتى إتمام الصفقة |

**مثال صفقة:**

```
تمويل شحنة إلكترونيات من دبي إلى دمشق
- المبلغ المستهدف: 50,000 USD
- مدة الصفقة: 45 يوماً
- الربح المتوقع: 8% (أي 4,000 USD)
- الحد الأدنى للمشاركة: 100 USD
- المستثمرون يشاركون بنسبة من المبلغ، ويحصلون على أرباحهم بنسبة مساهمتهم
```

يتيح للمستخدم شراء وبيع الذهب والفضة فعلياً (وليس تداولاً) — يُسجل الملكية بالجرامات ويُخزن في خزائن آمنة.

| الميزة | الوصف | الأولوية |
|--------|-------|----------|
| شراء ذهب/فضة | شراء بالـ USD أو SYP بسعر السوق + هامش 1-2% | P1 |
| بيع ذهب/فضة | بيع إلى المنصة بسعر السوق | P1 |
| عرض الأسعار الحية | XAU/USD, XAG/USD من مزود خارجي | P1 |
| محفظة ذهب/فضة | رصيد بالجرامات منفصل عن المحفظة النقدية | P1 |
| سجل المعاملات | مشتريات، مبيعات، تحويلات | P2 |
| حد أدنى للشراء | 0.1 جرام ذهب / 1 جرام فضة | P1 |

## 3.4 قيود النظام (Constraints)

**الحدود اليومية للمستخدم العادي:**

- الإيداع: 10,000,000 SYP أو 10,000 USD
- السحب: 5,000,000 SYP أو 5,000 USD
- التحويل: 2,000,000 SYP أو 2,000 USD

**الحدود اليومية للتاجر (حسب التصنيف):**

- صغير: 10,000 USD
- متوسط: 50,000 USD
- كبير: 200,000 USD (بعد موافقة خاصة)

**الحدود اليومية للوكيل:**

- إجمالي المعاملات: 50,000 USD
- الحد الأقصى للمعاملة الواحدة: 5,000 USD

**الرسوم:**

| الخدمة | الرسم |
|--------|-------|

| سحب إلى بنك | 1% (بحد أدنى 2 USD) |
