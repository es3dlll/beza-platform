# R1 - الإحالة والمكافآت

## الوصف
دعوة الأصدقاء للتسجيل في المنصة والحصول على مكافآت.

## دعوة صديق

### سير العمل
1. المستخدم يشارك رابط الدعوة (مع رفرنس خاص)
2. الصديق يسجل عبر الرابط
3. الصديق يقوم بأول إيداع (min 10 USD)
4. يتم التحقق من الصديق (phone_verified_at موجود)
5. إضافة 5 USD مكافأة لمحفظة الداعي

### قواعد العمل
- المكافأة: 5 USD لكل صديك موثق يقوم بإيداع 10 USD
- لا حد أقصى لعدد الدعوات
- التحقق يتم تلقائياً

## برنامج الولاء

### سير العمل
1. كل معاملة تمنح نقاط ولاء (1 point لكل 1 USD)
2. النقاط تُستبدل بخصومات أو استرداد نقدي
3. عرض رصيد النقاط في المحفظة

## مكافآت الاستثمار

### سير العمل
1. مكافأة ترحيبية 1% على أول استثمار في صفقة
2. تضاف المكافأة بعد أول DealInvestment

## API Endpoint
`POST /api/v1/referral/generate-link`
`GET /api/v1/referral/status`

## اختبارات
- إنشاء رابط دعوة ← 200
- تسجيل عبر رابط دعوة + إيداع ← مكافأة للداعي
- التحقق من رصيد المكافأة 5 USD
- عرض حالة الإحالات ← 200
