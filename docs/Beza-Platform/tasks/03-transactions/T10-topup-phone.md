# T10 - شحن رصيد هاتف

## الوصف
شحن رصيد هاتف لمقدمي الخدمات المحليين.

## المدخلات
| الحقل | النوع |
|-------|-------|
| provider | string (مثلاً: MTN, Syriatel) |
| phone | string (رقم الهاتف المستهدف) |
| amount | decimal |
| pin | string, size:4 |

## سير العمل
1. التحقق من PIN
2. التحقق من رصيد كافٍ
3. الاتصال بـ API مزود الاتصالات
4. خصم المبلغ من المحفظة
5. تسجيل Transaction

## قواعد العمل
- رسوم الخدمة: حسب اتفاقية كل مزود
- فترة التفعيل: P2 (إطلاق متأخر)

## API Endpoint
`POST /api/v1/topup/phone`

## أولوية التنفيذ
P2

## اختبارات
- شحن لرقم صحيح ← 200
- شحن برصيد غير كاف ← 400
- شحن لمزود غير مدعوم ← 400
