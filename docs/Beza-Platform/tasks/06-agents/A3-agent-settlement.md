# AG3 - تسوية رصيد الوكيل

## الوصف
تسوية يومية لرصيد الوكيل النقدي مع محفظته في Beza.

## سير العمل (Cron)
1. حساب إجمالي معاملات الوكيل لليوم (cash_in + cash_out)
2. حساب العمولة المستحقة للوكيل (1% لكل معاملة)
3. إنشاء تقرير تسوية
4. تحويل العمولة إلى محفظة الوكيل في Beza (wallet_balance)
5. إشعار الوكيل بالتسوية

## API Endpoint
`GET /api/v1/agent/settlements`

## Cron Job
`php artisan agents:settle-daily`

## اختبارات
- عرض تاريخ التسوية ← 200
- تشغيل cron ← تسوية صحيحة
- حساب عمولة 1000 USD = 10 USD
