> هذا الملف هو المرجع الوحيد للتكامل الخارجي مع نظام مدفوعات التجار في Beza.

## 01. المصادقة — تسجيل تاجر جديد

### POST /api/v1/merchant/auth/register

إنشاء حساب تاجر جديد. يتطلب توثيقاً تجارياً للموافقة من قبل المشرف.

#### المدخلات

| الحقل | النوع | الإلزام | الوصف |
|-------|-------|--------|-------|
| `business_name` | string(128) | مطلوب | الاسم التجاري |
| `owner_name` | string(128) | مطلوب | اسم صاحب التاجر |
| `phone` | string(15) | مطلوب | رقم الهاتف (مع رمز الدولة) |
| `email` | email | مطلوب | البريد الإلكتروني |
| `password` | string(64) | مطلوب | كلمة المرور (8+ أحرف، حرف كبير + رقم) |
| `commercial_register` | string(64) | مطلوب | رقم السجل التجاري |
| `tax_id` | string(64) | اختياري | الرقم الضريبي |
| `business_type` | enum | مطلوب | individual / company / ecommerce |
| `address` | string(256) | اختياري | العنوان الكامل |
| `city` | string(64) | اختياري | المدينة |
| `website` | url | اختياري | الموقع الإلكتروني |

#### الاستجابة (201 Created)

```json
{
  "success": true,
  "data": {
    "merchant_id": "merch_a1b2c3d4",
    "business_name": "متجر أحمد الإلكتروني",
    "status": "pending_approval",
    "message": "تم تسجيل حساب التاجر بنجاح. ينتظر الموافقة من المشرف."
  }
}
```

#### رموز الحالة

| الرمز | المعنى |
|-------|--------|
| 201 | تم إنشاء حساب التاجر — ينتظر الموافقة |
| 400 | خطأ في المدخلات |
| 409 | تعارض — رقم الهاتف أو البريد الإلكتروني مسجل مسبقاً |
| 422 | كيان غير قابل للمعالجة — سجل تجاري غير صالح |

## 02. المصادقة — تسجيل الدخول

### POST /api/v1/merchant/auth/login

تسجيل دخول التاجر واستلام Bearer Token للوصول إلى نقاط API.

#### المدخلات

| الحقل | النوع | الإلزام | الوصف |
|-------|-------|--------|-------|
| `phone` | string(15) | مطلوب | رقم الهاتف المسجل |
| `password` | string(64) | مطلوب | كلمة المرور |

#### الاستجابة (200 Success)

```json
{
  "success": true,
  "data": {
    "token_type": "Bearer",
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
    "expires_in": 1440,
    "merchant": {
      "id": "merch_a1b2c3d4",
      "business_name": "متجر أحمد الإلكتروني",
      "status": "approved",
      "tier": "medium",
      "daily_limit": 50000.00,
      "monthly_limit": 500000.00
    }
  }
}
```

#### رموز الحالة

| الرمز | المعنى |
|-------|--------|
| 200 | نجاح — تم تسجيل الدخول |
| 401 | غير مصرح — رقم الهاتف أو كلمة المرور خطأ |
| 403 | ممنوع — الحساب معلق أو لم تتم الموافقة عليه بعد |
| 429 | تجاوز المعدل — أكثر من 5 محاولات فاشلة/دقيقة |

## 03. المصادقة — تجديد التوكن

### POST /api/v1/merchant/auth/refresh

تجديد Bearer Token قبل انتهاء صلاحيته.

#### المدخلات

| الحقل | النوع | الإلزام | الوصف |
|-------|-------|--------|-------|
| `refresh_token` | string | مطلوب | توكن التجديد |

#### الاستجابة (200 Success)

```json
{
  "success": true,
  "data": {
    "token_type": "Bearer",
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
    "expires_in": 1440
  }
}
```

#### رموز الحالة

| الرمز | المعنى |
|-------|--------|
| 200 | نجاح — تم تجديد التوكن |
| 401 | غير مصرح — توكن التجديد منتهٍ أو غير صالح |

---

## 04. المصادقة — تسجيل الخروج

### POST /api/v1/merchant/auth/logout

إبطال التوكن الحالي وتسجيل الخروج.

#### المدخلات

لا يتطلب جسم طلب. يكفي إرسال Bearer Token في الترويسة.

#### الاستجابة (200 Success)

```json
{
  "success": true,
  "message": "تم تسجيل الخروج بنجاح"
}
```

#### رموز الحالة

| الرمز | المعنى |
|-------|--------|
| 200 | نجاح — تم إبطال التوكن |
| 401 | غير مصرح — التوكن غير صالح |
