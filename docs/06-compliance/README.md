# Compliance — الامتثال التنظيمي

> **الهدف:** المرجع الموحد لجميع متطلبات الامتثال التنظيمي والأمني لمنصة بيزا  
> **الجمهور المستهدف:** مسؤولو الامتثال، المطورون، فريق الأمان، الجهات الرقابية  
> **المبدأ:** لا تكرار — كل موضوع في مجلد واحد فقط، الباقي يشير إليه

## طبقات الحماية

```
المصادقة ← JWT 15 دقيقة + Refresh Token 7 أيام + Device Binding
التفويض ← RBAC (دور) + ABAC (سمة) لكل نقطة API
التشفير ← AES-256-GCM للراحة + TLS 1.3 للنقل
التدقيق ← Audit Log WORM لكل معاملة مالية
الامتثال ← AML/CFT + KYC + CBS + العقوبات
```

---

## القواعد المالية الصارمة

1. **دفتر الأستاذ** — مصدر الحقيقة الوحيد، Append-Only (WORM)
2. **المعاملات** — قيد مزدوج (Debit/Credit) لكل حركة مالية
3. **التخزين** — Bigint بوحدات صغرى (فلس)، ممنوع float/double/decimal
4. **المفاتيح** — ULID حصرياً، ممنوع Auto-increment
5. **الصلاحيات** — لا صلاحية لتطبيق UPDATE أو DELETE على أي سجل مالي
