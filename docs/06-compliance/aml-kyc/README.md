## الأطر التنظيمية

### 1. AML — مكافحة غسل الأموال

| المبدأ | الوصف |
|--------|-------|
| فحص تلقائي | كل معاملة تُفحص مقابل قواعد AML |
| عتبات الإبلاغ | حدود للمعاملات المشبوهة |
| تصعيد للمراجعة | الحالات عالية المخاطر تُرفع يدوياً |
| سجل تدقيق | غير قابل للتعديل لكل عملية |

### 2. KYC — اعرف عميلك

| المستوى | المتطلبات | الحدود |
|---------|-----------|--------|
| T1 | رقم هاتف فقط | 500,000 SYP/يوم |
| T2 | هوية وطنية + صورة شخصية | 2,000,000 SYP/يوم |
| T3 | إثبات دخل + فاتورة | غير محدودة |

> **تفاصيل الحدود والسلوك التلقائي:** [`../kyc-tiers.md`](../kyc-tiers.md)

### 3. Sharia — الامتثال الشرعي

- جميع المنتجات المالية متوافقة مع الشريعة الإسلامية
- مراجعة من هيئة شرعية مستقلة

## متطلبات CBS (المصرف المركزي السوري)

- تقارير شهرية تلقائية
- تسوية دورية مع المصرف المركزي
- الاحتفاظ بالسجلات 10 سنوات
- الإبلاغ عن المعاملات المشبوهة خلال 24 ساعة
- الامتثال لقائمة العقوبات
