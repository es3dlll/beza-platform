# 1. ملخص تنفيذي ورؤية المنصة

## 1.1 الرؤية

Beza هي منظومة مالية رقمية متكاملة تهدف إلى تحويل المشهد المالي في سوريا والمنطقة العربية. تجمع المنصة بين:

- محفظة رقمية مزدوجة العملة (SYP/USD) للأفراد
- حسابات تجار مع متاجر إلكترونية وتقبل مدفوعات (Payment Gateway)
- شبكة وكلاء (مكاتب صرافة) تقدم خدمات سحب وإيداع نقدي
- بطاقات افتراضية وفيزيائية Visa/MasterCard
- صفقات استثمارية في تمويل الشحنات التجارية بأرباح محددة مسبقاً

## 1.2 القيم الأساسية

| القيمة | الوصف |
|--------|-------|
| **الشمول المالي** | إتاحة الخدمات لمن لا يملك حساباً بنكياً |
| **الشفافية** | رسوم واضحة، أسعار صرف لحظية |
| **الأمان** | أعلى معايير التشفير والمصادقة |
| **اللامركزية في الخدمة** | عبر شبكة وكلاء تغطي كل المحافظات |

## 1.3 الرؤية والرسالة

**الرؤية:** أن نصبح المنصة المالية الرقمية الأولى في العالم العربي، ونعمل على تعزيز الشمول المالي وتمكين الأفراد والشركات من إدارة أموالهم بكل سهولة وأمان.

**الرسالة:** تقديم حلول مالية رقمية متكاملة، شفافة، ومنخفضة التكلفة، مع التركيز على تجربة مستخدم استثنائية وأمان على مستوى المؤسسات المالية.
