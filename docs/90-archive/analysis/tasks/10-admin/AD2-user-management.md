# AD2 - إدارة المستخدمين (Admin)

## الوصف
إدارة جميع المستخدمين: عرض، تعديل، حظر.

## قائمة المستخدمين
`GET /api/v1/admin/users`

### ميزات
- Pagination
- فلترة: status, kyc_status, is_merchant, is_agent
- بحث: name, phone, email

## تفاصيل المستخدم
`GET /api/v1/admin/users/{id}`

### المخرجات
- معلومات المستخدم
- المحافظ والأرصدة
- آخر المعاملات
- حالة KYC
- الأجهزة المسجلة

## تحديث حالة المستخدم
`PUT /api/v1/admin/users/{id}/status`

### الإجراءات
- suspend ← تعليق الحساب
- activate ← تفعيل الحساب
- block ← حظر نهائي

## واجهات المستخدم
- React Admin: UserList, UserDetails

## قواعد العمل
- حظر المستخدم يمنع تسجيل الدخول
- تعليق المستخدم يحتفظ بالبيانات ولكن لا يمكنه استخدام الخدمة
- لا يمكن حظر المشرفين

## اختبارات
- عرض القائمة ← 200
- بحث برقم هاتف ← 200
- تعليق مستخدم ← 200
- محاولة حظر مستخدم بدون صلاحية ← 403
