# W1 - إنشاء المحفظة المزدوجة

## الوصف
عند تسجيل مستخدم جديد، يتم إنشاء محفظتين تلقائياً: SYP و USD.

## سير العمل
1. يتم استدعاؤه ضمن `register()` في AuthController
2. لكل عملة (SYP, USD):
   - إنشاء رقم محفظة فريد: `BEZA` + 8 أرقام عشوائية
   - رصيد SYP = 0
   - رصيد USD = 5 (هدية ترحيب)
   - `is_active = true`

## جداول قاعدة البيانات
- wallets: user_id, currency, wallet_number, balance, frozen_balance, is_active

## قواعد العمل
- كل مستخدم لديه محفظة SYP ومحفظة USD إجبارياً
- `wallet_number` فريد وغير قابل للتغيير
- `frozen_balance` تُستخدم عند إنشاء رمز سحب نقدي (لم يتم صرفه بعد)

## API Endpoint
لا يوجد endpoint منفصل — يتم ضمن `POST /api/v1/auth/register`

## اختبارات
- التحقق من أن المستخدم الجديد يملك محفظتين
- التحقق من أن رقم المحفظة فريد
- التحقق من رصيد الترحيب 5 USD
