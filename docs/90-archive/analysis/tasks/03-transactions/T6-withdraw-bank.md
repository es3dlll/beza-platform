# T6 - سحب إلى بنك

## الوصف
سحب أموال من المحفظة إلى حساب بنكي مسجل.

## المدخلات
| الحقل | النوع |
|-------|-------|
| currency | enum: SYP, USD |
| amount | decimal, min:10 USD |
| bank_account_id | id (حسب الحسابات المسجلة في merchant.bank_account) |
| pin | string, size:4 |

## سير العمل
1. التحقق من PIN
2. التحقق من رصيد كافٍ
3. تجميد المبلغ في frozen_balance
4. إنشاء طلب سحب بحالة 'pending'
5. فريق العمليات يراجع وينفذ التحويل البنكي (1-3 أيام)
6. بعد التنفيذ: خصم المبلغ + الرسوم من frozen_balance
7. إشعار المستخدم

## قواعد العمل
- رسوم السحب: 1% (بحد أدنى 2 USD)
- مدة المعالجة: 1-3 أيام عمل
- الحد الأدنى: 10 USD أو 10,000 SYP
- الحد الأقصى: 5,000 USD أو 5,000,000 SYP يومياً
- الحساب البنكي يجب أن يكون مسجلاً وموثقاً مسبقاً

## API Endpoint
`POST /api/v1/withdraw/bank`
`GET /api/v1/withdraw/bank/status`

## جداول قاعدة البيانات
- transactions (type: 'withdraw')
- wallets (frozen_balance)

## اختبارات
- طلب سحب بمبلغ صحيح ← 201
- سحب برصيد غير كاف ← 400
- سحب برقم PIN خاطئ ← 400
- استعلام حالة السحب ← 200
