# T4 - إيداع عبر بنك

## الوصف
إضافة رصيد للمحفظة عبر تحويل بنكي محلي.

## المدخلات
| الحقل | النوع |
|-------|-------|
| currency | enum: SYP, USD |
| amount | decimal, min حسب العملة |
| bank_account | string (آخر 4 أرقام) |
| transaction_reference | string (رقم إيصال التحويل) |

## سير العمل
1. المستخدم يُدخل بيانات التحويل البنكي
2. يُنشأ طلب إيداع بحالة 'pending'
3. فريق العمليات يراجع الطلب (خلال 24 ساعة)
4. بعد الموافقة: يتم تحديث الحالة إلى 'completed' وزيادة رصيد المحفظة
5. إشعار للمستخدم بإتمام الإيداع

## قواعد العمل
- الحد الأدنى للإيداع: 10 USD أو 10,000 SYP
- الحد الأقصى: 10,000 USD أو 10,000,000 SYP يومياً
- مدة المعالجة: حتى 24 ساعة (يدوي)
- يمكن أتمتة العملية عبر API البنك إذا توفر

## API Endpoint
`POST /api/v1/deposit/bank`
`GET /api/v1/deposit/bank/status`

## جداول قاعدة البيانات
- transactions (type: 'deposit', status: 'pending' ← 'completed')
- deposit_requests (اختياري)

## اختبارات
- إنشاء طلب إيداع ← 201
- استعلام عن حالة طلب ← 200
- إيداع بمبلغ أقل من الحد الأدنى ← 400
