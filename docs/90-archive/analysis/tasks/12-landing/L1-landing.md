# L1 - صفحة الهبوط التسويقية

## الوصف
موقع تسويقي منفصل (Next.js SSG) لجذب المستخدمين الجدد.

## الصفحات

### الرئيسية `/`
**المكونات:**
- Hero: عنوان + وصف + CTA (تحميل التطبيق + فتح متجر)
- Features: عرض المميزات (محفظة، بطاقات، صفقات، وكلاء)
- Testimonials: آراء المستخدمين
- Pricing: خطط الأسعار والرسوم
- FAQ: أسئلة شائعة
- Footer: روابط + تواصل اجتماعي

### التجار `/merchants`
صفحة مخصصة لاستقطاب التجار مع شرح فوائد المنصة.

### الوكلاء `/agents`
صفحة لاستقطاب مكاتب الصرافة كوكلاء.

### تحميل التطبيق `/download`
روابط Google Play + App Store.

## تحسين SEO
- Next.js SSG (Static Site Generation)
- meta tags لكل صفحة
- Open Graph tags
- Twitter Cards
- Sitemap.xml
- robots.txt

## النشر
- Vercel / Netlify
- CDN (Automatically via platform)

## اختبارات
- تحميل الصفحة الرئيسية ← 200
- التحقق من SEO tags
- روابط التحميل تعمل
- تجاوب الصفحة مع الشاشات المختلفة
