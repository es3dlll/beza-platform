# D4 - إلغاء صفقة (استرجاع المبالغ)

## الوصف
عند إلغاء الصفقة لأي سبب، يتم استرجاع رأس المال للمستثمرين.

## سير العمل
1. تحديث deal.status = 'cancelled'
2. لكل DealInvestment في الصفقة (حيث status = invested):
   - إعادة المبلغ إلى محفظة المستثمر
   - تحديث DealInvestment (status: refunded)
3. إشعار المستثمرين بالإلغاء والاسترجاع

## قواعد العمل
- لا يتم توزيع أرباح في حالة الإلغاء
- يُسترجع رأس المال فقط
- الإلغاء متاح فقط للصفقات ذات الحالة open أو funded

## API Endpoint
`POST /api/v1/admin/deals/{id}/cancel`

## اختبارات
- إلغاء صفقة ← استرجاع المبالغ
- إلغاء صفقة مكتملة ← 400 (غير مسموح)
- التحقق من رصيد المستثمر بعد الاسترجاع
