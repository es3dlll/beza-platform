# SE2 - كشف الاحتيال (Fraud Detection)

## الوصف
آليات لكشف ومنع الأنشطة المشبوهة.

## قواعد الكشف

### 1. سرعة المعاملات غير طبيعية
- أكثر من 5 معاملات في الدقيقة
- → تأخير المعاملة وطلب 2FA

### 2. تغيير الجهاز IP فجأة
- login من IP مختلف تماماً عن آخر 3 جلسات
- → إشعار للمستخدم عبر SMS + طلب تأكيد

### 3. محاولات PIN خاطئة
- 5 محاولات خاطئة → قفل PIN لمدة 15 دقيقة
- 10 محاولات خاطئة → قفل الحساب (يتطلب دعم)
- تسجيل كل محاولة في audit_logs

### 4. معاملات من جهاز جديد
- device_id لم يُشاهد من قبل للمستخدم
- → طلب OT P تأكيدي + 2FA

### 5. تغيير كلمة السر + معاملة كبيرة
- تغيير password خلال آخر ساعة
- متبوع بمعاملة > 500 USD
- → تعليق المعاملة وإشعار المستخدم

## قائمة IPs المحظورة
- مزامنة مع قواعد بيانات موثوقة
- IPs المعروفة بالاحتيال
- تحديث أسبوعي

## API Endpoint
`GET /api/v1/admin/fraud/report` (للمشرفين)

## اختبارات
- 5 محاولات PIN خاطئة ← قفل 15 دقيقة
- تغيير الجهاز ← OTP تأكيدي
- معاملة مشبوهة ← تعليق ← مراجعة يدوية
