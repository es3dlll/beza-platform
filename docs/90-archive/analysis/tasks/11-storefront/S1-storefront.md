# S1 - المتجر الإلكتروني (Storefront)

## الوصف
واجهة المتجر الإلكتروني الجاهزة للتجار.

## صفحات المتجر

### قائمة المنتجات
`GET /api/v1/store/products?merchant_id=...`

**الصفحة:** `/`
**المكون:** ProductList

**المخرجات:**
- name, price, currency, image
- فلترة: category, price range, search
- Pagination

### تفاصيل المنتج
`GET /api/v1/store/products/{id}`

**الصفحة:** `/product/{id}`
**المكون:** ProductPage

**المخرجات:**
- كل معلومات المنتج
- صور
- خيارات المقاس/اللون

### سلة التسوق
**الصفحة:** `/cart`
**المكون:** Cart

**سير العمل:**
1. إضافة منتج إلى السلة (LocalStorage أو Context)
2. عرض المنتجات في السلة
3. تعديل الكمية
4. حذف منتج من السلة

### الدفع (Checkout)
**الصفحة:** `/checkout`
**المكون:** Checkout

**سير العمل:**
1. إدخال عنوان الشحن
2. اختيار طريقة الدفع (Beza Wallet)
3. تأكيد الطلب
4. إنشاء MerchantOrder
5. إعادة التوجيه إلى Beza Pay

## المكونات
- SEO (تحسين محركات البحث)
- Header مع سلة التسوق
- ProductCard
- CartItem

## اختبارات
- عرض قائمة المنتجات ← 200
- عرض تفاصيل منتج ← 200
- إضافة إلى السلة ← تحديث العداد
- إتمام عملية شراء ← إنشاء طلب + redirect
