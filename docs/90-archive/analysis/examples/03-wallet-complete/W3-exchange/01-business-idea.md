# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية

المستخدم "أحمد" لديه 500 USD في محفظته، ويحتاج 500,000 SYP لشراء سلعة محلياً. يمكنه تحويل USD إلى SYP عبر عملية الصرافة الداخلية بسعر السوق مع رسوم بسيطة (1-2%).

1. **فوري** — التحويل مباشر
2. **سعر تنافسي** — سعر السوق الفعلي
3. **رسوم شفافة** — 1-2% هامش ربح
4. **مبلغ أدنى** — 1 USD أو 1000 SYP

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم في Beza
أريد: تحويل أموال بين محافظ العملات (SYP ↔ USD)
لكي: أستطيع الدفع بالعملة المناسبة حسب حاجتي
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | المستخدم يختار من عملة (from_currency) | إجباري |
| 2 | المستخدم يختار إلى عملة (to_currency) | إجباري |
| 3 | المستخدم يدخل المبلغ | ≥ الحد الأدنى |
| 4 | التحقق من أن from_currency ≠ to_currency | business rule |
| 5 | التحقق من رصيد كافٍ في محفظة المصدر | business rule |
| 6 | حساب سعر الصرف الحالي من السوق | business rule |
| 7 | حساب رسوم الصرافة (1-2%) | business rule |
| 8 | خصم المبلغ + الرسوم من محفظة المصدر | atomic |
| 9 | إضافة المبلغ المحول إلى المحفظة الوجهة | atomic |
| 10 | تسجيل معاملة type=exchange | audit |
| 11 | إرسال إشعار تأكيد الصرافة | notification |

## رسوم الصرافة

| العملية | النسبة | مثال (100 USD → SYP) |
|---------|--------|----------------------|
| USD → SYP | 1.5% | 100 USD → 98.5 USD يصرف |
| SYP → USD | 1.5% | 1,000,000 SYP → 985,000 SYP يصرف |
| الهامش | 1-2% | يغطي تقلبات السوق + أرباح المنصة |

## تدفق الشاشات (User Flow)

```
[الرئيسية] → [صرافة] → [اختيار من/إلى عملة] → [إدخال المبلغ] → [عرض السعر] → [تأكيد] → [نجاح]
                                                                              ↓
                                                                      [عرض الرصيد الجديد]
```
