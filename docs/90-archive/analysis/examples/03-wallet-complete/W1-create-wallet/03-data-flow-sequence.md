## جدول زمني لتنفيذ العملية (استجابة < 300ms p95)

| الخطوة | الزمن المستغرق | ملاحظة |
|--------|---------------|--------|
| Network Request (Flutter → API) | ~30ms | يعتمد على سرعة الشبكة |
| Middleware Stack | ~5ms | Rate Limit فقط |
| Validation | ~5ms | تحقق من الحقول |
| User::create (MySQL INSERT) | ~15ms | إنشاء المستخدم |
| CreateUserWallets (Listener) | ~20ms | إنشاء محفظتين + إيداع 5$ |
| Event Dispatch | ~2ms | Queued |
| Response Serialization | ~10ms | JSON |
| Network Response (API → Flutter) | ~30ms | |
| **المجموع** | **~117ms** | ضمن الهدف < 300ms |
