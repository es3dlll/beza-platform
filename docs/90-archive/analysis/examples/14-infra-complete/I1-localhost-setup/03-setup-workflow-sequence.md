```

  │────────────────────────────────>│──────────────────────>                  │
```

## الوقت المتوقع للإعداد

| الخطوة | الوقت |
|--------|-------|
| تثبيت المتطلبات الأساسية | 15-30 دقيقة |
| إعداد Laravel API | 5 دقائق |
| إعداد الواجهات (npm install) | 5-10 دقيقة لكل منها |
| إعداد Flutter | 10-20 دقيقة |
| التحقق النهائي | 5 دقائق |
| **المجموع** | **45-80 دقيقة** |
