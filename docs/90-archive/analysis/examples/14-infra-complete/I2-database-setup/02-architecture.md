## طبقات البيانات

| الطبقة | الجداول | الغرض |
|--------|---------|-------|
| Core | users, wallets, transactions | بيانات أساسية |
| Business | merchants, deals, cards | منطق الأعمال |
| Support | kyc, disputes, settings | خدمات مساعدة |
| Audit | audit_logs, notifications | تتبع وتدقيق |
| Infrastructure | jobs, failed_jobs, migrations | تشغيل النظام |
