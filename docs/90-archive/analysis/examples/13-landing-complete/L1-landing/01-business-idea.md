# 01 - فكرة المشروع — موقع Beza التسويقي

## ما هو موقع Beza التسويقي؟

موقع تسويقي منفصل (Next.js SSG) لجذب المستخدمين الجدد إلى منصة Beza.

## الأهداف

1. **جذب المستخدمين الجدد**: عرض مميزات المنصة (محفظة، بطاقات، صفقات، وكلاء)
2. **استقطاب التجار**: صفحة مخصصة لشرح فوائد المنصة للتجار
3. **استقطاب الوكلاء**: صفحة لمكاتب الصرافة للانضمام كوكلاء
4. **تحسين SEO**: ظهور متقدم في محركات البحث
5. **تحميل التطبيق**: روابط مباشرة لـ Google Play و App Store

## الصفحات

| الصفحة | المسار | المكونات |
|--------|--------|---------|
| الرئيسية | `/` | Hero, Features, Testimonials, Pricing, FAQ, Footer |
| التجار | `/merchants` | شرح فوائد المنصة للتجار |
| الوكلاء | `/agents` | شرح فوائد الانضمام كوكيل |
| التحميل | `/download` | روابط Google Play + App Store |

## الفرق بين الموقع التسويقي ومنصة Beza

| الموقع التسويقي (Landing) | منصة Beza (Web App) |
|--------------------------|---------------------|
| Next.js SSG | Laravel + React |
| محتوى ثابت (static) | محتوى ديناميكي |
| SEO أولوية | UI/UX أولوية |
| نشر على Vercel/Netlify | نشر على خوادم مخصصة |
| لا يتطلب تسجيل دخول | يتطلب مصادقة |
