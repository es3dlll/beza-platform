# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية

إيداع بنكي في منصة Beza. 1. يدخل بيانات التحويل البنكي → 2. ينشأ طلب pending → 3. مراجعة يدوية → 4. موافقة → تحديث الحالة + زيادة الرصيد

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم في Beza
أريد: إيداع أموال عبر التحويل البنكي
لكي: أشحن محفظتي من حسابي البنكي
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | إيداع بنكي | الحالة |
|---|-------|--------|--------|
| 1 | إدخال بيانات التحويل | POST /deposit/bank | إجباري |
| 2 | إرفاق صورة الإيصال | receipt_image | إجباري |
| 3 | التحقق من الحالة | GET /deposit/bank/status | إجباري |
| 4 | الموافقة اليدوية | manual_review | إجباري |
| 5 | زيادة الرصيد بعد الموافقة | balance_update | atomic |

## تدفق الشاشات (User Flow)

```
1. يدخل بيانات التحويل البنكي →
│
 2. ينشأ طلب pending →
│
 3. مراجعة يدوية →
│
 4. موافقة →
│
 تحديث الحالة + زيادة الرصيد
```

## القواعد الأساسية

- الحد الأدنى 10 USD أو 10000 SYP
- الحد الأقصى 10000 USD يومياً
- مدة المعالجة حتى 24 ساعة
- مراجعة يدوية من قبل فريق التدقيق
- إرفاق إيصال التحويل إجباري
