# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية

سحب بنكي في منصة Beza. 1. التحقق من الرصيد → 2. خصم الرصيد (تجميد) → 3. إنشاء طلب سحب → 4. معالجة بنكية → 5. تحديث الحالة

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم في Beza
أريد: سحب أموال إلى حسابي البنكي
لكي: أحصل على أموالي نقداً في حسابي البنكي
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | سحب بنكي | الحالة |
|---|-------|--------|--------|
| 1 | إدخال بيانات الحساب البنكي | bank_account | إجباري |
| 2 | تحديد المبلغ | amount | إجباري |
| 3 | التحقق من الرصيد | balance_check | business rule |
| 4 | تجميد الرصيد | freeze | atomic |
| 5 | معالجة بنكية | processing | manual |

```
 2. خصم الرصيد (تجميد) →
│

│

```

## القواعد الأساسية

- الحد الأدنى للسحب 5 USD
- رسوم السحب 1% من المبلغ
- مدة المعالجة 1-3 أيام عمل
- يتم تجميد الرصيد فور الموافقة
- يجب توثيق الحساب البنكي مسبقاً
