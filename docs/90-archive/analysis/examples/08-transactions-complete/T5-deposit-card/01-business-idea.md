# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية

إيداع بطاقة ائتمانية في منصة Beza. 1. تشفير بيانات البطاقة → 2. طلب من API مزود الدفع (Stripe/PayTabs) → 3. إذا نجح → زيادة رصيد المحفظة

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم في Beza
أريد: إيداع أموال عبر بطاقتي الائتمانية
لكي: أشحن محفظتي فوراً
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | إيداع بطاقة ائتمانية | الحالة |
|---|-------|--------|--------|
| 1 | إدخال بيانات البطاقة | card_number, expiry, cvv | إجباري |
| 2 | تشفير البيانات | encryption | security |
| 3 | تمرير الدفع للمزود | payment_gateway | إجباري |
| 4 | توثيق 3DSecure | 3ds | إجباري |
| 5 | زيادة الرصيد فور النجاح | balance_update | atomic |

## تدفق الشاشات (User Flow)

```
1. تشفير بيانات البطاقة →
│
 2. طلب من API مزود الدفع (Stripe/PayTabs) →
│
 3. إذا نجح →
│
 زيادة رصيد المحفظة
```

## القواعد الأساسية

- رسوم الإيداع 2.5%
- التوثيق 3DSecure إجباري
- لا تخزين بيانات البطاقة مطلقاً
- الحد الأقصى 5000 USD/day
- يتم تمرير الدفع عبر Stripe/PayTabs فقط
