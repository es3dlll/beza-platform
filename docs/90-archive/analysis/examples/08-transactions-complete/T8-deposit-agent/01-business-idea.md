# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية

إيداع وكيل في منصة Beza. 1. المستخدم يعطي نقداً للوكيل → 2. الوكيل يؤكد الاستلام → 3. إضافة للمستخدم → 4. خصم من الوكيل

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم في Beza
أريد: إيداع نقدي عبر وكيل معتمد
لكي: أشحن محفظتي نقداً بدون بطاقة بنكية
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | إيداع وكيل | الحالة |
|---|-------|--------|--------|
| 1 | إدخال رقم الوكيل | agent_phone | إجباري |
| 2 | تحديد المبلغ | amount | إجباري |
| 3 | تأكيد الوكيل | agent_confirmation | إجباري |
| 4 | إضافة للمستخدم | user_credit | atomic |
| 5 | خصم من الوكيل | agent_debit | atomic |

## تدفق الشاشات (User Flow)

```
1. المستخدم يعطي نقداً للوكيل →
│
 2. الوكيل يؤكد الاستلام →
│
 3. إضافة للمستخدم →
│
 4. خصم من الوكيل
```

## القواعد الأساسية

- الحد الأقصى للإيداع النقدي 1000 USD/day
- يجب أن يكون الوكيل نشطاً
- يجب أن يكون لدى الوكيل رصيد كافٍ (للتسليم)
- يؤكد الوكيل استلام النقد عبر تطبيقه
