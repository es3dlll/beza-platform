# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية
لوحة تحكم شاملة للوكيل تعرض إحصائيات الأداء، آخر النشاطات، العمولات المتراكمة، وإمكانية التحكم بحالة التوفر.

## سيناريو المستخدم
```
بصفتي: وكيل Beza معتمد
أريد: الاطلاع على إحصائيات أدائي وعمولاتي
لكي: أتابع نشاطي اليومي وأعرف أرباحي
```

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | عرض إجمالي عدد المعاملات (total_transactions) | إجباري |
| 2 | عرض حجم التداول الكلي (total_volume) | إجباري |
| 3 | عرض العمولات المتراكمة (commission_earned) | إجباري |
| 4 | عرض معاملات ومعاملات اليوم (today_count/today_volume) | إجباري |
