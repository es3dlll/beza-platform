# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية
تمكين العملاء من العثور على أقرب وكيل Beza عبر خريطة تفاعلية، مع عرض الموقع الجغرافي والتوفر وحالة الاتصال لكل وكيل.

## سيناريو المستخدم
```
بصفتي: عميل Beza
أريد: العثور على أقرب وكيل معتمد بالقرب مني
لكي: أتمكن من إيداع أو سحب النقود بشكل مباشر
```

## تدفق المستخدم (User Flow)
```
┌──────────────┐
│  العميل يفتح │
│  الخريطة     │
└──────┬───────┘
       ▼

│            خريطة الوكلاء                     │
│                                            │
│     📍 أنت هنا                              │
│        📍 وكيل أحمد (0.5 كم) 🟢            │
│           📍 وكيلة سارة (1.2 كم) 🟢        │
│              📍 وكيل خالد (2.0 كم) 🔴      │

└────────────────────────────────────────────┘
       │

│  بطاقة الوكيل:                             │

│  التقييم: ⭐ 4.8                          │
│  [📍 توجه إلى الوكيل]                      │
└────────────────────────────────────────────┘
```

## قبول السيناريو (Acceptance Criteria)
| # | الشرط | الحالة |
|---|-------|--------|
| 1 | عرض خريطة بالوكلاء القريبين (nearby agents) | إجباري |
| 2 | تحديد نطاق البحث بالكيلومتر (radius) | إجباري |
| 3 | فلتر إظهار الوكلاء المتاحين فقط (available) | إجباري |
| 4 | عرض المسافة بين العميل والوكيل (distance) | إجباري |
| 5 | تحديث موقع الوكيل في الوقت الفعلي | إجباري |
| 6 | تفاصيل الوكيل عند النقر على الماركر (marker) | إجباري |
| 7 | تبديل حالة الوكيل بين متاح/غير متاح | إجباري |
| 8 | البحث بإحداثيات (lat/lng) بدلاً من العنوان | إجباري |
| 9 | إظهار الوكلاء غير المتاحين بشكل مختلف (رمادي) | واجهة |
| 10 | التعامل مع عدم وجود وكلاء قريبين (empty state) | حافة |
