# 03 - تدفق البيانات (Data Flow Sequence) - بوابة الدفع (Payment Gateway)

```
  Merchant         API            LinkService        MySQL         Customer        Webhook
     │              │                  │                │               │              │
     │ POST /link   │                  │                │               │              │
     │------------->│                  │                │               │              │
     │              │  Create link     │                │               │              │
     │              │----------------->│                │               │              │
     │              │  Freeze amount   │--------------->│               │              │
     │              │  Return link URL │                │               │              │
     │<-------------│                  │                │               │              │
     │  Send URL    │                  │                │               │              │
     │-------------┼──────────────────────────────────────────────>│              │
     │              │                  │   GET /pay/token            │              │
     │              │                  │<-----------------------------│              │
     │              │  POST /pay       │                │               │              │
     │              │                  │<-----------------------------│              │
     │              │  Process payment │                │               │              │
     │              │----------------->│                │               │              │
     │              │  Unfreeze        │--------------->│               │              │
     │              │  Webhook         │-------------------------------------------->│
     │              │  Redirect        │                │               │              │
     │              │                  │<-----------------------------│              │
```

## شرح التدفق
1. التاجر ينشئ رابط دفع مع تحديد المبلغ والعملة
2. PaymentLinkService يقوم بتجميد المبلغ في محفظة التاجر
3. العميل يتلقى الرابط وينقر عليه لفتح صفحة الدفع
4. بعد الدفع، يتم فك التجميد وخصم المبلغ من المحفظة
5. يتم إرسال Webhook للتاجر مع تأكيد الدفع
