# 01 - فكرة العمل - تسوية رصيد التاجر (Settlement)

## الفكرة الأساسية
نظام التسوية البنكية يسمح للتاجر بتحويل رصيده من محفظة Beza الإلكترونية إلى حسابه البنكي الشخصي بشكل دوري أو فوري. هذا يمكن التاجر من سحب أرباحه نقداً واستخدامها في أعماله اليومية.

## سيناريو المستخدم الكامل
```
بصفتي: تاجر على منصة Beza
أريد: تسوية رصيدي وتحويله إلى حسابي البنكي
لكي: أحصل على أرباحي نقداً في البنك وأستخدمها في أعمالي
```

### خطوات التدفق الكامل للتسوية:

| الخطوة | الوصف | التوقيت |
|--------|-------|---------|
| 1 | النظام يحسب إجمالي مبيعات التاجر في الدورة | منتصف الليل (تلقائي) |
| 2 | خصم عمولة Beza (حسب شريحة التاجر) | تلقائي |
| 3 | خصم رسوم التحويل البنكي (1%) | تلقائي |
| 4 | خصم قيمة المرتجعات والتصريفات إن وجدت | تلقائي |
| 5 | التحقق من الحد الأدنى للتسوية (50 USD أو ما يعادله) | تلقائي |
| 6 | إنشاء طلب تسوية بحالة `pending` | تلقائي |
| 7 | تنفيذ التحويل البنكي عبر مزود الخدمة (Bank Gateway) | API |
| 8 | تحديث الحالة إلى `completed` أو `failed` | بعد تنفيذ التحويل |
| 9 | إشعار التاجر بنتيجة التسوية (FCM + Email + SMS) | فوري |
| 10 | تحديث رصيد محفظة التاجر بعد الخصم | ذري |

## أنواع التسوية

### 1. التسوية الفورية (Instant Settlement)
```php
// تسوية فورية - متاحة للتجار المميزين (Tier 1)
$settlement = MerchantSettlement::create([
    'merchant_id'    => $merchant->id,
    'type'           => 'instant',
    'gross_amount'   => 1250.00,
    'commission'     => 25.00,      // 2%
    'transfer_fee'   => 12.50,      // 1%
    'net_amount'     => 1212.50,
    'status'         => 'processing',
]);

// التحويل خلال 30 دقيقة
```

### 2. التسوية اليومية (Daily Settlement)
```
تتم كل يوم في منتصف الليل (00:00)
- المبيعات المتراكمة خلال اليوم
- مناسبة للتجار ذو الحجم المتوسط
- رسوم: 2% عمولة Beza + 1% تحويل بنكي
```

### 3. التسوية الأسبوعية (Weekly Settlement)
```php
// تسوية أسبوعية - كل يوم أحد
Schedule::weeklyOn(0, '00:00')->call(function () {
    MerchantSettlementService::processSettlements('weekly');
});
```

### 4. التسوية الشهرية (Monthly Settlement)
```
تتم في أول يوم من كل شهر
- تحتسب جميع مبيعات الشهر الماضي
- رسوم مخفضة: 1.5% عمولة Beza + 0.5% تحويل بنكي
- مناسبة للتجار الكبار (Tier 3)
```

## سيناريوهات شرائح التجار المختلفة

| الشريحة | حجم المبيعات الشهري | نوع التسوية المتاحة | رسوم Beza | رسوم التحويل |
|---------|--------------------|--------------------|-----------|-------------|
| Tier 1 (صغير) | < 5,000 USD | يومي، أسبوعي | 2.5% | 1% |
| Tier 2 (متوسط) | 5,000 - 50,000 USD | يومي، أسبوعي، شهري | 2.0% | 0.75% |
| Tier 3 (كبير) | > 50,000 USD | فوري، يومي، أسبوعي، شهري | 1.5% | 0.5% |

```php
// تحديد شريحة التاجر لحساب الرسوم
public function calculateFee(Merchant $merchant, float $amount): array
{
    $tier = match (true) {
        $merchant->monthly_volume > 50000 => 3,
        $merchant->monthly_volume > 5000  => 2,
        default                           => 1,
    };

    $commissionRates = [1 => 2.5, 2 => 2.0, 3 => 1.5];
    $transferRates   = [1 => 1.0, 2 => 0.75, 3 => 0.5];

    return [
        'commission_percentage' => $commissionRates[$tier],
        'transfer_fee_percentage' => $transferRates[$tier],
    ];
}
```

## شروط القبول (Acceptance Criteria)

| # | الشرط | معيار النجاح |
|---|-------|-------------|
| 1 | طلب تسوية رصيد التاجر | إنشاء settlement بحالة `pending` |
| 2 | حساب المبلغ (المبيعات - الرسوم - المرتجعات) | الحساب مطابق لتقرير المبيعات |
| 3 | الحد الأدنى للتسوية 50 USD | رفض الطلب إذا كان < 50 USD |
| 4 | دورة التسوية (فوري/يومي/أسبوعي/شهري) | التنفيذ حسب الجدول المحدد |
| 5 | رسوم تحويل بنكي 1% (حسب الشريحة) | الخصم مطابق لنسبة الشريحة |
| 6 | تحويل بنكي وتحديث الرصيد | خصم الرصيد بعد نجاح التحويل |
| 7 | إشعار التاجر بنتيجة التسوية | وصول الإشعار عبر جميع القنوات |
| 8 | معالجة فشل التحويل البنكي | إعادة الرصيد للمحفظة + إشعار |
