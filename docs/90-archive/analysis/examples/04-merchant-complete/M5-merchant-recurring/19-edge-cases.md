# 19 - حالات الحافة (Edge Cases) للاشتراكات المتكررة

## نظرة عامة
هذا المستند يغطي جميع الحالات النادرة والشاذة التي قد تحدث أثناء دورة حياة الاشتراك المتكرر، مع حلول معتمدة لكل حالة.

## 1. العميل يحذف حسابه في منتصف الاشتراك

```
السيناريو: عميل لديه اشتراك نشط (متبقي 6 دورات)، ثم يحذف حسابه من المنصة.

الإجراء:
1. النظام يكتشف حدث حذف الحساب
2. إلغاء الاشتراك فوراً بحالة `cancelled`
3. إلغاء جميع المدفوعات المجدولة مستقبلاً
4. إشعار التاجر بإلغاء الاشتراك
5. الاحتفاظ بسجل المدفوعات السابقة للأرشفة

ملاحظة: إذا كان هناك رصيد مستحق للعميل، يتم تحويله حسب سياسة المنصة.
```

```php
// معالجة حذف الحساب مع اشتراك نشط
$user->delete(); // Soft Delete
MerchantSubscription::where('customer_id', $user->id)
    ->where('status', 'active')
    ->update(['status' => 'cancelled', 'cancelled_at' => now(), 'cancelled_by' => 'system']);
```

## 2. رصيد غير كافٍ لـ 3 أشهر متتالية

```
السيناريو: اشتراك شهري بقيمة 100 USD، رصيد العميل صفر للأشهر: يناير، فبراير، مارس.

الإجراء:
- الشهر 1: فشل → retry (3 محاولات) → فشل → تسجيل
- الشهر 2: فشل → retry → فشل → إشعار بأن الاشتراك سيُعلق
- الشهر 3: فشل → retry → فشل → إيقاف الاشتراك تلقائياً → إشعار العميل والتاجر

النتيجة: حالة الاشتراك → `suspended`، يمكن إعادة التنشيط بعد الدفع.
```

```php
// كشف 3 أشهر متتالية من الفشل
$failedMonths = SubscriptionCharge::where('subscription_id', $sub->id)
    ->where('status', 'failed')
    ->where('created_at', '>=', now()->subMonths(3))
    ->count();

if ($failedMonths >= 3) {
    $sub->update(['status' => 'suspended']);
    event(new SubscriptionSuspended($sub, 'insufficient_balance_3_months'));
}
```

## 3. التاجر يغير السعر في منتصف الدورة

```
السيناريو: التاجر يريد تغيير سعر الاشتراك من 100 USD إلى 150 USD
           بعد أن دفع العميل 3 دورات من أصل 12.

الإجراء:
- لا يمكن تغيير سعر الاشتراك الحالي mid-cycle
- التاجر يقوم بإنشاء اشتراك جديد بالسعر الجديد
- العميل يوافق على الاشتراك الجديد
- إلغاء الاشتراك القديم بعد انتهاء دورته الحالية
```

```php
// الحل: إنشاء اشتراك جديد بدلاً من تعديل المبلغ
$newSubscription = MerchantSubscription::create([
    'merchant_id'    => $merchant->id,
    'customer_phone' => $customer->phone,
    'amount'         => 150.00,
    'currency'       => 'USD',
    'interval'       => 'monthly',
    'max_cycles'     => 12,
    'status'         => 'pending',
]);

// إلغاء القديم بعد الدورة الحالية
$oldSubscription->update(['max_cycles' => $oldSubscription->current_cycle]);
```

## 4. الفوترة النسبية (Prorated Billing)

```
السيناريو: عميل اشترك في اليوم 15 من الشهر (نصف الشهر متبقي).
           كيف يتم حساب أول دفعة؟

الحل: الفوترة النسبية تحتسب الأيام المتبقية من الشهر الأول.
      المبلغ = (السعر الشهري / 30) * الأيام المتبقية
      ثم يتم الانتظام على السعر الكامل في الشهر التالي.

مثال: اشتراك 100 USD/شهر، بدأ في 15 مارس (16 يوم متبقي)
      الدفعة الأولى = (100 / 30) * 16 = 53.33 USD
      الدفعة الثانية (1 أبريل) = 100 USD
```

```php
public function calculateProratedAmount(MerchantSubscription $sub): float
{
    $daysInMonth = now()->daysInMonth;
    $remainingDays = $daysInMonth - now()->day + 1;
    return round(($sub->amount / $daysInMonth) * $remainingDays, 2);
}
```

## 5. تغيير العملة (Currency Change)

```
السيناريو: الاشتراك كان بـ USD، والتاجر يريد تحويله إلى EUR.

الإجراء:
1. إيقاف الاشتراك الحالي (لا يُلغى، يُجمد)
2. إنشاء اشتراك جديد بالعملة الجديدة
3. تحويل سعر الصرف حسب سعر اليوم
4. العميل يوافق على الاشتراك الجديد
5. نقل سجل المدفوعات السابقة للتوثيق

تحذير: لا يمكن خلط عملتين في نفس الاشتراك مطلقاً.
```

## 6. استنفاذ محاولات إعادة الدفع (Retry Exhaustion)

```
السيناريو: فشلت جميع محاولات إعادة الدفع الثلاث (بعد ساعة، 6 ساعات، 24 ساعة).

الإجراء عند استنفاذ المحاولات:
1. تحديث حالة الاشتراك إلى `payment_failed`
2. إرسال إشعار نهائي للعميل: "فشلت محاولات الدفع، يرجى إعادة شحن الرصيد"
3. إرسال إشعار للتاجر: "العميل X لديه اشتراك متوقف"
4. جدولة مهمة لمراجعة الاشتراك بعد 7 أيام
5. إذا لم يتم الدفع بعد 7 أيام → إلغاء الاشتراك تلقائياً
```

| # | الحالة | النتيجة | رمز HTTP |
|---|--------|---------|----------|
| 1 | دون موافقة العميل | `pending` | 200 |
| 2 | رصيد غير كافٍ | `failed` → retry (3 محاولات) | 200 |
| 3 | إلغاء من العميل | `cancelled` | 200 |
| 4 | الوصول لـ max_cycles | `completed` | 200 |
| 5 | تغيير المبلغ في الاشتراك | اشتراك جديد مطلوب | 422 |
| 6 | حذف حساب العميل | `cancelled` + إشعار تاجر | 200 |
| 7 | 3 أشهر فشل متتالي | `suspended` | 200 |
| 8 | استنفاذ retry | `payment_failed` | 402 |
| 9 | تغيير العملة | تجميد + اشتراك جديد | 422 |
| 10 | فوترة نسبية | خصم نسبة من المبلغ | 200 |
