# 01 - فكرة المشروع - إدارة البطاقة (Card Management)

## الفكرة الأساسية
تمكين مستخدمي Beza من إدارة بطاقاتهم المصدرة: تحديث الحدود اليومية، حظر/إلغاء حظر البطاقة، الإبلاغ عن الفقدان، وعرض سجل المعاملات المرتبطة بكل بطاقة.

## سيناريو المستخدم
```
بصفتي: حامل بطاقة Beza
أريد: إدارة إعدادات بطاقتي والتحكم بها
لكي: أتمكن من تأمين بطاقتي عند الحاجة وتتبع استخدامي
```

## تدفق المستخدم (User Flow)
```
┌──────────────┐    ┌───────────────────┐    ┌─────────────────┐
│  قائمة       │───▶│  اختيار بطاقة     │───▶│  إدارة البطاقة  │
│  البطاقات    │    │  من القائمة       │    │  (Limit/Block/  │
│              │    │                   │    │  Report Lost)   │
└──────────────┘    └───────────────────┘    └────────┬────────┘
                                                      │
                           ┌──────────────────────────┼──────────────────┐
                           ▼                          ▼                  ▼
                   ┌──────────────┐          ┌──────────────┐  ┌───────────────────┐
                   │ تحديث الحد   │          │  حظر/إلغاء   │  │ الإبلاغ عن فقدان  │
                   │ اليومي       │          │  حظر         │  │ ← إصدار بديل     │
                   └──────────────┘          └──────────────┘  └───────────────────┘
```

## قبول السيناريو (Acceptance Criteria)
| # | الشرط | الحالة |
|---|-------|--------|
| 1 | عرض تفاصيل البطاقة مع PAN مخفي | إجباري |
| 2 | تحديث الحد اليومي (daily_limit) | إجباري |
| 3 | حظر البطاقة (تغيير الحالة إلى blocked) | إجباري |
| 4 | إلغاء حظر البطاقة (إعادة الحالة إلى active) | إجباري |
| 5 | الإبلاغ عن فقدان البطاقة (تغيير إلى lost) | إجباري |
| 6 | إصدار بطاقة بديلة تلقائياً عند الإبلاغ عن فقدان | تلقائي |
| 7 | عرض سجل معاملات البطاقة مع التقسيم والصفحات | إجباري |
| 8 | إرسال إشعار عند حظر/إلغاء حظر البطاقة | إعلامي |
| 9 | منع غير مالك البطاقة من إدارتها | أمني |
| 10 | التحقق من أن الحد الجديد ضمن المسموح (1000-500000) | تحقق |
