# 01 - فكرة المشروع - تقارير البطاقة (Card Reports)

## الفكرة الأساسية
تقديم تقارير وتحليلات شاملة لأنماط إنفاق المستخدم عبر البطاقة، مع إمكانية التصدير والتصفية حسب الفترة والفئة.

## سيناريو المستخدم
```
بصفتي: حامل بطاقة Beza
أريد: الاطلاع على تقارير إنفاقي الشهرية والتصدير
لكي: أتمكن من تتبع ميزانيتي وفهم أين تذهب أموالي
```

## تدفق المستخدم (User Flow)
```
┌────────────────┐    ┌──────────────────┐    ┌───────────────────┐
│  اختيار بطاقة  │───▶│  اختيار نوع      │───▶│  عرض التقرير     │
│  من القائمة    │    │  التقرير         │    │  مع خيار التصدير │
└────────────────┘    └──────┬───────────┘    └───────────────────┘
                             │
          ┌──────────────────┼──────────────────┐
          ▼                  ▼                  ▼
   ┌────────────┐   ┌──────────────┐   ┌────────────────┐
   │ ملخص عام   │   │ توزيع شهري   │   │ إنفاق حسب      │
   │ + رسم بياني│   │ + مقارنة     │   │ الفئة (نسبة)   │
   └────────────┘   └──────────────┘   └────────────────┘
```

## قبول السيناريو (Acceptance Criteria)
| # | الشرط | الحالة |
|---|-------|--------|
| 1 | عرض ملخص الإنفاق (الإجمالي، عدد المعاملات، المعدل اليومي) | إجباري |
| 2 | تصفية التقرير حسب نطاق تاريخ (from/to) | إجباري |
| 3 | عرض توزيع الإنفاق الشهري (monthly breakdown) | إجباري |
| 4 | عرض الإنفاق حسب الفئة (category) مع النسبة المئوية | إجباري |
| 5 | تصدير التقرير بصيغ CSV / PDF / XLSX | إجباري |
| 6 | التعامل مع البطاقات بدون معاملات (إرجاع 0) | حافة |
| 7 | منع الوصول لتقارير بطاقات الآخرين | أمني |
| 8 | تحديث البيانات فوراً عند إجراء معاملة جديدة | فوري |
| 9 | تخزين التقارير المُصدرة للتحميل لاحقاً | تحسين |
