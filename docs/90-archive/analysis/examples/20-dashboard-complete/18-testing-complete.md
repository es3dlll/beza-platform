## اختبارات API (Integration)

```bash
# اختبار جلب الرصيد
curl -X GET http://localhost:8000/api/v1/wallet/balance \
  -H "Authorization: Bearer $TOKEN"

# اختبار التحويل
curl -X POST http://localhost:8000/api/v1/transfer \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"to_phone":"963944654321","amount":10,"currency":"USD","pin":"1234"}'

# اختبار الصرف
curl -X POST http://localhost:8000/api/v1/wallet/exchange \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"from":"USD","to":"SYP","amount":10}'
```
