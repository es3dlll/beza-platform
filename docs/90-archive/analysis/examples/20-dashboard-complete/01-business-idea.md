# 01 - فكرة العمل وسيناريو المستخدم (Business Idea & User Scenario)

## الفكرة الأساسية

المستخدم يفتح تطبيق SAKK، يرى كل شيء في نظرة واحدة:
1. رصيده + رمز QR لاستقبال الأموال
2. أسعار الصرف الفوري وتحويل سريع
3. أزرار الإجراءات السريعة (إرسال، استقبال، بطاقات، ذهب)
4. آخر المعاملات

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم في SAKK
أريد: لوحة رئيسية شاملة تعرض رصيدي وأدواتي المالية
لكي: أدير أموالي بسرعة دون التنقل بين صفحات متعددة
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | عرض رصيد المحفظة (SYP/USD) مع إمكانية إخفائه | مكتمل |
| 2 | عرض QR code خاص بالمستخدم لاستقبال الأموال | مكتمل |
| 3 | عرض رقم الحساب مع زر نسخ | مكتمل |
| 4 | أزرار الإجراءات السريعة (إرسال، بطاقات، استقبال، ذهب) | مكتمل |
| 5 | تحية زمنية (صباح الخير/مساء الخير) + اسم المستخدم | مكتمل |
| 6 | تاريخ عربي ديناميكي | مكتمل |
| 7 | قائمة الإشعارات منسدلة مع أيقونات ملونة | مكتمل |
| 8 | تحويل العملات (USD ↔ SYP) بنقرة واحدة | مكتمل |
| 9 | آخر المعاملات في قائمة سريعة | مكتمل |
| 10 | لوحة إرسال سفلية (Bottom Sheet) | مكتمل |
| 11 | لوحة استقبال سفلية (Bottom Sheet) | مكتمل |
| 12 | تنبيه KYC قابل للإخفاء | مكتمل |

## تدفق الشاشات (User Flow)

```
[تسجيل الدخول] → [Dashboard]
                    ├── [إرسال] → Bottom Sheet → تحويل
                    ├── [بطاقات] → /cards
                    ├── [استقبال] → Bottom Sheet → QR / رقم الحساب
                    ├── [ذهب وفضة] → /gold-silver
                    ├── [الإشعارات] → Dropdown ← /notifications/:id
                    ├── [صرف فوري] → تحويل عملات ← رسالة نجاح/فشل
                    ├── [المعاملات] → قائمة ← /transactions
                    └── [KYC] → /kyc ← إخفاء
```
