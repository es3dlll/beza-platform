# 05 - نظام الألوان والثيم (Theme & Styling)

## هوية SAKK البصرية

```css
/* الألوان الأساسية */
--navy-dark:    #080c1a;    /* الخلفية الرئيسية */
--navy-card:    #0f1730;    /* خلفية البطاقات */
--navy-deeper:  #0a0e22;    /* تدرج البطاقات */
--gold:         #F5A623;    /* اللون الذهبي (accent) */
--gold-dark:    #d48a10;    /* تدرج ذهبي غامق */
--glass:        rgba(232,237,245,0.12);  /* نص شفاف */
--glass-dim:    rgba(232,237,245,0.06);  /* نص خافت */
--glass-bright: #E8EDF5;    /* نص ساطع */
--white-glass:  rgba(255,255,255,0.015); /* خلفيات شفافة */
```

## Glassmorphism (الزجاجية)

جميع البطاقات والمكونات تستخدم تأثير الزجاج:

```jsx
style={{
  background: 'rgba(255,255,255,0.02)',
  border: '1px solid rgba(255,255,255,0.04)',
  backdropFilter: 'blur(24px)',
}}
```

## تدرجات ذهبية (Gold Gradients)

| الاستخدام | التدرج |
|-----------|--------|
| أزرار CTA | `linear-gradient(135deg, #F5A623, #d48a10)` |
| ظل الأزرار | `0 4px 20px rgba(245,166,35,0.12)` |
| فاصل AppBar | `linear-gradient(90deg, rgba(245,166,35,0.06), rgba(245,166,35,0.12), rgba(245,166,35,0.06))` |
| خلفية المحفظة | `radial-gradient(circle, #F5A623 0%, transparent 50%)` |
| زوايا QR | `3px solid rgba(245,166,35,0.3)` |

## ألوان حالة المعاملات

| الحالة | اللون | الاستخدام |
|--------|-------|-----------|
| وارد (in) | أخضر `rgba(34,197,94,0.X)` | أيقونات + مبالغ |
| صادر (out) | أحمر `rgba(239,68,68,0.X)` | أيقونات + مبالغ |
| ذهبي | `#F5A623` | أيقونات الصرف والسعر |
| نظامي | أرجواني `rgba(99,102,241,0.X)` | إشعارات النظام |
