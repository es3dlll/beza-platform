# 01 - فكرة الموافقة على التجار والوكلاء

## الفكرة الأساسية

التجار والوكلاء يحتاجون موافقة المشرف قبل استخدام خدمات المنصة:
1. **تقديم طلب** — المستخدم يملأ بياناته ويرفع المستندات
2. **مراجعة** — المشرف يراجع الطلب والمستندات
3. **موافقة** — تفعيل حساب التاجر/الوكيل
4. **رفض** — مع إرسال سبب الرفض وطلب مستندات إضافية

## سيناريو المستخدم (User Story)

```
بصفتي: مشرف منصة Beza
أريد: مراجعة طلبات التجار والوكلاء والموافقة عليها
لكي: أضمن أن جميع التجار موثوقون ومستوفون للشروط
```

## قبول السيناريو

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | عرض قائمة طلبات التجار المعلقة | status = pending |
| 2 | عرض قائمة طلبات الوكلاء المعلقة | status = pending |
| 3 | عرض المستندات المرفوعة | صور، تراخيص |
| 4 | الموافقة على طلب | merchant.status = active |
| 5 | الرفض مع سبب | merchant.status = rejected |
| 6 | طلب مستندات إضافية | إشعار لمقدم الطلب |
| 7 | إشعار مقدم الطلب بالنتيجة | FCM + Email |
| 8 | الموافقة تغير user.is_merchant | true |
