# 19 - حالات الحافة (Edge Cases)

## 1. قيمة إعداد غير صحيحة
**المشكلة**: إدخال نص في حقل رقمي.
**الحل**: Validation + type casting في Setting model.

## 2. سعر صرف = 0
**المشكلة**: وضع سعر صرف بصفر → تقسيم على صفر.
**الحل**: Validation rule `min:1`.

## 3. رسوم سلبية
**المشكلة**: وضع رسوم -5%.
**الحل**: Validation rule `min:0`.

## 4. تفعيل الصيانة أثناء وجود معاملات نشطة
**المشكلة**: مستخدمون في منتصف معاملة.
**الحل**: السماح بإكمال المعاملات الحالية + منع الجديدة.

## 5. Cache قديم بعد التحديث
**المشكلة**: الخوادم الأخرى لا تزال ترى القيمة القديمة.
**الحل**: `Cache::forget()` + `Cache::remember()` مع TTL قصير.

## 6. تحديث إعداد لا وجود له
**المشكلة**: محاولة تحديث `fee_invalid`.
**الحل**: تجاهل المفاتيح غير المعروفة (أو التحقق من القائمة المسموحة).
