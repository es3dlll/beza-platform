# 01 - فكرة إعدادات النظام (Business Idea)

## الفكرة الأساسية

المشرف يحتاج إلى تعديل إعدادات المنصة ديناميكياً دون الحاجة لتعديل الكود:
1. **الرسوم** — تعديل نسب رسوم المعاملات
2. **الحدود** — تعديل الحدود اليومية للتحويل والإيداع
3. **أسعار الصرف** — تحديث سعر صرف SYP/USD والهامش
4. **إعدادات عامة** — وضع الصيانة، متطلبات KYC

## سيناريو المستخدم

```
بصفتي: مشرف منصة Beza
أريد: تعديل إعدادات المنصة بسرعة
لكي: أتحكم في رسوم وحدود المنصة دون الحاجة لتعديل الكود
```

## قبول السيناريو

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | عرض جميع الإعدادات الحالية | GET /settings |
| 2 | تعديل رسوم التحويل | PUT /settings/fees |
| 3 | تعديل الحدود اليومية | PUT /settings/limits |
| 4 | تعديل سعر الصرف | PUT /settings/exchange-rate |
| 5 | تفعيل/تعطيل وضع الصيانة | PUT /settings |
| 6 | تفعيل/تعطيل اشتراط KYC | PUT /settings |
| 7 | الإعدادات تُطبق فوراً | بدون إعادة تشغيل |
