# 01 - فكرة النزاعات (Business Idea)

## الفكرة الأساسية

عند حدوث مشكلة في معاملة (تحويل خاطئ، خدمة غير مكتملة)، يمكن للمستخدم تقديم نزاع:
1. **تقديم نزاع** — المستخدم يرفع شكوى مع أدلة
2. **مراجعة** — المشرف يفتح النزاع ويراجع التفاصيل
3. **قرار** — استرجاع كامل أو جزئي أو رفض
4. **إشعار** — إبلاغ الطرفين بالقرار

## سيناريو المستخدم

```
بصفتي: مستخدم Beza
أريد: تقديم نزاع على معاملة لم تتم بشكل صحيح
لكي: أسترد أموالي أو أحصل على حل عادل
```

## قبول السيناريو

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | المستخدم يقدم نزاع مع transaction_id | POST /disputes |
| 2 | رفع ملفات إثبات (صور) | evidence_files |
| 3 | المشرف يفتح النزاع ويرى التفاصيل | GET /admin/disputes |
| 4 | المشرف يتخذ قرار (refund/reject) | POST /resolve |
| 5 | الـ refund يخصم من التاجر ويضاف للعميل | Atomic |
| 6 | إشعار الطرفين بالقرار | FCM + Email |
| 7 | إغلاق تلقائي بعد 48 ساعة | Cron |
