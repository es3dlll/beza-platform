# 19 - حالات الحافة (Edge Cases)

## 1. يوم بدون معاملات
**المشكلة**: لا توجد معاملات في التاريخ المحدد.
**الحل**: إرجاع أصفار بدلاً من خطأ.

## 2. فترة زمنية طويلة جداً
**المشكلة**: طلب تقرير مالي لـ 5 سنوات.
**الحل**: حد أقصى 365 يوماً.

## 3. بيانات غير متسقة (معاملات قيد التنفيذ)
**المشكلة**: معاملات pending أو processing تظهر في التقرير.
**الحل**: فلترة WHERE status = 'completed'.

## 4. فرق التوقيت
**المشكلة**: `today()` يختلف حسب توقيت السيرفر.
**الحل**: ضبط Asia/Damascus + استخدام UTC في DB.

## 5. أرقام كبيرة جداً
**المشكلة**: overflow في SUM.
**الحل**: DECIMAL(15,2) كافٍ للحجم المتوقع.

## 6. تقرير شهري في أول الشهر
**المشكلة**: طلب تقرير شهر 5 في يوم 1 — البيانات قليلة.
**الحل**: عرض البيانات المتاحة + مقارنة بالأمس فقط.

## 7. تصدير CSV لأكثر من 10000 صف
**المشكلة**: الأداء مع حجم بيانات كبير.
**الحل**: توليد في الخلفية + إشعار عند الانتهاء (queue).

| # | الحالة | النتيجة | الحل |
|---|--------|---------|------|
| 1 | يوم بدون معاملات | 200 مع أصفار | default 0 |
| 2 | فترة > 365 يوم | 422 | Validation |
| 3 | معاملات pending | تجاهل | status=completed |
| 4 | توقيت خاطئ | Asia/Damascus | Config |
| 5 | Overflow | DECIMAL كافٍ | DB type |
