# 01 - فكرة التقارير (Business Idea)

## الفكرة الأساسية

المشرف يحتاج تقارير دقيقة عن أداء المنصة:
1. **تقرير يومي** — معاملات اليوم، إيرادات، مستخدمون جدد
2. **تقرير شهري** — نمو شهري، MAU، GMV، مقارنة بالشهر السابق
3. **تقرير مالي** — P&L، هامش الربح، تحليل الرسوم والتكاليف

## سيناريو المستخدم

```
بصفتي: مشرف منصة Beza
أريد: تقارير دقيقة يومية وشهرية ومالية
لكي: أتابع أداء المنصة وأتخذ قرارات استراتيجية
```

## قبول السيناريو

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | تقرير يومي: إجمالي المعاملات + الإيرادات + مستخدمون جدد | GET /reports/daily |
| 2 | تقرير شهري: مقارنة بالشهر السابق | GET /reports/monthly |
| 3 | تقرير مالي: P&L + تحليل رسوم | GET /reports/financial |
| 4 | تصدير CSV/Excel | format=excel |
| 5 | فلترة حسب التاريخ | date, from, to |
| 6 | توليد تلقائي يومي (cron) | daily at 00:05 |
