# 01 - فكرة لوحة تحكم المشرف (Business Idea)

## الفكرة الأساسية

المشرف "خالد" يحتاج إلى رؤية شاملة لأداء المنصة في لمحة سريعة. لوحة التحكم تقدم:
1. **مؤشرات الأداء** — أعداد المستخدمين، المعاملات، المحافظ
2. **رسوم بيانية** — نمو شهري، إيرادات، حجم معاملات
3. **محدثة تلقائياً** — كل 30 ثانية دون إعادة تحميل الصفحة
4. **مخزنة مؤقتاً** — 5 دقائق لتقليل ضغط DB

## سيناريو المستخدم (User Story)

```
بصفتي: مشرف منصة Beza
أريد: رؤية إحصائيات المنصة في لوحة تحكم واحدة
لكي: أتخذ قرارات إدارية بناءً على بيانات حية
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | عرض إجمالي المستخدمين | من جدول users |
| 2 | عرض المستخدمين النشطين يومياً | last_login_at = today |
| 3 | عرض إجمالي المعاملات | COUNT(transactions) |
| 4 | عرض حجم المعاملات | SUM(amount) |
| 5 | عرض إجمالي أرصدة المحافظ | SUM(balance) |
| 6 | عرض عدد التجار | COUNT(is_merchant) |
| 7 | عرض عدد الوكلاء | COUNT(is_agent) |
| 8 | رسم بياني للإيرادات آخر 30 يوم | Line Chart |
| 9 | رسم بياني لحجم المعاملات آخر 30 يوم | Bar Chart |
| 10 | رسم بياني لنمو المستخدمين آخر 30 يوم | Area Chart |
| 11 | جدول أعلى 5 تجار | حسب حجم المعاملات |
| 12 | تحديث تلقائي كل 30 ثانية | refetchInterval |
