   │                    │                     │<───────────────────│            │

## جدول زمني

| الخطوة | الزمن |
|--------|-------|
| قائمة المستخدمين (صفحة واحدة) | ~50ms |
| تفاصيل مستخدم + محافظ + معاملات | ~30ms |
| تغيير حالة مستخدم | ~20ms |
