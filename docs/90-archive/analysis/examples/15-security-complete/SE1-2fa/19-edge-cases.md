## 3. المستخدم يغير هاتفه

```
الإجراءات:
1. تعطيل 2FA باستخدام رمز استرداد (إذا كان موجوداً)
2. أو توثيق الهوية عبر KYC
3. تفعيل 2FA من جديد
```

## 4. مهلة رمز 2FA

```php
// رمز 2FA صالح لمدة 30 ثانية فقط
// الرمز المستخدم يرفض فوراً (Replay Attack Protection)
public function verifyCode($secret, $code): bool
{
    return $this->google2fa->verifyKeyNewer(
        $secret, $code, session('last_2fa_timestamp')
    ) !== false;
}
```

## 5. مستخدمون متعددون على نفس الجهاز

```
كل مستخدم لديه Secret مختلف
Google Authenticator يدعدة حسابات متعددة
```

## 6. متصفح جديد أو جهاز جديد

```
إرسال إشعار عند محاولة 2FA من جهاز جديد
يمكن إضافة "تذكر هذا الجهاز" (cookie لمدة 30 يوماً)
```
