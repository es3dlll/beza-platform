# 03 - تدفق المصادقة الثنائية (Authentication Flow)

## تفعيل 2FA

```
المستخدم            Flutter/React            API                GoogleAuth
  │                     │                    │                    │
  │ طلب تفعيل 2FA      │                    │                    │
  │────────────────────>│                    │                    │
  │                     │ POST /api/2fa/enable                   │
  │                     │───────────────────>│                    │
  │                     │                    │ توليد Secret      │
  │                     │                    │────────────────┐  │
  │                     │                    │                │  │
  │                     │  QR Code URL       │<───────────────┘  │
  │                     │<───────────────────│                    │
  │  عرض QR Code       │                    │                    │
  │<────────────────────│                    │                    │
  │                     │                    │                    │
  │ مسح QR بالـ        │                    │                    │
  │ Google Authenticator│                    │                    │
  │─────────────────────────────────────────────────────────────>│
  │                     │                    │                    │
  │ إدخال رمز التحقق   │                    │                    │
  │────────────────────>│                    │                    │
  │                     │ POST /api/2fa/verify(secret,code)      │
  │                     │───────────────────>│                    │
  │                     │                    │ رمز صحيح؟         │
  │                     │                    │────────────────┐  │
  │                     │                    │                │  │
  │                     │  ✔ مفعل + 8 رموز  │<───────────────┘  │
  │                     │<───────────────────│                    │
  │  حفظ رموز الاسترداد│                    │                    │
  │<────────────────────│                    │                    │
```

## استخدام 2FA في المعاملة

```
المستخدم            Flutter                API                2FA Service
  │                     │                    │                    │
  │ معاملة > 1000 USD  │                    │                    │
  │────────────────────>│                    │                    │
  │                     │ POST /api/transfer │                    │
  │                     │───────────────────>│                    │
  │                     │                    │ isRequired()       │
  │                     │                    │──────────────────>│
  │                     │                    │ 2FA مطلوب!        │
  │                     │                    │<──────────────────│
  │                     │  402 2FA Required  │                    │
  │                     │<───────────────────│                    │
  │ طلب إدخال رمز 2FA  │                    │                    │
  │<────────────────────│                    │                    │
  │                     │                    │                    │
  │ إدخال رمز 2FA      │                    │                    │
  │────────────────────>│                    │                    │
  │                     │ POST /api/transfer │                    │
  │                     │ + header: 2fa_code │                    │
  │                     │───────────────────>│                    │
  │                     │                    │ verifyCode()       │
  │                     │                    │──────────────────>│
  │                     │                    │ رمز صحيح          │
  │                     │                    │<──────────────────│
  │                     │  ✔ معاملة ناجحة   │                    │
  │                     │<───────────────────│                    │
```
