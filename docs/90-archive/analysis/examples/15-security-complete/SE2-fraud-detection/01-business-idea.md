# 01 - أهمية كشف الاحتيال (Business Idea)

## لماذا كشف الاحتيال؟

- حماية أموال المستخدمين
- الامتثال للوائح المالية
- منع غسيل الأموال
- بناء الثقة في المنصة

## قواعد الكشف الأساسية

| القاعدة | الوصف | الإجراء |
|---------|-------|---------|
| سرعة معاملات غير طبيعية | > 5 معاملات في الدقيقة | طلب 2FA + تأخير |
| تغيير IP فجأة | دخول من IP جديد | إشعار SMS + تأكيد |
| محاولات PIN خاطئة | 5 محاولات | قفل PIN 15 دقيقة |
| جهاز جديد | device_id غير معروف | OTP تأكيدي + 2FA |
| تغيير كلمة السر + معاملة كبيرة | خلال ساعة | تعليق المعاملة |
| معاملات فوق 5000 USD | حد المسؤولية | مراجعة يدوية |

## أنواع الاحتيال المستهدفة

1. **Account Takeover** — سرقة الحساب عبر كلمة المرور
2. **Phishing** — خداع المستخدم لإدخال بياناته
3. **Carding** — اختبار بطاقات مسروقة
4. **Money Laundering** — تحويلات متكررة لنفس الرقم
5. **Fake KYC** — وثائق هوية مزورة
