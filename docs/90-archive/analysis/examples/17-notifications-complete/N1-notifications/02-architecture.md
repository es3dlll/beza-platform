## المكونات

1. **NotificationController** - استقبال طلبات API
2. **NotificationService** - منطق الإرسال والتوجيه
3. **Channel Adapters** - تكامل مع كل قناة
4. **Queue System (Redis)** - معالجة غير متزامنة
5. **Database** - تخزين الإشعارات الداخلية
