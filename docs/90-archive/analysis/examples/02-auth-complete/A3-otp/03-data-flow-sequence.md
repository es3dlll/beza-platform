## سلسلة الاستدعاءات الكاملة — التحقق من OTP

```
  User              Flutter/React          Laravel API         OtpService        Redis           MySQL
   │                     │                     │                   │               │               │
   │  Enter OTP code     │                     │                   │               │               │
   │────────────────────>│                     │                   │               │               │
   │                     │                     │                   │               │               │
   │                     │  POST /auth/verify- │                   │               │               │
   │                     │  otp {phone, otp}   │                   │               │               │
   │                     │────────────────────>│                   │               │               │
   │                     │                     │                   │               │               │
   │                     │                     │  validate         │               │               │
   │                     │                     │                   │               │               │
   │                     │                     │  GET otp_{phone}  │               │               │
   │                     │                     │  from Cache       │               │               │
   │                     │                     │──────────────────>│──────────────>│               │
   │                     │                     │                   │               │               │
   │                     │                     │  Compare OTP      │               │               │
```
