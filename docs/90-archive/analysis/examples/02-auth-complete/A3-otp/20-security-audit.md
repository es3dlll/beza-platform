# 20 - أمان رمز التحقق OTP (Security Audit)

## 1. توليد الرمز
```php
// رمز عشوائي 6 أرقام — تخزين HASH في Redis
$otp = random_int(100000, 999999);
Cache::put('otp_' . $phone, Hash::make($otp), 300); // 5 دقائق
```

## 2. التحقق من الرمز
```php
// مقارنة HASH — حتى المسؤول لا يرى الرمز
if (!Hash::check($request->otp, Cache::get('otp_' . $phone))) { ... }
```

## 3. منع إعادة الاستخدام
```php
// حذف OTP بعد أول استخدام ناجح
Cache::forget('otp_' . $phone);
```
