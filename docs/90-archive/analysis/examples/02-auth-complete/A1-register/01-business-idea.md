# 01 - فكرة العمل وسيناريو المستخدم (Business Idea) — تسجيل مستخدم جديد (Register)

## الفكرة الأساسية

المستخدم "علي" يريد إنشاء حساب في منصة Beza للاستفادة من خدمات التحويل والدفع الرقمي. يحتاج إلى:
1. **تسجيل سريع** — إدخال الاسم، رقم الهاتف، كلمة المرور، PIN
2. **محفظة فورية** — يتم إنشاء محفظتين (SYP + USD) تلقائياً
3. **هدية ترحيب** — 5 USD تضاف فوراً لمحفظة USD
4. **رسالة ترحيب** — SMS يؤكد نجاح التسجيل

## سيناريو المستخدم (User Story)

```
بصفتي: مستخدم جديد في سوريا
أريد: إنشاء حساب في Beza
لكي: أتمكن من إرسال واستقبال الأموال رقمياً
```

## قبول السيناريو (Acceptance Criteria)

| # | الشرط | الحالة |
|---|-------|--------|
| 1 | إدخال الاسم (max 255 حرف) | إجباري |
| 2 | إدخال رقم الهاتف (09XXXXXXXX) | إجباري، unique، regex |
| 3 | إدخال كلمة المرور (min 8) | إجباري، confirmed |
| 4 | إدخال PIN (4 أرقام) | إجباري، confirmed |
| 5 | إنشاء المستخدم في جدول users | OK |
| 6 | إنشاء محفظة SYP (رصيد 0) تلقائياً | OK |
| 7 | إنشاء محفظة USD (رصيد 5) تلقائياً | OK |
| 8 | توليد UUID للمستخدم | OK |
| 9 | Hash لكلمة المرور و PIN | OK |
| 10 | إنشاء JWT token | OK |
| 11 | إرسال SMS ترحيبي | OK |
| 12 | حالة الحساب: pending | OK |

## تدفق الشاشات (User Flow)

```
[ترحيب] → [تسجيل] → [إدخال الاسم + هاتف + كلمة سر + PIN] → [تأكيد] → [الرئيسية]
```

## لماذا pending عند التسجيل؟

1. **KYC إلزامي** — يجب على المستخدم تقديم هويته لتفعيل الحساب
2. **الحدود** — الحساب pending يقيد التحويلات حتى اكتمال KYC
3. **الأمان** — منع استخدام المنصة من قبل حسابات وهمية
