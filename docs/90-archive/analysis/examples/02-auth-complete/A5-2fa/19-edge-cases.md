# 19 - حالات الحافة — المصادقة الثنائية (2FA)

## 1. فقدان هاتف المستخدم (لا يمكن الوصول لـ Authenticator)

**المشكلة**: المستخدم فقد هاتفه ولا يمكنه فتح تطبيق Authenticator.

**الحل**: رموز الاسترداد (Recovery Codes) — 8 رموز استخدام لمرة واحدة.

```json
["BZFA-1234-ABCD", "BZFA-5678-EFGH", ...]
```

## 2. فرق التوقيت بين الأجهزة (TOTP غير صحيح)

**المشكلة**: Google Authenticator يظهر رمزاً مختلفاً لأن توقيت الجهاز غير دقيق.

**الحل**: `verifyKey(secret, code, 1)` — ±1 window (30 ثانية) للتسامح.

## 3. إعادة استخدام recovery code

**المشكلة**: مستخدم يستخدم نفس recovery code مرتين.

**الحل**: حذف recovery code من القائمة بعد الاستخدام الأول.

## 4. تفعيل 2FA من جهازين

**المشكلة**: مستخدم يفتح صفحة 2FA على جهازين ويضغط "تفعيل" في نفس الوقت.

**الحل**: آخر طلب يحل محل السابق لأن secret يُستبدل.

## 5. إلغاء 2FA بدون إعادة مصادقة

**المشكلة**: مستخدم يريد تعطيل 2FA — يجب التأكد من هويته.

**الحل**: طلب كلمة المرور + رمز TOTP (أو recovery code) لتعطيل 2FA.

## 6. QR Code لا يظهر بشكل صحيح

**المشكلة**: QR code base64 كبير جداً أو مشوه.

**الحل**: عرض secret النصي كبديل — يمكن للمستخدم إدخاله يدوياً.

## 7. 2FA إجباري للمعاملات الكبيرة

**المشكلة**: مستخدم ليس لديه 2FA ويحاول تحويل > 1000 USD.

**الحل**: رفض العملية + رسالة "2FA مطلوب لهذه المعاملة".

```php
if ($user->isTwoFactorRequiredForAmount($amountUsd) && !$user->hasTwoFactorEnabled()) {
    throw new TwoFactorRequiredException();
}
```

## 8. إعادة تعيين 2FA من قبل المسؤول

**المشكلة**: مستخدم فقد recovery codes أيضاً — لا يمكنه الدخول.

**الحل**: دعم تقني — يمكن للمسؤول تعطيل 2FA بعد التحقق من هوية المستخدم.

## 9. TOTP متكرر (Replay Attack)

**المشكلة**: رمز TOTP صالح لمدة 30 ثانية — يمكن للمهاجم استخدامه إذا اعترضه.

**الحل**: `verifyKey` يسمح باستخدام الرمز مرة واحدة فقط ضمن النافذة الزمنية.

## 10. 2FA يبطئ تجربة المستخدم

**المشكلة**: المستخدم يحتاج لإدخال رمز في كل مرة يدخل فيها.

**الحل**: "تذكر هذا الجهاز لمدة 30 يوماً" — تخزين cookie آمن.

## جدول ملخص حالات الحافة

| # | الحالة | النتيجة | مستوى المعالجة |
|---|--------|---------|---------------|
| 1 | فقدان الهاتف | Recovery codes | Application |
| 2 | فرق التوقيت | ±1 window | Google2FA |
| 3 | إعادة استخدام recovery code | رفض (محذوف من القائمة) | Application |
| 4 | تفعيل من جهازين | آخر تفعيل يسود | Application |
| 5 | تعطيل بدون مصادقة | طلب كلمة مرور + رمز | Application |
| 6 | QR code معطل | عرض secret بديل | Frontend |
| 7 | 2FA إجباري | رفض العملية | Middleware |
| 8 | فقدان كل شيء | دعم فني | Manual |
| 9 | Replay attack | نافذة زمنية قصيرة | Google2FA |
| 10 | تجربة مستخدم بطيئة | تذكر الجهاز | Frontend |
