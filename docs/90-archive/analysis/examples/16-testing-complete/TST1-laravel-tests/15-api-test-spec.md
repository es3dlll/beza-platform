# 15 - مواصفات اختبارات API (API Test Spec)

## قائمة جميع اختبارات API

| المجموعة | عدد الاختبارات | التغطية |
|----------|---------------|---------|
| Auth | 12 | تسجيل، دخول، خروج، OTP، forgot password |
| Wallet | 6 | عرض رصيد، تحويل عملات |
| Transfer | 10 | نجاح، فشل، رصيد، PIN، حد يومي، تحويل للنفس |
| Merchant | 8 | تسجيل تاجر، منتجات، دفع |
| Agent | 6 | إيداع، سحب، صلاحية الكود |
| Deal | 6 | إنشاء صفقة، استثمار، توزيع أرباح |
| Card | 4 | إنشاء بطاقة، معاملة بطاقة |
| KYC | 6 | تقديم مستندات، موافقة، رفض |
| Admin | 8 | قائمة مستخدمين، تقارير، إعدادات |
| Notifications | 4 | قائمة، قراءة، قراءة الكل |
| 2FA | 6 | تفعيل، تحقق، تعطيل، رموز استرداد |
| Fraud | 6 | قواعد الكشف، قفل PIN، مراجعة |
| **المجموع** | **82** | **~95%** |

## تشغيل مجموعة محددة

```bash
# اختبار Auth
php artisan test --filter=AuthTest

# اختبار التحويلات
php artisan test --filter=TransferTest

# اختبار جميع feature tests
php artisan test --testsuite=Feature
```
