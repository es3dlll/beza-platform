> هذا الملف هو المرجع الوحيد للتكامل الخارجي مع نظام مدفوعات التجار في Beza.

## 01. المصادقة — تسجيل تاجر جديد

### POST /api/v1/merchant/auth/register

إنشاء حساب تاجر جديد. يتطلب توثيقاً تجارياً للموافقة من قبل المشرف.

#### المدخلات

| الحقل | النوع | الإلزام | الوصف |
|-------|-------|--------|-------|
| `business_name` | string(128) | مطلوب | الاسم التجاري |
| `owner_name` | string(128) | مطلوب | اسم صاحب التاجر |
| `phone` | string(15) | مطلوب | رقم الهاتف (مع رمز الدولة) |
| `email` | email | مطلوب | البريد الإلكتروني |
| `password` | string(64) | مطلوب | كلمة المرور (8+ أحرف، حرف كبير + رقم) |
| `commercial_register` | string(64) | مطلوب | رقم السجل التجاري |
| `tax_id` | string(64) | اختياري | الرقم الضريبي |
| `business_type` | enum | مطلوب | individual / company / ecommerce |
| `address` | string(256) | اختياري | العنوان الكامل |
| `city` | string(64) | اختياري | المدينة |
| `website` | url | اختياري | الموقع الإلكتروني |

#### الاستجابة (201 Created)

```json
{
  "success": true,
  "data": {
    "merchant_id": "merch_a1b2c3d4",
    "business_name": "متجر أحمد الإلكتروني",
    "status": "pending_approval",
    "message": "تم تسجيل حساب التاجر بنجاح. ينتظر الموافقة من المشرف."
  }
}
```

#### رموز الحالة

| الرمز | المعنى |
|-------|--------|
| 201 | تم إنشاء حساب التاجر — ينتظر الموافقة |
| 400 | خطأ في المدخلات |
| 409 | تعارض — رقم الهاتف أو البريد الإلكتروني مسجل مسبقاً |
| 422 | كيان غير قابل للمعالجة — سجل تجاري غير صالح |

## 02. المصادقة — تسجيل الدخول

### POST /api/v1/merchant/auth/login

تسجيل دخول التاجر واستلام Bearer Token للوصول إلى نقاط API.

#### المدخلات

| الحقل | النوع | الإلزام | الوصف |
|-------|-------|--------|-------|
| `phone` | string(15) | مطلوب | رقم الهاتف المسجل |
| `password` | string(64) | مطلوب | كلمة المرور |

#### الاستجابة (200 Success)

```json
{
  "success": true,
  "data": {
    "token_type": "Bearer",
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
    "expires_in": 1440,
    "merchant": {
      "id": "merch_a1b2c3d4",
      "business_name": "متجر أحمد الإلكتروني",
      "status": "approved",
      "tier": "medium",
      "daily_limit": 50000.00,
      "monthly_limit": 500000.00
    }
  }
}
```

#### رموز الحالة

| الرمز | المعنى |
|-------|--------|
| 200 | نجاح — تم تسجيل الدخول |
| 401 | غير مصرح — رقم الهاتف أو كلمة المرور خطأ |
| 403 | ممنوع — الحساب معلق أو لم تتم الموافقة عليه بعد |
| 429 | تجاوز المعدل — أكثر من 5 محاولات فاشلة/دقيقة |

## 11. رمز الاستجابة السريع — توليد

### POST /api/v1/merchant/qr/generate

توليد رمز QR ديناميكي للدفع في المتجر الفعلي. الرمز صالح لمدة 15 دقيقة كحد أقصى. يتطلب Bearer Token للتاجر.

#### المدخلات

| الحقل | النوع | الإلزام | الوصف |
|-------|-------|--------|-------|
| `amount` | integer | مطلوب | المبلغ بأصغر وحدة عملة (فلس) — مثلاً 1500 = 15.00 USD |
| `currency` | enum(SYP, USD) | مطلوب | عملة الدفع |
| `order_id` | string(64) | اختياري | رقم الطلب لدى التاجر (إن وجد) |
| `branch_id` | string(32) | اختياري | معرف الفرع (للمتاجر متعددة الفروع) |
| `description` | string(128) | اختياري | وصف عملية الدفع |

#### الاستجابة (201 Created)

```json
{
  "success": true,
  "data": {
    "qr_id": "qr_f6e7d8a9",
    "transaction_id": "txn_f6e7d8",
    "qr_code_png": "data:image/png;base64,iVBORw0KGgo...",
    "qr_code_svg": "<svg xmlns=\"...\">...</svg>",
    "qr_raw_data": "{\"v\":1,\"mid\":\"merch_a1b2\",\"tid\":\"txn_f6e7d8\",\"a\":1500,\"c\":\"USD\",\"e\":\"20260531T141500Z\",\"s\":\"a1b2c3d4...\"}",
    "amount": 1500,
    "currency": "USD",
    "expires_at": "2026-05-31T14:15:00Z",
    "status": "pending"
  }
}
```

#### رموز الحالة

| الرمز | المعنى |
|-------|--------|
| 201 | تم توليد رمز QR بنجاح |
| 400 | خطأ في المدخلات — مبلغ صفر أو سالب، عملة غير مدعومة |
| 401 | غير مصرح — التوكن منتهي أو غير صالح |
| 403 | ممنوع — حساب التاجر معلق أو غير مفعل |

## 12. رمز الاستجابة السريع — التحقق

### POST /api/v1/merchant/qr/verify

التحقق من صحة رمز QR وبدء معالجة الدفع. يتطلب Bearer Token للمستخدم (وليس التاجر).

#### المدخلات

| الحقل | النوع | الإلزام | الوصف |
|-------|-------|--------|-------|
| `qr_data` | string | مطلوب | النص الداخلي للرمز (JSON كامل) |
| `device_fingerprint` | string(128) | اختياري | بصمة الجهاز الماسح |

#### الاستجابة — رمز صالح وغير مدفوع (200)

```json
{
  "success": true,
  "data": {
    "merchant_id": "merch_a1b2",
    "merchant_name": "متجر أحمد الإلكتروني",
    "amount": 1500,
    "currency": "USD",
    "description": "تيشيرت قطني",
    "order_id": "ORD-0042",
    "status": "valid",
    "expires_at": "2026-05-31T14:15:00Z",
    "payment_ready": true
  }
}
```

#### الاستجابة — رمز منتهي الصلاحية (400)

```json
{
  "success": false,
  "error": {
    "code": "QR_EXPIRED",
    "message": "انتهت صلاحية رمز QR. الرجاء طلب رمز جديد من التاجر.",
    "details": {
      "expired_at": "2026-05-31T14:15:00Z",
      "current_time": "2026-05-31T14:20:00Z"
    }
  }
}
```

#### الاستجابة — توقيع غير صالح (400)

```json
{
  "success": false,
  "error": {
    "code": "QR_INVALID_SIGNATURE",
    "message": "رمز QR غير صالح أو تم التلاعب به.",
    "details": {
      "reason": "signature_mismatch"
    }
  }
}
```

#### رموز الحالة

| الرمز | المعنى |
|-------|--------|
| 200 | رمز صالح — جاهز للدفع |
| 400 | رمز غير صالح — منتهي، مدفوع مسبقاً، توقيع خاطئ، أو ملغى |
| 401 | غير مصرح — التوكن منتهي |
| 404 | التاجر غير موجود أو الحساب معلق |

## 13. التسوية — سرد التسويات

### GET /api/v1/merchant/settlements

عرض سجل التسويات اليومية للتاجر مع المبالغ والعمولات. يتطلب Bearer Token للتاجر.

#### المعاملات (Query Parameters)

| الحقل | النوع | الإلزام | الوصف |
|-------|-------|--------|-------|
| `page` | integer | اختياري | رقم الصفحة (الافتراضي 1) |
| `per_page` | integer | اختياري | عدد النتائج لكل صفحة (20، حد أقصى 100) |
| `status` | enum | اختياري | تصفية حسب الحالة: pending, processing, successful, failed, pending_review, cancelled |
| `from` | date | اختياري | بداية فترة التسوية (Y-m-d) |
| `to` | date | اختياري | نهاية فترة التسوية (Y-m-d) |

#### الاستجابة (200)

```json
{
  "success": true,
  "data": [
    {
      "id": "stl_20260531_merch_a1b2",
      "merchant_id": "merch_a1b2",
      "period_start": "2026-05-30T00:00:00Z",
      "period_end": "2026-05-31T00:00:00Z",
      "gross_amount": 50000,
      "total_fees": 2637,
      "withheld_amount": 2500,
      "tax_amount": 187,
      "net_amount": 44863,
      "currency": "USD",
      "status": "successful",
      "transaction_count": 40,
      "transferred_at": "2026-05-31T01:00:00Z"
    }
  ],
  "meta": {
    "current_page": 1,
    "per_page": 20,
    "total": 15,
    "last_page": 1
  }
}
```

#### رموز الحالة

| الرمز | المعنى |
|-------|--------|
| 200 | نجاح — تم جلب اللائحة |
| 401 | غير مصرح — التوكن منتهي |
| 422 | معاملات غير صالحة |

## 17. التسوية — طلب تسوية يدوية

### POST /api/v1/merchant/settlements/request-manual

طلب تسوية يدوية عاجلة خارج دورة الجدولة العادية. يُراجع الطلب من قبل الإدارة خلال 24 ساعة عمل.

#### المدخلات

| الحقل | النوع | الإلزام | الوصف |
|-------|-------|--------|-------|
| `note` | string(256) | اختياري | ملاحظة من التاجر توضح سبب الطلب العاجل |

#### الاستجابة (201 Created)

```json
{
  "success": true,
  "data": {
    "request_id": "req_manual_a1b2",
    "status": "pending_review",
    "message": "تم استلام طلب التسوية اليدوية. سيتم معالجتها خلال 24 ساعة عمل.",
    "estimated_at": "2026-06-01T12:00:00Z"
  }
}
```

#### رموز الحالة

| الرمز | المعنى |
|-------|--------|
| 201 | تم استلام الطلب — قيد المراجعة |
| 400 | خطأ في المدخلات |
| 401 | غير مصرح — التوكن منتهي |
| 409 | تعارض — يوجد طلب تسوية يدوية معلق سابقاً لم تتم معالجته بعد |
