## التدفق المعماري

```
طلبات API
    │
    ▼
    ┌─────────────────────────────┐
    │   طبقات النواة (Core Layer) │ ← ValueObjects، Enums، Traits
    └─────────────┬───────────────┘
                  │
    ┌─────────────▼───────────────┐
    │   الوحدات النمطية (Modules) │ ← 31 وحدة، كل وحدة مستقلة
    │   التواصل عبر Event Bus فقط │ ← ممنوع الاستدعاء المباشر
    └─────────────┬───────────────┘
                  │
    ┌─────────────▼───────────────┐
    │   أمان + امتثال + تدقيق    │ ← مدمج في كل طبقة
    └─────────────────────────────┘
```
