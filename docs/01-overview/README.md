# بزة — Beza Platform 🅱️

**منصة مالية رقمية متكاملة — سوريا 2026**

---

## الرؤية

منصة مالية رقمية تقدم خدمات الدفع، التحويل، التجارة الإلكترونية، والشمول المالي للأفراد والشركات في سوريا.

## الرسالة

بناء بنية تحتية مالية رقمية آمنة، سريعة، ومنخفضة التكلفة — متاحة للجميع عبر الجوال والويب.

## الجمهور المستهدف

| الفئة | الوصف |
|-------|-------|
| الأفراد | تحويل P2P، دفع فواتير، شحن رصيد |
| التجار | قبول مدفوعات، روابط دفع، QR |
| الوكلاء | إيداع/سحب نقدي، إدارة العملاء |
| الشركات | رواتب، تسوية مالية، فواتير |

## القيم الأساسية

- **الأمان أولاً** — WORM Ledger، تشفير شامل، TOTP
- **السرعة** — معالجة فورية للمعاملات
- **الشفافية** — رسوم واضحة، سجل تدقيق كامل
- **الشمول** — دعم المناطق الريفية عبر شبكة وكلاء

## مسار المستخدم الأساسي (MVP)

```
تسجيل → إنشاء محفظة → شحن رصيد → تحويل لصديق → إشعار
```
