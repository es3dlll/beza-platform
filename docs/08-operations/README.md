## هيكل Runbook النموذجي

كل runbook يتبع الهيكل التالي:
1. **الوصف** — ما المشكلة؟
2. **الأعراض** — كيف نعرف أن المشكلة حدثت؟
3. **التأثير** — من يتأثر؟ ما درجة الخطورة؟
4. **خطوات الكشف** — كيف نؤكد المشكلة؟
5. **خطوات الاستجابة** — ماذا نفعل فوراً؟
6. **خطوات الحل** — كيف نصلح المشكلة نهائياً؟
7. **خطوات ما بعد الحل** — ماذا نسجل؟ كيف نمنع التكرار؟
