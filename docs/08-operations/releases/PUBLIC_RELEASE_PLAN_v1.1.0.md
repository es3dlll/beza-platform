## 2. معايير الترقية بين المراحل
- **معدل الأخطاء:** < 0.01% من جميع الطلبات
- **زمن الاستجابة:** P95 < 200ms و P99 < 500ms
- **التسوية:** لا فروقات حرجة في دفتر الأستاذ
- **الدعم:** متوسط وقت الاستجابة للشكاوى < 30 دقيقة
- **الامتثال:** جميع تقارير CBS مرسلة بنجاح

## 3. خطة التراجع الآمن
```
1. كشف المشكلة → إشعار فريق الطوارئ
2. تفعيل feature flag للعودة للإصدار السابق
3. git revert v1.1.0 → إعادة النشر
4. إيقاف قائمة انتظار الإصدار الجديد ← تصريف القديم
5. تأكيد استقرار النظام ← إشعار جميع المتأثرين
```
