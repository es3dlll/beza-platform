# ملاحظات الإطلاق التجريبي — منصة بيزا v1.1.0-beta

**تاريخ الإطلاق:** 2026-06-01
**الهدف:** تجربة المستخدمين الأوائل وجمع الملاحظات التشغيلية
**الفئة:** تجريبي (Beta) — غير جاهز للاستخدام الإنتاجي الواسع

---

## الميزات الجديدة

### 💰 المالية الأساسية
- إيداع وسحب آمن مع قيد مزدوج في دفتر الأستاذ
- محفظة رقمية بعملة الليرة السورية (SYP) بوحدة الفلس
- تحويلات فورية بين المستخدمين مع تسجيل فوري

### 🔄 التحويلات الدولية (FX)
- أسعار صرف ديناميكية مع صلاحية زمنية
- رسوم متدرجة حسب الشريحة ونوع الزبون
- تدقيق أمني للتحويلات عالية المخاطر

### 📋 الفواتير والمدفوعات المجدولة
- دفع فواتير الخدمات (كهرباء، اتصالات، مياه)
- جدولة دفع شهرية تلقائية
- إيصالات برقم مرجعي موحد (RCP-*)

### 🛒 السوق الرقمي والضمان المالي
- سوق رقمي للبائعين المعتمدين مع فئات المنتجات
- ضمان مالي آمن بنظام (initiate → fund → release)
- نظام نزاعات مع 3 قرارات: لصالح المشتري / البائع / التقسيم

### 🔔 الإشعارات والتحليلات
- إشعارات متعددة القنوات (InApp، Email، SMS)
- إشعارات ذكية مرتبطة بـ 7 أحداث نظامية
- لوحة تحليلات تشغيلية مع 10 مؤشرات أداء
- تصدير تقارير مالية وتشغيلية (CSV)

### 🛡️ الأمان والامتثال
- كشف احتيال فوري بقواعد AML ديناميكية
- ربط الأجهزة للمعاملات المالية
- سجل تدقيق غير قابل للتعديل (WORM)
- رؤوس أمان HTTP صارمة (CSP، HSTS، XFO)
- تشفير النسخ الاحتياطية (AES-256-CBC)

## التغييرات المعروفة (Known Issues)

| الرقم | المشكلة | الحالة | خطة المعالجة |
|-------|---------|--------|---------------|
| 1 | قناة SMS غير جاهزة بعد — `isReady()` → false | معروف | ربط مع مزود SMS في الإنتاج |
| 2 | المصادقة عبر Token فقط — لا OTP أو Biometric | مقرر للإصدار 1.2 | إضافة OTP كخيار احتياطي |
| 3 | قاعدة بيانات SQLite — غير مناسبة للإنتاج المباشر | معروف | الترقية إلى PostgreSQL في الإنتاج |
| 4 | لا يوجد دفع لبطاقات الائتمان أو الدفع عند الاستلام | مقرر للإصدار 1.3 | تكامل مع مزود دفع خارجي |

## متطلبات الترقية

### قبل التحديث من v1.0.0
1. وقف جميع مشغلي الطوابير: `php artisan queue:rest`
2. تشغيل التهجير: `php artisan migrate --force`
3. تحديث متغيرات البيئة (راجع `.env.production`)
4. إعادة تشغيل الخدمات: `php artisan serve`

### لمستخدمي الإصدارات السابقة
- لا يوجد تحديث مباشر — هذه النسخة الأولى القابلة للتجربة
- ترحيل البيانات غير مدعوم بعد
