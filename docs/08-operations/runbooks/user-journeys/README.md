## هيكل الرحلة النموذجي

كل رحلة مستخدم تتبع الهيكل التالي:
1. **المشغل** — ما الذي يبدأ الرحلة؟
2. **المتطلبات المسبقة** — ما الذي يجب أن يكون موجوداً؟
3. **الخطوات** — التسلسل من البداية إلى النهاية
4. **السيناريوهات البديلة** — ماذا لو حدث خطأ؟
5. **نقاط القرار** — أين يتخذ المستخدم أو النظام قراراً؟
6. **النتيجة** — حالة النجاح والفشل
