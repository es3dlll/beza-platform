## 1. Rate Limiting (`SEC-001-RL`)

### المراجعة
- ✅ الفصل بين هويات الطلب (User > API Key > IP) صحيح
- ✅ الحدود对不同 الأنواع منفصلة — لا collision
- ✅ استثناء `health/status` منطقي
- ✅ رؤوس `X-RateLimit-*` متوافقة مع RFC 6585

### ملاحظات
- ⚠️ إضافة حد منفصل لـ `POST /api/auth/verify-otp` — 5 محاولات/دقيقة
- ⚠️ إضافة حد لـ `POST /api/auth/refresh` — 10 محاولات/دقيقة
- ✅ استخدام `Illuminate\Cache\RateLimiter` — موثوق ومختبر

### سيناريوهات اختبار إضافية

| # | السيناريو | المتوقع |
|---|-----------|---------|
| 9 | 1000 طلب متزامن من IP واحد | 429 بعد تجاوز الحد العام |
| 10 | مستخدم مسجل — حد auth يختلف عن حد payment | حد auth لا يؤثر على حد payment |
| 11 | Admin يصل إلى حد admin (100/دقيقة) وحد عام (60/دقيقة) — الأكبر يسري | 100/دقيقة |
| 12 | إعادة تعيين العداد بعد انتهاء النافذة الزمنية | 200 OK بعد انتظار decay |

## 2. Webhook HMAC (`SEC-001-WH`)

### المراجعة
- ✅ HMAC-SHA256 — خوارزمية قوية ومعتمدة
- ✅ `hash_equals()` — يمنع timing attack
- ✅ نافذة ±300 ثانية — توازن بين الأمان وسهولة الاستخدام
- ✅ Nonce عشوائي 32 حرف — يمنع replay attacks حتى ضمن النافذة

### ملاحظات
- ✅ إضافة تخزين nonce مؤقت (Cache) لمنع إعادة استخدام same nonce خلال النافذة
- ✅ تدوير secret كل 90 يوم — إضافة config للـ rotation

### سيناريوهات اختبار إضافية

| # | السيناريو | المتوقع |
|---|-----------|---------|
| 9 | إعادة إرسال same signed payload (replay attack) | فشل (nonce مستخدم) |
| 10 | secret قديم (قبل rotation) — ضمن فترة grace | نجاح مع تحذير |
| 11 | future timestamp > +5 دقائق | فشل |
| 12 | empty payload | توقيع صحيح (لا يمنع) |

## 3. JSON Sanitization (`SEC-001-JS`)

### المراجعة
- ✅ 20+ نمط ممنوع — تغطية جيدة
- ✅ `strip_tags()` — حماية XSS إضافية
- ✅ رسائل خطأ بالعربية

### ملاحظات
- ⚠️ إضافة `\bOR\b\s+\d+\s*=\s*\d+` (1=1, 2=2) — حقن شائع
- ⚠️ إضافة `\bHAVING\b` — لتغطية كاملة
- ✅ إضافة دعم UTF-8 للأنماط العربية (لا تتأثر)

### سيناريوهات اختبار إضافية

| # | السيناريو | المتوقع |
|---|-----------|---------|
| 9 | `' OR 1=1 --` | فشل |
| 10 | `admin' HAVING 1=1 --` | فشل |
| 11 | `1; SELECT pg_sleep(5) --` | فشل |
| 12 | JSON بطول 1MB | تعامل بدون OOM |
| 13 | Unicode injection: `\u0027 OR 1=1 --` | فشل (يُفك ترميزه قبل الفحص) |
