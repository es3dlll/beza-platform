# Architecture Principles

## المبادئ المعمارية الأساسية

```yaml
Architecture Principles:
  - Single Source of Truth: Ledger هو المصدر الوحيد للحقيقة المالية
  - Event-Driven: كل التواصل بين الوحدات عبر الأحداث (Events) فقط
  - Immutability: السجلات المالية Append-Only فقط (WORM)
  - Money Safety: لا توجد عمليات حسابية على float أو double
  - Zero Trust: كل طلب يتم التحقق منه في كل طبقة
  - Arabic-First: الدعم الكامل للغة العربية و RTL في كل الطبقات
  - Modular Boundaries: حدود واضحة بين الوحدات مع واجهات رسمية
```

## القيم غير القابلة للتفاوض

| المبدأ | التطبيق التقني |
|--------|---------------|
| الثقة قبل السرعة | تحقق مزدوج + سجل تدقيق لكل عملية مالية |
| الشفافية المالية | عرض كل الرسوم والعمولات قبل التأكيد |
| الامتثال التنظيمي | قواعد AML/KYC مدمجة في نواة النظام |
| العربية أولاً | i18n مع RTL في كل واجهات المستخدم |
| الأمان المدمج | تشفير البيانات الحساسة + JWT قصير العمر |

## قواعد البيانات والمالية

- **ULID** حصرياً لكل المفاتيح الأساسية (ممنوع Auto-increment أو UUID)
- **Bigint** بوحدات صغرى (فلس) لتخزين الأموال - ممنوع float/double/decimal
- **Append-Only Ledger** (WORM) - لا UPDATE أو DELETE على السجلات المالية
- **CoreFinancialEngine** - الملك الوحيد لحالات الأرصدة والخصم/الإيداع

## قواعد الأمان والمصادقة

- **JWT** قصير العمر (15 دقيقة) مع Refresh Token
- **Device Binding** إلزامي لأي معاملة مالية
- **RBAC + ABAC** معاً لحماية كل نقطة API
- **Audit Log** لكل عملية مالية - غير قابل للتعديل
