# Module Catalog - دليل الوحدات النمطية

Beza Platform يتكون من 31 وحدة نمطية (Module) ضمن بنية Modular Monolith في Laravel 13.

## Core Modules (الوحدات الأساسية)

| الوحدة | المسؤولية | تعتمد على |
|--------|-----------|-----------|
| **Identity** | إدارة المستخدمين، المصادقة، التسجيل، إدارة الجلسات | Core |
| **Wallet** | المحافظ المالية متعددة العملات، الأرصدة، الحدود | Identity, Ledger |
| **Ledger** | دفتر الأستاذ المحاسبي، القيود المحاسبية، التسوية | Core |
| **CoreFinancialEngine** | محرك المعاملات المالية، الخصم/الإيداع، التعليق | Ledger, Wallet |
| **Compliance** | الامتثال التنظيمي، AML/KYC، فحص العقوبات | Identity |

## Financial Services (الخدمات المالية)

| الوحدة | المسؤولية | تعتمد على |
|--------|-----------|-----------|
| **FX** | صرف العملات، أسعار الصرف المتعددة، تثبيت السعر | CFE, Ledger |
| **Remittance** | التحويلات الدولية، حوالات المغتربين | FX, CFE, Compliance |
| **Agent** | شبكة الوكلاء، الإيداع/السحب النقدي، العمولات | Wallet, CFE |
| **Settlement** | التسويات المالية مع البنوك والجهات الخارجية | Ledger, CFE |
| **Bills** | دفع الفواتير (كهرباء، ماء، اتصالات، حكومة) | Wallet, CFE |

## Merchant Services (خدمات التجار)

| الوحدة | المسؤولية | تعتمد على |

## هيكل الوحدة النمطية

كل وحدة نمطية تتبع الهيكل التالي:

```
ModuleName/
├── Actions/          # عمليات أعمال قابلة لإعادة الاستخدام
├── Controllers/      # متحكمات API نحيفة
├── Events/           # أحداث الوحدة
├── Exceptions/       # استثناءات خاصة
├── Listeners/        # مستمعو الأحداث
├── Models/           # Eloquent Models
├── Policies/         # سياسات الصلاحيات
├── Rules/            # قواعد تحقق مخصصة
├── Services/         # منطق الأعمال
├── ValueObjects/     # كائنات القيمة
├── Database/         # Migrations, Factories, Seeders
├── Resources/lang/   # ترجمات الوحدة
├── Routes/api.php    # مسارات الوحدة (بادئة /v1/{module})
├── Tests/            # Feature + Unit tests
└── README.md         # توثيق الوحدة
```

## قواعد التواصل بين الوحدات

- **ممنوع**: استدعاء مباشر لوحدة أخرى عبر `app()` أو الحقن
- **مسموح فقط**: إطلاق حدث `event(new EventName(...))` ← مستمع `ShouldQueue`
- **الاستثناء الوحيد**: Core modules يمكن استدعاؤها عبر واجهات رسمية موثقة
