# مسرد المصطلحات — Glossary

**آخر تحديث:** 2026-05-31

---

## المصطلحات المالية

| المصطلح | التعريف |
|---------|---------|
| **CFE** | Cash Flow Engine — محرك التدفق النقدي، المسؤول عن معالجة المعاملات المالية |
| **Ledger** | دفتر الأستاذ — سجل مالي WORM (Write Once Read Many) غير قابل للتعديل |
| **Wallet** | محفظة رقمية — حساب مالي مرتبط بمستخدم |
| **P2P** | Peer-to-Peer — تحويل مباشر بين مستخدمين |
| **KYC** | Know Your Customer — اعرف عميلك: عملية توثيق الهوية |
| **AML** | Anti-Money Laundering — مكافحة غسل الأموال |
| **Settlement** | تسوية مالية — عملية مقاصة بين الأطراف |
| **Float** | فئة عائمة (ممنوع في القيم المالية) — نستخدم bigint (فلس) |
| **Tier** | مستوى تحقق (T1/T2/T3) — حدود المعاملات حسب مستوى التوثيق |

## المصطلحات التقنية

| المصطلح | التعريف |
|---------|---------|
| **Modular Monolith** | تطبيق واحد مقسّم إلى وحدات نمطية (31 وحدة) بدلاً of Microservices |
| **Core Layer** | طبقة النواة — مكونات مشتركة لا تعتمد على أي وحدة |
| **Event Bus** | ناقل الأحداث — للتواصل بين الوحدات دون اقتران مباشر |
| **WORM** | Write Once Read Many — سياسة عدم تعديل السجلات المالية |
| **Idempotency** | خاصية تكرار الطلب دون تأثير جانبي — مفتاح لكل عملية مالية |
| **FSD** | Feature-Sliced Design — منهجية تنظيم واجهات React |
| **SSOT** | Single Source of Truth — مصدر حقيقة واحد لكل مفهوم |
| **ADR** | Architecture Decision Record — توثيق القرارات المعمارية |
| **SOP** | Standard Operating Procedure — إجراءات التشغيل الموحدة |

## دور الوثائق

| الاختصار | المعنى |
|----------|--------|
| **PRD** | Product Requirements Document — وثيقة متطلبات المنتج |
| **API Spec** | مواصفات واجهة البرمجة (OpenAPI 3.1) |
| **Runbook** | دليل طوارئ — خطوات الاستجابة للحوادث |
| **Changelog** | سجل التغييرات — توثيق كل إصدار |
| **SOP** | إجراءات التشغيل الموحدة — دورة العمل الكاملة |
