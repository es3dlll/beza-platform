# DESIGN.md - دليل التصميم الشامل لمنصة بيزا

الهوية البصرية، الأنماط، والمكونات - تطبيق فلاتر ولوحة الويب

## 1. الرؤية والفلسفة التصميمية

### 1.1 الرؤية
بناء تجربة مستخدم مالية رقمية تجمع بين الأصالة العربية والحداثة العالمية، تقدم الثقة عبر البساطة، والشفافية عبر الوضوح، والراحة عبر السلاسة.

### 1.2 المبادئ التصميمية الأساسية
- **العربية أولاً:** كل عنصر يبدأ بالتصميم للعربية واتجاه اليمين لليسار، ثم يُكيّف للإنجليزية
- **الثقة البصرية:** ألوان هادئة، تباين عالي، خطوط واضحة، رسائل مطمئنة
- **البساطة الوظيفية:** كل عنصر له هدف، لا زخارف غير ضرورية، تقليل الخطوات
- **التكيف الذكي:** واجهات تتكيف مع الوقت، الموقع، سلوك المستخدم، وحالة الشبكة
- **الوصول الشامل:** تصميم يخدم الجميع بغض النظر عن القدرة، العمر، أو الخبرة التقنية

### 1.3 شخصيات المستخدمين المستهدفة
- **المواطن العادي:** يحتاج واجهة بسيطة، خطوات واضحة، لغة يومية
- **التاجر:** يحتاج سرعة، تقارير، إدارة متعددة الفروع
- **الوكيل:** يحتاج إدارة سيولة، عمولات، نقاط خدمة
- **مسؤول الامتثال:** يحتاج مراجعة، تقارير، صلاحيات دقيقة
- **المغترب:** يحتاج تحويلات دولية، أسعار صرف، تتبع لحظي

## 2. الهوية البصرية الأساسية

### 2.1 نظام الألوان

**الألوان الأساسية**
| اللون | الرمز | الاستخدام |
|-------|-------|-----------|
| الأزرق الملكي | `#1E3A8A` ← `#3B82F6` | الأزرار الأساسية، العناوين الرئيسية، العناصر النشطة |
| الأخضر الزمردي | `#10B981` ← `#34D399` | أزرار التأكيد، المؤشرات الإيجابية، أيقونات النجاح |
| الذهبي الدافئ | `#F59E0B` ← `#FBBF24` | عناصر الذهب، المكافآت، المستويات المميزة |

**الألوان المحايدة**
- الأسود العميق: `#0F172A` — للنصوص الأساسية في الوضع الفاتح
- الأبيض النقي: `#FFFFFF` — للخلفيات في الوضع الفاتح
- الرمادي الحيادي: `#64748B` — للنصوص الثانوية والعناصر غير النشطة
- الرمادي الفاتح: `#F1F5F9` — للخلفيات الثانوية والفواصل

**ألوان الحالة**
- الأحمر التحذيري: `#EF4444` — للأخطاء، التحذيرات، الإجراءات الخطرة
- البرتقالي التنبيهي: `#F97316` — للتنبيهات المتوسطة، الحالات المعلقة
- الأزرق المعلوماتي: `#3B82F6` — للمعلومات، الروابط، التلميحات
- البنفسجي الخاص: `#8B5CF6` — للميزات الجديدة، العروض الحصرية

**ألوان الوضع الداكن**
- خلفية أساسية: `#0F172A`
- خلفية ثانوية: `#1E293B`
- نصوص أساسية: `#F8FAFC`
- نصوص ثانوية: `#94A3B8`
- حدود وعناصر: `#334155`

### 2.2 نظام الخطوط

- **الخط الأساسي:** Cairo (Google Fonts — Cairo Variable Font)
- **الأوزان المدعومة:** 300, 400, 500, 600, 700, 800, 900
- **الاستخدام:**
  - وزن 300: النصوص الثانوية، التسميات الصغيرة
  - وزن 400: النصوص العادية، محتوى الفقرات
  - وزن 500: العناوين الفرعية، أزرار الثانوية
  - وزن 600: العناوين الرئيسية، أزرار الأساسية
  - وزن 700+: العناوين الكبيرة، الأرقام المهمة، التنبيهات

**أحجام النصوص المعيارية**
- صغير جداً: 11px — للتسميات الدقيقة، التواريخ الثانوية
- صغير: 13px — للتسميات، النصوص المساعدة
- عادي: 16px — للمحتوى الأساسي، أزرار النصوص
- متوسط: 18px — للعناوين الفرعية، النصوص المهمة
- كبير: 24px — للعناوين الرئيسية، الأرقام البارزة
- كبير جداً: 32px — للعناوين البطولية، الأرصدة
- ضخم: 48px+ — للشاشات الترحيبية، الإنجازات الكبيرة

**تباعد الأسطر:** نصوص صغيرة 1.2، نصوص عادية 1.5، نصوص كبيرة 1.3، عناوين 1.1

**دعم اللغات:** العربية (RTL افتراضي)، الإنجليزية (LTR)، الكردية والأرمنية (اختياري)

### 2.3 نظام الأيقونات

- **المصدر:** Lucide Icons أو Material Symbols مع تخصيص
- **الحجم القياسي:** 20px داخل النصوص، 24px للأيقونات المستقلة
- **سمك الخط:** 1.5px للوضوح على جميع الخلفيات
- **فئات الأيقونات:** مالية، أمان، تنقل، حالة، إجراءات

### 2.4 نظام الصور والخلفيات
- الصور الشخصية: دائرية، إطار ذهبي للمستخدمين المميزين
- صور المنتجات: خلفية بيضاء نقية، زاوية 45 درجة، ظل ناعم
- صور الخلفيات: تدرجات لونية مع أنماط هندسية إسلامية خفيفة
- ضغط ذكي، تحميل تدريجي، دعم الوضع الداكن

## 4. مكتبة المكونات التفصيلية

### 4.1 نظام الأزرار

| الخاصية | الزر الأساسي | الزر الثانوي | زر النص | زر الخطر |
|---------|-------------|-------------|---------|---------|
| الخلفية | `#1E3A8A` | شفافة | بدون | `#EF4444` |
| النص | أبيض | `#1E3A8A` | `#1E3A8A` | أبيض |
| الحدود | بدون | 2px solid `#1E3A8A` | بدون | بدون |
| الارتفاع | 48px | 48px | 32px | 48px |
| نصف القطر | 12px | 12px | — | 12px |

**الأحجام:** صغير (32px)، عادي (48px — الافتراضي)، كبير (56px)

**الحركات:** تكبير 2% عند اللمس (100ms)، عودة (150ms)، اهتزاز عند الخطأ (300ms)

### 4.2 نظام الحقول والنماذج
- الارتفاع: 48px، نصف القطر: 12px
- الحالات: عادي ← نشط ← صحيح (أخضر) ← خطأ (أحمر) ← معطل
- حقول خاصة: رقم (لوحة مفاتيح رقمية)، عملة (تنسيق تلقائي)، تاريخ (هجري/ميلادي)، كلمة مرور (مقياس قوة)

### 4.3 نظام البطاقات
- بطاقة معلومات: ظل مستوى 1، نصف قطر 16px
- بطاقة رصيد بطولية: تدرج أزرق، نص أبيض
- بطاقة معاملة: أيقونة + تفاصيل + مبلغ + حالة
- بطاقة إجراء سريع: مربع مع أيقونة ونص
- حركات: انزلاق لأعلى عند التحميل، تكبير عند النقر

### 4.4 نظام التنقل
- **شريط سفلي (موبايل):** 64px، 4-5 عناصر، أيقونة + نص
- **قائمة جانبية (ويب):** 240px، شعار + عناصر + إجراءات
- **شريط علوي:** 56px، عنوان + إجراءات + صورة مستخدم
- **فتات التنقل:** مسار الصفحة مع عناصر قابلة للنقر

### 4.5 نظام التنبيهات والنوافذ
- التنبيهات العائمة: أعلى الشاشة، لون حسب النوع، 3-5 ثوانٍ
- النوافذ المنبثقة: خلفية معتمة، نصف قطر 20px، حركة تكبير
- صفحات التأكيد: أيقونة كبيرة + عنوان + تفاصيل + أزرار

### 4.6 نظام الجداول والقوائم
- جدول بيانات: رأس رمادي فاتح، خطوط فاصلة، تمرير أفقي
- قائمة معاملات: أيقونة + تفاصيل + مبلغ + وقت، تمرير لانهائي
- قائمة إجراءات سريعة: شبكة 2×2 أو 3×3، قابلة للتخصيص

## 5. نظام الحركات والتحريك

### 5.1 المبادئ
- الحركات تخدم الوظيفة، ليست زخرفة
- المدة: 150-300ms للأساسيات، 300-500ms للانتقالات الكبيرة
- المنحنى: ease-out للدخول، ease-in للخروج، ease-in-out للتبديل

### 5.2 انتقالات الشاشات
- **أفقي:** الصفحات ضمن نفس القسم (300ms, ease-in-out)
- **عمودي:** النوافذ المنبثقة والصفحات الفرعية (250ms, ease-out)
- **تكبير:** من عنصر إلى تفاصيله (400ms, custom cubic-bezier)

### 5.3 حركات التحميل
- مؤشر دائري: 360° خلال 1 ثانية، سمك 3px، لون أزرق
- شريط تقدم: ارتفاع 4px، انسيابي مع تسارع
- تحديث بالسحب: مؤشر دائري عند العتبة، ارتداد إن لم يصل

## 7. إرشادات المنصات

### 7.1 تطبيق فلاتر (موبايل)
- أهداف لمس ≥ 44×44px
- استخدام Material 3 مع تخصيص
- إدارة الحالة: Provider أو Riverpod
- التنقل: GoRouter مع حماية المسارات

### 7.2 لوحة الويب (إدارة)
- React 18 + TypeScript + Tailwind CSS
- إدارة الحالة: Redux Toolkit أو Zustand
- رسوم بيانية: Recharts أو Chart.js

### 7.3 واجهة الوكيل
- وضع عمل مبسط + وضع مراجعة تفصيلي
- تخزين محلي للعمل دون اتصال + مزامنة تلقائية

### 7.4 بوابة التاجر
- إدارة متعددة الفروع، فواتير سريعة، تكامل نقاط بيع
- وضع نقطة بيع (شاشة كاملة) + وضع إدارة

## 8. معايير الوصول الشامل

### 8.1 بصرية
- تباين نصوص ≥ 4.5:1، نصوص كبيرة ≥ 3:1
- عدم الاعتماد على اللون فقط للحالة
- دعم تكبير النص حتى 200%

### 8.2 حركية
- أهداف لمس ≥ 44×44px
- تنقل كامل بلوحة المفاتيح
- دعم قارئات الشاشة (ARIA labels)

### 8.3 معرفية
- لغة بسيطة ومباشرة
- تدفق مهام خطي مع تقدم واضح
- تلميحات سياقية عند الحاجة

## 10. القوالب الجاهزة

- **صفحة قائمة:** شريط عنوان + فلترة + قائمة + ترقيم
- **صفحة تفاصيل:** صورة + أقسام معلومات + إجراءات ثابتة
- **نموذج إدخال:** حقول مرتبة + تحقق فوري + زر إرسال
- **بطاقة ملخص:** قيمة كبيرة + مؤشر تغيير + رابط تفاصيل
