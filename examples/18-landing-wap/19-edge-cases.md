# حالات الحافة — WAP

| الحالة | السلوك المتوقع |
|--------|---------------|
| **انقطاع الشبكة أثناء التحويل** | يحفظ في IndexedDB Queue ← يرسل لاحقاً ← إشعار للمستخدم |
| **إعادة إرسال نفس التحويل** | `idempotency_key` يمنع التكرار — Laravel يعيد الرد السابق |
| **انتهاء صلاحية JWT** | يتجدد تلقائياً عبر Refresh Token في الـ middleware |
| **تغيير الدور (مستخدم → تاجر)** | بعد تسجيل الخروج والدخول مجدداً، تظهر لوحة التاجر |
| **فتح الرابط بدون جلسة** | يُعاد توجيهه إلى `/wap/login` |
| **محاولة دخول بتاجر إلى /user** | 403 Forbidden — Middleware `role:user` يمنع |
| **تعدد علامات التبويب** | كل علامة تشترك في نفس الـ Cookie — لا مشكلة |
| **حذف Cache/Service Worker** | يعيد تحميل الملفات من الشبكة — PWA يتثبت من جديد |
| **Idempotency Key مكرر** | Laravel يعيد آخر رد ناجح — لا ينفذ التحويل مجدداً |
| **Queue ممتلئة (> 50 عنصر)** | يُمنع إضافة عناصر جديدة — يُطلب من المستخدم مراجعة Queue |
| **تحديث الصفحة أثناء Offline Queue** | Queue محفوظة في IndexedDB — لا تفقد البيانات |
| **فشل المزامنة 5 مرات** | يُوسم العنصر بـ `failed` — يُعرض للمستخدم مع زر إعادة المحاولة |
